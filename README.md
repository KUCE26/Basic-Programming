# Basic-Programming

기초프로그래밍 중간고사 모의테스트 — 고려대학교 **기초프로그래밍 (Python)** 중간고사 대비 사이트예요.
엘리스 실습과 같은 형식(지시사항 → 코드 작성 → 실행/제출 → 테스트케이스 채점)으로 **A–E 5세트 · 50문제**와 엘리스 **4차시·8차시 과제 15문제**(과제 세트)를 브라우저에서 바로 풀 수 있어요. Python은 Pyodide(CPython 3.12 WebAssembly)로 브라우저 안에서 실행돼요.

사이트 주소 (GitHub Pages): https://foy1229-maker.github.io/Basic-Programming/

## 페이지

| 파일 | 내용 |
|---|---|
| `index.html` | 대시보드 — 세트 카드 5장, 세트별 통과 문제 수·점수, 10슬롯 안내 |
| `practice.html?set=1~6&q=1~15` | 실습 — 왼쪽 문제(지시사항·입출력 예시·Tips), 오른쪽 편집기(Ace) + 실행/제출. 실행은 `입력` 탭 내용으로, 제출은 숨겨진 테스트 전부(문제당 4~6개)로 채점. 통과 기록과 작성 중 코드는 이 브라우저(localStorage)에만 저장 |

## 범위와 구성

- 범위: 엘리스 「기초 프로그래밍」 **2~8차시** (Python 시작하기 · 자료형 · 조건문 · 반복문 · 함수 1·2). 모듈·예외 처리·클래스는 쓰지 않아요.
- 난이도: 4차시·8차시 과제 수준. 문제 유형은 고려대 엘리스 실습·과제와 엘리스 아카데미 「Do it! 첫 파이썬」을 참고해 새로 만든 변형 문제예요.
- 세트마다 같은 10슬롯: 1 입출력·산술 · 2 포맷팅·형 변환 · 3 리스트 · 4 딕셔너리 · 5 문자열 · 6 조건문 · 7 for 반복 · 8 while·break · 9 함수 · 10 함수 심화
- 채점 규칙: 줄 끝 공백과 맨 끝 빈 줄만 무시하고 글자 하나까지 비교(엘리스·`check.py`와 같음). 5초 넘게 돌면 시간 초과.

## 문제 수정·추가

문제 원본은 `problems/setN/`에 문제마다 세 파일이에요. (`set6`은 엘리스 과제 — `tools/make_elice_set.py`가 만들고, 입력이 없는 문제의 출력 예시는 모범 답안 실행 결과로 채워요.)

| 파일 | 내용 |
|---|---|
| `pK.md` | 제목, 스토리, `## 지시사항`, (함수형이면) `## 시작 코드`, `## 입력 예시 n` / `## 출력 예시 n`, `## Tips` |
| `pK_sol.py` | 모범 답안 (표준 입력 → 표준 출력) |
| `pK_tests.txt` | 채점용 입력 4~6개, `=====` 한 줄로 구분. 앞 두 개는 입력 예시와 같게 |

```bash
python3 tools/build.py        # 모범 답안을 모든 테스트로 실행해 기대 출력 생성, md 예시 출력과 대조 → assets/problems.js
python3 tools/verify.py 3     # 3세트만 빠르게 검사 (예시 일치, 금지 문법, 테스트 수)
```

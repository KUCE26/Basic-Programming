# 성적표 오름차순 정리

하트 여왕의 재판에서 증인들의 점수표가 뒤죽박죽이 되었습니다. 토끼 서기는 버블 정렬로 점수를 낮은 순서대로 다시 정리하기로 했습니다.

## 지시사항
1. 정수 `n` 을 입력받으세요. n 은 2 이상 20 이하입니다. 점수를 저장할 배열은 크기 20 으로 선언하세요.
2. n 개의 점수(0 이상 100 이하 정수)를 공백이나 줄바꿈으로 구분해 입력받아 배열에 저장하세요.
3. `void bubbleSort(int arr[], int n)` 함수를 완성하세요. 인접한 두 원소를 비교해 왼쪽이 더 크면 서로 바꾸는 방식으로 배열 앞쪽 n 개를 오름차순으로 정렬합니다.
4. 정렬된 점수를 첫 줄에 공백 한 칸으로 구분해 출력하세요(마지막 점수 뒤에는 공백 없이 줄바꿈).
5. 둘째 줄에 `최저점: ○ 최고점: ○` 를 출력하세요. 정렬된 배열의 첫 원소와 마지막 원소입니다.

## 시작 코드
```c
#include <stdio.h>

void bubbleSort(int arr[], int n) {
    // 인접한 두 원소를 비교하며 정렬하세요.
}

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
5
72 16 35 89 47
```
## 출력 예시 1
```
16 35 47 72 89
최저점: 16 최고점: 89
```

## 입력 예시 2
```
6
100 0 50 50 0 100
```
## 출력 예시 2
```
0 0 50 50 100 100
최저점: 0 최고점: 100
```

## Tips
배열을 함수에 넘기면 함수 안에서 바꾼 값이 main 의 배열에도 그대로 반영됩니다. 바깥 반복이 한 번 끝날 때마다 가장 큰 값이 뒤쪽에 하나씩 자리를 잡습니다.
채점은 결과만 보지만 시험에서는 정렬 과정을 직접 구현하는 문제가 나오니 지정한 정렬로 짤 것.

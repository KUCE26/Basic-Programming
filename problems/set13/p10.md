# 높은 점수부터 선택하기

체셔 고양이가 점수 카드를 가장 높은 것부터 늘어놓는 놀이를 합니다. 매번 남은 카드 중 가장 큰 카드를 골라 앞으로 보내는 선택 정렬 방식을 씁니다.

## 지시사항
1. 정수 `n` 을 입력받으세요. n 은 3 이상 20 이하입니다. 카드를 저장할 배열은 크기 20 으로 선언하세요.
2. n 개의 점수(0 이상 100 이하 정수)를 입력받아 배열에 저장하세요.
3. `void selectionSortDesc(int arr[], int n)` 함수를 완성하세요. 아직 정렬되지 않은 구간에서 가장 큰 원소를 찾아 그 구간의 맨 앞 원소와 바꾸는 일을 반복해 내림차순으로 정렬합니다.
4. 정렬된 점수를 첫 줄에 공백 한 칸으로 구분해 출력하세요(마지막 점수 뒤에는 공백 없이 줄바꿈).
5. 둘째 줄에 `상위 3개 합: ○` 를 출력하세요. 정렬 후 앞의 세 원소의 합입니다.

#include <stdio.h>

void selectionSortDesc(int arr[], int n) {
    // 가장 큰 원소를 찾아 앞으로 보내는 일을 반복하세요.

int main(void) {

## 입력 예시 1
```
5
72 16 35 89 47
```
## 출력 예시 1
```
89 72 47 35 16
상위 3개 합: 208
```

## 입력 예시 2
```
4
10 90 90 20
```
## 출력 예시 2
```
90 90 20 10
상위 3개 합: 200
```

## Tips
안쪽 반복에서는 최댓값이 있는 위치(인덱스)를 기억해 두었다가, 안쪽 반복이 끝난 뒤에 한 번만 바꿉니다.
채점은 결과만 보지만 시험에서는 정렬 과정을 직접 구현하는 문제가 나오니 지정한 정렬로 짤 것.

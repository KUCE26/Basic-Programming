# 사라진 다과 찾기

모자 장수의 찻상에 놓인 다과 번호표 중 어떤 번호가 어디 있는지 3월 토끼가 묻습니다. 앞에서부터 차례로 훑는 선형 탐색으로 대답해 주세요.

## 지시사항
1. 정수 `n` 을 입력받으세요. n 은 1 이상 20 이하입니다. 번호표를 저장할 배열은 크기 20 으로 선언하세요.
2. n 개의 번호(0 이상 99 이하 정수)를 입력받아 배열에 저장한 뒤, 찾을 번호 `key` (역시 0 이상 99 이하 정수)를 하나 더 입력받으세요.
3. `int findFirst(int arr[], int n, int key)` 함수를 완성하세요. 배열을 앞에서부터 차례로 보며 key 와 같은 값이 처음 나오는 위치(0 부터 센 인덱스)를 반환하고, 끝까지 없으면 -1 을 반환합니다.
4. 첫 줄에 findFirst 의 반환값을 출력하세요.
5. 둘째 줄에 `등장 횟수: ○회` 를 출력하세요. 배열에 key 가 몇 번 나오는지 셉니다. 없으면 0 회입니다.

## 시작 코드
```c
#include <stdio.h>

int findFirst(int arr[], int n, int key) {
    // 앞에서부터 차례로 비교하세요.
    return -1;
}

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
5
7 3 9 3 1
3
```
## 출력 예시 1
```
1
등장 횟수: 2회
```

## 입력 예시 2
```
4
10 20 30 40
50
```
## 출력 예시 2
```
-1
등장 횟수: 0회
```

## Tips
찾으면 바로 `return i;` 로 함수를 끝낼 수 있습니다. 반복문이 끝까지 돌았다는 것은 찾지 못했다는 뜻입니다.

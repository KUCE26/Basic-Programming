# 이어 붙인 이름

하트 여왕은 두 병사의 이름을 하이픈으로 이어 붙여 한 부대 이름으로 부릅니다.

## 지시사항
1. 공백 없는 영문 단어 두 개를 한 줄에 공백으로 구분해 입력받으세요. 각 단어의 길이는 1 이상 30 이하입니다.
2. 첫 단어와 둘째 단어의 길이를 각각 `첫 단어 길이: ○`, `둘째 단어 길이: ○` 형식으로 한 줄씩 출력하세요.
3. 크기 100 인 `char` 배열에 첫 단어를 복사하고, 하이픈 `-` 한 글자를 이어 붙이고, 둘째 단어를 이어 붙여 부대 이름을 만드세요. `string.h` 의 함수를 사용합니다.
4. `부대 이름: ○○` 형식으로 부대 이름을, 다음 줄에 `부대 이름 길이: ○` 형식으로 그 길이를 출력하세요.

## 시작 코드
```c
#include <stdio.h>
#include <string.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
Alice Rabbit
```
## 출력 예시 1
```
첫 단어 길이: 5
둘째 단어 길이: 6
부대 이름: Alice-Rabbit
부대 이름 길이: 12
```

## 입력 예시 2
```
Cheshire Cat
```
## 출력 예시 2
```
첫 단어 길이: 8
둘째 단어 길이: 3
부대 이름: Cheshire-Cat
부대 이름 길이: 12
```

## Tips
`strcpy` 는 덮어쓰고 `strcat` 은 이어 붙입니다. 이어 붙이기 전에 목적지 배열이 `strcpy` 로 먼저 채워져 있어야 합니다. 합친 결과가 담길 배열은 두 단어 길이의 합 + 1 (하이픈) + 1 (널 문자) 이상이어야 합니다.

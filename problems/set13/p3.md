# 구름다리 점프

토끼가 구름다리의 첫 번째 발판에서 출발합니다. 각 발판에는 숫자가 적혀 있고, 토끼는 지금 서 있는 발판의 숫자만큼 앞으로 점프합니다. 마지막 발판을 지나 강 건너편에 닿으면 다리를 건넌 것입니다.

## 지시사항
1. 발판 수 `n` 을 입력받으세요. n 은 1 이상 100 이하입니다. 배열은 크기 100 으로 선언하세요.
2. 각 발판에 적힌 정수(1 이상 100 이하)를 1번 발판부터 순서대로 공백으로 구분해 입력받아 저장하세요. 발판 수만큼 입력됩니다.
3. 1번 발판에서 출발해, 서 있는 발판의 숫자만큼 앞으로 점프하는 것을 반복하세요. 위치가 n 번을 넘으면(건너편) 멈춥니다.
4. 첫 줄에 `점프 횟수: ○` 를 출력하세요.
5. 둘째 줄에 점프를 시작한 발판의 번호(1부터)를 밟은 순서대로 공백 한 칸으로 구분해 출력하세요. 마지막 번호 뒤에는 공백이 없습니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
5
1 1 2 3 5
```
## 출력 예시 1
```
점프 횟수: 4
1 2 3 5
```

## 입력 예시 2
```
4
2 9 1 1
```
## 출력 예시 2
```
점프 횟수: 3
1 3 4
```

## Tips
반복 조건은 '마지막 발판에 도착했다'가 아니라 '마지막 발판을 지났다'입니다. 배열 인덱스는 0 부터지만 출력하는 발판 번호는 1 부터입니다.

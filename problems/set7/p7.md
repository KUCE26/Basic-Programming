# [12차시] 날짜 구하기
엘리스 회사 직원들의 생년월일이 년, 월, 일 순서로 저장되어 있습니다. 년도를 뺀 월과 일을 구하여 생일 날짜에 알림을 띄우려고 합니다.

## 지시사항
1. 첫 번째 줄에 생년월일을 8글자로 입력받습니다.
2. 4글자로 이루어진 년도를 제외한 월일만 출력합니다.

## 입력 예시 1
```
19801005
```
## 출력 예시 1
```
1005
```

## 입력 예시 2
```
20060229
```
## 출력 예시 2
```
0229
```

## Tips
정수로 바꾸면 앞의 0이 사라져요. 문자열 그대로 `[4:]`로 자르세요.

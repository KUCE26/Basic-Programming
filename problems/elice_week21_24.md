## [실습1] 지역 변수와 전역 변수 (lecturepages/55663069)
변수는 어디에서 선언되었는지에 따라 크게 지역 변수와 전역 변수로 나뉩니다. 우리나라에서는 통상적으로 맥주 500ml를 맥주 한 잔이라고 합니다. 하지만 영국에서는 맥주 한 잔을 1 파인트(568mL)라고 표현한다고 합니다.
지시사항: 실행 버튼을 눌러 발생하는 에러를 확인합니다. main() 함수에서 선언한 정수형 변수 beer를 england() 함수에서 사용할 수 있도록 전역 변수로 다시 선언합니다. main() 함수 내 beer 변수 선언 코드를 수정한 후 실행 버튼을 눌러 결과를 확인합니다.
Tips: 지역 변수는 함수 내부에서 선언된 변수로서, 함수가 종료되면 소멸합니다. 따라서 함수 외부에서 지역 변수를 참조할 수 없습니다. 전역 변수는 함수 외부에서 선언된 변수로, 어디서든지 사용이 가능합니다.
코드(해설 화면):
```c
#include <stdio.h>
int beer;
void england(void) {
    beer = 568;
    printf("영국의 맥주 한잔은 %dmL\n", beer);
}
int main(void) {
    // 정수형 변수 beer는 지역 변수로 main()내에서만 사용 가능합니다.
    int beer = 500;
    printf("한국의 맥주 한잔은 %dmL\n", beer);
    england();
    return 0;
}
```

## [실습3] 접미사 배열 (55663131)
3월 토끼가 "e… ce… ice… lice… elice…" 처럼 단어의 끝자리부터 한 글자씩 늘려 말함(접미사). qsort 를 활용하여 문자열 s 의 모든 접미사를 사전식으로 정렬하여 출력.

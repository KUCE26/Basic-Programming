# 평균 이상 찾기

코더랜드대 시험에서 최고점을 받은 학생이 누구인지, 평균 이상은 몇 명인지 조교 토끼가 정리합니다. 점수는 전역 배열에 저장하고, 평균 이상 인원은 함수가 세어 줍니다.

## 지시사항
1. 전역 변수로 크기 30 인 정수 배열 `score` 와 학생 수 `n` 을 선언하세요.
2. `main` 에서 학생 수 n (1 이상 30 이하)과 점수 n 개(0 이상 100 이하 정수)를 입력받아 `score` 에 저장하세요.
3. 인자가 없고 정수를 반환하는 함수를 만들어, 평균 이상인 학생 수를 반환하게 하세요. 평균과 같은 점수도 포함합니다.
4. 첫 줄에 `최고점: ○` 를 출력하세요.
5. 둘째 줄에 `위치:` 다음에 최고점인 학생의 번호(1부터)를 입력 순서대로 `공백 한 칸 + 번호` 형태로 모두 이어 출력하세요.
6. 셋째 줄에 `평균 이상: ○명` 을 출력하세요. 이 값은 지시한 함수의 반환값이어야 합니다.

## 시작 코드
```c
#include <stdio.h>

// 필요한 전역 변수와 함수를 여기에 작성하세요.

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
5
70 90 80 90 60
```
## 출력 예시 1
```
최고점: 90
위치: 2 4
평균 이상: 3명
```

## 입력 예시 2
```
4
50 50 50 50
```
## 출력 예시 2
```
최고점: 50
위치: 1 2 3 4
평균 이상: 4명
```

## Tips
함수 안에서 전역 배열 `score` 를 그대로 쓸 수 있으므로 배열을 매개변수로 넘길 필요가 없습니다. 최댓값을 먼저 구한 뒤 한 번 더 훑어 위치를 모두 찾습니다.

# 중복 번호 세어 정리

3월 토끼가 찻잔에 적힌 번호를 모아 왔는데 같은 번호가 여러 개입니다. 번호를 정렬한 뒤 종류별로 몇 개씩 있는지 표로 정리하려 합니다.

## 지시사항
1. 정수 `n` 을 입력받으세요. n 은 1 이상 20 이하입니다. 이어서 n 개의 정수(-100 이상 100 이하)를 입력받아 크기 20 의 배열에 저장하세요.
2. `qsort` 로 배열을 오름차순 정렬하세요. 비교 함수는 `int cmp(const void *a, const void *b)` 형태로 작성합니다.
3. 정렬된 배열에서 같은 값끼리 묶어, 값이 작은 것부터 한 줄에 하나씩 `값: ○개` 형식으로 출력하세요(콜론 뒤 공백 한 칸, 개수 뒤에 `개`).
4. 마지막 줄에 `종류 ○가지, 최다 ○` 를 출력하세요. 서로 다른 값의 가짓수와, 가장 많이 나온 값입니다. 가장 많이 나온 값이 여럿이면 그중 가장 작은 값을 출력합니다.

## 입력 예시 1
```
7
3 -1 3 2 -1 3 2
```
## 출력 예시 1
```
-1: 2개
2: 2개
3: 3개
종류 3가지, 최다 3
```

## 입력 예시 2
```
4
5 5 5 5
```
## 출력 예시 2
```
5: 4개
종류 1가지, 최다 5
```

## Tips
정렬하고 나면 같은 값이 붙어 있으므로, 앞 원소와 다른 값이 나올 때마다 새 묶음이 시작됩니다. 최다 값은 개수가 '더 클 때만' 갱신하면 동점일 때 작은 값이 남습니다.

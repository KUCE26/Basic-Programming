# X 무늬 울타리

여왕의 정원에 N x N 칸 울타리를 만듭니다. 바깥 테두리와 두 대각선을 서로 다른 무늬로 표시해 주세요.

## 지시사항
1. 정수 `N` (3 이상 9 이하)을 입력받으세요. `int g[9][9]` 를 0 으로 초기화해 선언하세요.
2. 먼저 N x N 영역의 테두리 칸(첫 행, 마지막 행, 첫 열, 마지막 열)을 1 로 바꾸세요.
3. 그다음 두 대각선(왼쪽 위에서 오른쪽 아래, 오른쪽 위에서 왼쪽 아래)의 칸을 2 로 바꾸세요. 테두리와 겹치는 칸은 대각선(2)이 우선합니다.
4. N 줄을 출력하세요. 값 0 은 `.`, 1 은 `#`, 2 는 `*` 로 칸 사이에 공백 없이 붙여 씁니다.
5. 마지막 줄에 `테두리 칸: ○, 대각선 칸: ○` 를 출력하세요. 배열에서 값이 1 인 칸의 수, 값이 2 인 칸의 수입니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
5
```
## 출력 예시 1
```
*###*
#*.*#
#.*.#
#*.*#
*###*
테두리 칸: 12, 대각선 칸: 9
```

## 입력 예시 2
```
4
```
## 출력 예시 2
```
*##*
#**#
#**#
*##*
테두리 칸: 8, 대각선 칸: 8
```

## Tips
오른쪽 위에서 왼쪽 아래로 가는 대각선의 열 번호는 `n - 1 - i` 입니다. 대각선을 나중에 덮어써야 우선순위가 자연스럽게 맞고, N 이 홀수일 때 가운데 칸이 두 대각선에 모두 속한다는 점에 주의하세요.

# 모음 없는 암호

하트 여왕의 비밀 문서는 모음을 모두 지우고 남은 글자를 하이픈으로 이어 적습니다.

## 지시사항
1. 공백 없는 영문 단어 하나를 `scanf("%s", ...)` 로 입력받으세요. 길이는 1 이상 100 이하이며 대소문자가 섞여 있을 수 있습니다.
2. 모음은 `a`, `e`, `i`, `o`, `u` 와 그 대문자 `A`, `E`, `I`, `O`, `U` 입니다. 단어에서 모음을 모두 지우고 남은 글자(자음, 숫자 등)를 원래 순서대로 한 줄에 출력하세요. 글자와 글자 사이에는 하이픈 `-` 하나를 넣고, 맨 앞과 맨 뒤에는 넣지 않습니다.
3. 남은 글자가 하나도 없으면 첫 줄은 빈 줄이 됩니다.
4. 둘째 줄에 `남은 글자 ○개, 삭제 ○개` 를 출력하세요(남은 글자 수, 지운 모음 수 순서).

## 시작 코드
```c
#include <stdio.h>
#include <string.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
Wonderland
```
## 출력 예시 1
```
W-n-d-r-l-n-d
남은 글자 7개, 삭제 3개
```

## 입력 예시 2
```
Cheshire
```
## 출력 예시 2
```
C-h-s-h-r
남은 글자 5개, 삭제 3개
```

## Tips
하이픈은 '이미 출력한 글자가 있을 때 새 글자 앞에' 찍으면 줄 끝에 남지 않습니다. 모음 판정은 조건을 길게 `||` 로 이어도 되고, 판정만 하는 함수를 따로 만들어도 됩니다.

# 섭씨를 화씨로

엘리스가 해외 날씨 앱을 보는데 화씨로만 표시되어 있어요. 섭씨 온도를 화씨로 바꿔 주는 프로그램을 만들어 보세요.

## 지시사항
1. 섭씨 온도를 실수로 입력받으세요.
2. 화씨 = 섭씨 * 9 / 5 + 32 공식으로 화씨 온도를 계산하세요.
3. 첫째 줄에 `25.0C = 77.0F` 형식으로 섭씨와 화씨를 모두 소수점 첫째 자리까지 출력하세요.
4. 둘째 줄에 화씨 온도를 `int()`로 소수점을 버린 정수 값을 출력하세요.

## 입력 예시 1
```
25.0
```
## 출력 예시 1
```
25.0C = 77.0F
77
```

## 입력 예시 2
```
36.5
```
## 출력 예시 2
```
36.5C = 97.7F
97
```

## Tips
f-string에서 `{값:.1f}`는 소수점 첫째 자리까지 나타냅니다.

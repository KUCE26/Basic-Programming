# 삼각형 판별기

엘리스가 막대 세 개로 삼각형을 만들려고 해요. 만들 수 있는지, 어떤 삼각형인지 알려 주세요.

## 지시사항
1. 세 변의 길이를 공백으로 구분하여 정수로 입력받으세요.
2. 가장 긴 변의 길이가 나머지 두 변의 길이의 합보다 작을 때만 삼각형을 만들 수 있습니다. 만들 수 없으면 `삼각형이 아닙니다.`를 출력하세요.
3. 삼각형을 만들 수 있다면 세 변이 모두 같을 때 `정삼각형입니다.`, 두 변만 같을 때 `이등변삼각형입니다.`, 모두 다르면 `일반삼각형입니다.`를 출력하세요.

## 입력 예시 1
```
3 3 3
```
## 출력 예시 1
```
정삼각형입니다.
```

## 입력 예시 2
```
3 4 5
```
## 출력 예시 2
```
일반삼각형입니다.
```

## Tips
`max(a, b, c)`로 가장 긴 변을 구할 수 있어요. 입력되는 길이는 모두 1 이상입니다.

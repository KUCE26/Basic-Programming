# 예산 안에서 쇼핑하기

엘리스가 용돈을 들고 시장에 갔어요. 물건 가격을 하나씩 확인하다가 돈이 모자라는 순간 쇼핑을 멈추려고 해요.

## 지시사항
1. 첫째 줄에 예산(정수)을 입력받으세요.
2. 그 다음 줄부터 물건의 가격이 한 줄에 하나씩 주어집니다. `while True`로 가격을 계속 입력받으세요.
3. 지금까지 산 물건의 가격 합에 이번 가격을 더했을 때 예산을 넘으면 그 물건은 사지 않고 `예산 초과`를 출력한 뒤 `break`로 반복을 끝내세요. (합이 예산과 같은 것은 괜찮습니다.)
4. 예산을 넘지 않으면 물건을 사고 개수를 1 늘리세요.
5. 반복이 끝난 뒤 `산 물건: 3개`, `남은 돈: 500원` 형식으로 두 줄을 출력하세요.
6. 입력은 반드시 예산을 넘는 가격이 나올 때까지 주어집니다.

## 입력 예시 1
```
10000
3000
4000
2500
5000
```
## 출력 예시 1
```
예산 초과
산 물건: 3개
남은 돈: 500원
```

## 입력 예시 2
```
5000
5000
100
```
## 출력 예시 2
```
예산 초과
산 물건: 1개
남은 돈: 0원
```

## Tips
`예산 초과`는 물건을 사지 않고 출력만 합니다. 산 물건 개수와 남은 돈에는 그 물건이 포함되지 않아요.

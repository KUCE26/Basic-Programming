# 리스트 뒤집기와 정렬

엘리스 토끼가 시계 숫자들을 적어 둔 리스트를 가지고 놀고 있어요. 리스트를 여러 방법으로 바꿔 봅시다.

## 지시사항
1. 공백으로 구분된 정수들을 입력받아 정수 리스트 `nums`로 만드세요. (원소는 2개 이상입니다.)
2. 첫째 줄에 짝수 번째 인덱스(0, 2, 4, ...)의 원소만 모은 리스트를 출력하세요.
3. 둘째 줄에 `nums`를 뒤집은 리스트를 출력하세요. (`reverse()` 또는 `[::-1]`)
4. 셋째 줄에 `nums`를 오름차순으로 정렬한 뒤 뒤에서 두 번째 값을 출력하세요. (중복 값도 각각 하나로 셉니다.)

## 입력 예시 1
```
3 8 1 9 4
```
## 출력 예시 1
```
[3, 1, 4]
[4, 9, 1, 8, 3]
8
```

## 입력 예시 2
```
10 20
```
## 출력 예시 2
```
[10]
[20, 10]
10
```

## Tips
리스트를 그대로 `print`하면 `[3, 1, 4]`처럼 출력됩니다. 정렬은 `sort()`나 `sorted()`를 쓸 수 있어요.

# 나만의 단어장

엘리스가 영어 단어장을 만들고 있어요. 단어를 등록하고 퀴즈를 내 보세요.

## 지시사항
1. 첫째 줄에 등록할 단어 수 N이 주어집니다.
2. 다음 N줄에는 `영어 한글` 형식으로 공백으로 구분된 단어 쌍이 주어집니다. 이를 딕셔너리에 저장하세요.
3. 그 다음 줄에 퀴즈 단어 수 M이 주어지고, 이어서 M줄에 영어 단어가 하나씩 주어집니다.
4. 각 퀴즈 단어에 대해 딕셔너리에 있으면 한글 뜻을, 없으면 `모르는 단어`를 한 줄씩 출력하세요.
5. 마지막 줄에 `등록된 단어 수: N` 형식으로 딕셔너리에 들어 있는 단어 수(딕셔너리의 길이)를 출력하세요. 퀴즈 단어 수와는 관계없습니다.

## 입력 예시 1
```
3
apple 사과
book 책
cat 고양이
3
book
dog
apple
```
## 출력 예시 1
```
책
모르는 단어
사과
등록된 단어 수: 3
```

## 입력 예시 2
```
2
rabbit 토끼
watch 시계
2
clock
watch
```
## 출력 예시 2
```
모르는 단어
시계
등록된 단어 수: 2
```

## Tips
`키 in 딕셔너리`로 키가 있는지 확인할 수 있어요. 같은 영어 단어는 입력에 두 번 나오지 않습니다.

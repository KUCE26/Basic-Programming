# 택시 요금 계산기

엘리스 토끼가 택시를 타고 이상한 나라로 가고 있어요. 택시 미터기가 고장 나서 요금을 직접 계산해야 합니다.

## 지시사항
1. 이동 거리(정수, 단위 m)를 입력받으세요.
2. 기본 요금은 2km(2000m)까지 4800원입니다.
3. 2000m를 넘으면 초과한 거리 131m마다 100원이 추가됩니다. 초과 거리를 131로 나눈 몫만큼 추가하고, 나머지가 있으면 한 번 더 추가하세요.
4. `택시 요금은 (요금)원입니다.` 형식으로 출력하세요.

## 입력 예시 1
```
2500
```
## 출력 예시 1
```
택시 요금은 5200원입니다.
```

## 입력 예시 2
```
1500
```
## 출력 예시 2
```
택시 요금은 4800원입니다.
```

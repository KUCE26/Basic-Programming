# 7은 건너뛰는 FizzBuzz

엘리스가 친구들과 FizzBuzz 게임을 하고 있어요. 그런데 7의 배수는 불행의 숫자라서 말하지 않고 넘어가기로 했어요.

## 지시사항
1. 정수 N을 입력받으세요.
2. 1부터 N까지 반복하면서 7의 배수는 `continue`로 건너뛰세요.
3. 3의 배수이면 `Fizz`, 5의 배수이면 `Buzz`, 3과 5의 공배수이면 `FizzBuzz`, 그 외에는 숫자 그대로 결과 리스트에 문자열로 추가하세요.
4. 결과 리스트의 원소를 공백으로 이어서 한 줄에 출력하세요. (`" ".join(...)`)

## 입력 예시 1
```
15
```
## 출력 예시 1
```
1 2 Fizz 4 Buzz Fizz 8 Fizz Buzz 11 Fizz 13 FizzBuzz
```

## 입력 예시 2
```
7
```
## 출력 예시 2
```
1 2 Fizz 4 Buzz Fizz
```

## Tips
`join`은 문자열로 이루어진 리스트에만 쓸 수 있으니 숫자는 `str()`로 바꿔 추가하세요. 7과 15의 공배수(예: 105)는 7의 배수로 먼저 건너뜁니다.

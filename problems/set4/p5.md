# 문자열 분석기

엘리스가 비밀 편지를 받았는데 앞뒤에 공백이 잔뜩 붙어 있어요. 문자열을 다듬고 분석해 보세요.

## 지시사항
1. 문자열을 한 줄 입력받고 `strip()`으로 앞뒤 공백을 제거하세요. (입력 문자열은 영문자와 공백으로만 이루어져 있습니다.)
2. `글자 수: 11` 형식으로 공백 제거 후 글자 수를 출력하세요.
3. `첫 글자: H, 마지막 글자: d` 형식으로 첫 글자와 마지막 글자를 출력하세요.
4. `짝수 인덱스: HloWrd` 형식으로 짝수 인덱스(0, 2, 4, ...) 글자만 모은 문자열을 출력하세요.
5. `소문자: hello world` 형식으로 모두 소문자로 바꾼 문자열을 출력하세요.

## 입력 예시 1
```
  Hello World  
```
## 출력 예시 1
```
글자 수: 11
첫 글자: H, 마지막 글자: d
짝수 인덱스: HloWrd
소문자: hello world
```

## 입력 예시 2
```
Python
```
## 출력 예시 2
```
글자 수: 6
첫 글자: P, 마지막 글자: n
짝수 인덱스: Pto
소문자: python
```

## Tips
`s[::2]`는 0번부터 2칸씩 건너뛰며 글자를 가져옵니다. 입력 문자열은 영문자와 공백으로만 이루어져 있습니다.

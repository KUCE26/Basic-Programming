# 이름표 옮기기 게임

쌍둥이 트위들덤과 트위들디가 상자 세 개 a, b, c 를 가지고 놉니다. 두 이름표 p 와 r 은 상자를 가리키는데, 명령에 따라 이름표를 옮기거나 상자 안의 값을 바꿉니다.

## 지시사항
1. 정수 `a`, `b`, `c` 를 한 줄에 입력받으세요(각각 -100 이상 100 이하). `int *p = &a;`, `int *r = &c;` 로 초기화하세요.
2. 다음 함수 네 개를 정의하세요. `void aim(int **pp, int *target)` : `*pp` 가 `target` 을 가리키게 합니다. `void bump(int *const q, int amount)` : `q` 가 가리키는 값에 `amount` 를 더합니다. `int peek(const int *q)` : `q` 가 가리키는 값을 반환합니다(값 변경 불가). `void swap_ptr(int **x, int **y)` : 두 포인터 변수의 내용을 서로 교환합니다.
3. 정수 `m` (1 이상 12 이하)과 다음 줄에 공백으로 구분된 명령 문자 m 개를 입력받으세요. 명령은 `a`, `b`, `c`, `+`, `*`, `S`, `P` 중 하나입니다.
4. `a`, `b`, `c` : `aim(&p, &변수)` 로 `p` 가 해당 상자를 가리키게 합니다. `+` : `bump` 로 `p` 가 가리키는 상자에 10 을 더합니다. `*` : `p` 가 가리키는 상자의 값을 2 배로 만듭니다. `S` : `swap_ptr(&p, &r)` 로 두 이름표를 서로 바꿉니다(상자 값은 그대로).
5. `P` : `a=○ b=○ c=○ p=○ r=○` 를 한 줄 출력하세요. 앞의 세 값은 변수 `a`, `b`, `c` 이고, `p`, `r` 의 값은 `peek` 으로 읽은 이름표가 가리키는 값입니다.
6. `P` 가 하나도 없으면 아무것도 출력하지 않습니다.

## Tips
`int *const q` 는 `q` 가 가리키는 대상은 못 바꾸지만 그 값은 바꿀 수 있고, `const int *q` 는 반대입니다. `S` 명령 뒤에는 `p` 와 `r` 이 가리키는 상자가 서로 바뀌었음을 매번 추적하세요. 명령 문자는 공백으로 구분되어 있으니, 문자 하나를 읽을 때 앞의 공백·줄바꿈을 건너뛰도록 하세요.

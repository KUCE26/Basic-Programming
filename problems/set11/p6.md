# 진법 변환 전광판

엘리스 토끼의 전광판은 숫자를 여러 진법으로 보여 줍니다. 입력받은 정수를 10진수, 8진수, 16진수로 출력해 보세요.

## 지시사항
1. 양의 정수 하나를 `int` 변수에 입력받으세요.
2. `10진수: ○○` 형식으로 출력하세요. (`%d`)
3. `8진수: ○○` 형식으로 출력하세요. (`%o`)
4. `16진수(소문자): ○○` 형식으로 출력하세요. (`%x`)
5. `16진수(대문자): ○○` 형식으로 출력하세요. (`%X`)
6. `접두사 포함: ○○` 형식으로 출력하세요. 16진수 앞에 `0x` 가 붙도록 `%#x` 를 사용하세요.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
255
```
## 출력 예시 1
```
10진수: 255
8진수: 377
16진수(소문자): ff
16진수(대문자): FF
접두사 포함: 0xff
```

## 입력 예시 2
```
48879
```
## 출력 예시 2
```
10진수: 48879
8진수: 137357
16진수(소문자): beef
16진수(대문자): BEEF
접두사 포함: 0xbeef
```

## Tips
`%o`, `%x`, `%X` 는 접두사 없이 숫자만 출력합니다. `%#x` 는 0이 아닌 값에 `0x` 를 붙여 줍니다.

# 진법 변환 전광판

엘리스 토끼의 전광판은 숫자를 여러 진법으로 보여 줍니다. 입력받은 정수를 10진수, 8진수, 16진수로 출력해 보세요.

## 지시사항
1. 1 이상 2147483647 이하의 정수 하나를 `int` 변수에 입력받으세요.
2. `10진수: ` 뒤에 10진수를 그대로 출력하세요.
3. `8진수: ` 뒤에 8진수를 폭 5칸 오른쪽 정렬(빈 곳은 공백)로 출력하세요.
4. `16진수(소문자): ` 뒤에 소문자 16진수를 8자리 0 채움으로 출력하세요.
5. `16진수(대문자): ` 뒤에 대문자 16진수를 접두사 없이 그대로 출력하세요.
6. `접두사 포함: ` 뒤에 소문자 16진수를 앞에 `0x` 를 붙여 전체 10칸, 빈 곳은 0 채움으로 출력하세요.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
255
```
## 출력 예시 1
```
10진수: 255
8진수:   377
16진수(소문자): 000000ff
16진수(대문자): FF
접두사 포함: 0x000000ff
```

## 입력 예시 2
```
48879
```
## 출력 예시 2
```
10진수: 48879
8진수: 137357
16진수(소문자): 0000beef
16진수(대문자): BEEF
접두사 포함: 0x0000beef
```

## Tips
`%o`, `%x`, `%X` 는 접두사 없이 숫자만 출력합니다. `%` 와 변환 문자 사이에 폭, 0 채움, `#` 같은 옵션을 넣을 수 있고, `#` 을 쓰면 `0x` 두 글자도 폭에 포함됩니다.

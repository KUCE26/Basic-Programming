# 공연 좌석 예매

엘리스 토끼가 공연 좌석을 예매합니다. 예매 코드는 열 문자, 줄 번호, `x`, 매수가 붙은 `B12x4` 같은 모양입니다. 코드를 풀어서 예매 내용을 확인해 보세요.

## 지시사항
1. `#define PRICE 12000` 으로 한 장의 가격을 상수로 정의하세요.
2. 예매 코드를 `scanf("%c%dx%d", ...)` 한 번으로 입력받아 열 문자(`char`), 줄 번호(`int`), 매수(`int`)에 저장하세요. 열 문자는 대문자 `A` ~ `Z` 한 글자입니다.
3. 열 번호를 `열 번호: ○○` 형식으로 출력하세요. `A` 는 1, `B` 는 2, ... 입니다. 문자끼리의 뺄셈을 이용하세요.
4. 줄 번호를 `줄 번호: ○○` 형식으로 출력하세요.
5. 총 금액(매수 * PRICE)을 `총 금액: ○○원` 형식으로 출력하세요.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
B12x4
```
## 출력 예시 1
```
열 번호: 2
줄 번호: 12
총 금액: 48000원
```

## 입력 예시 2
```
J30x6
```
## 출력 예시 2
```
열 번호: 10
줄 번호: 30
총 금액: 72000원
```

## Tips
형식 문자열에서 공백이 아닌 글자(`x`)는 입력에서 그대로 읽고 넘어갑니다. `%d` 는 숫자가 아닌 글자 앞에서 멈춥니다.

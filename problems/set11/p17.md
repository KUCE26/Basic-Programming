# 이상한 구름다리

이번 구름다리의 발판에는 음수나 0 도 적혀 있습니다. 양수는 앞으로, 음수는 뒤로 그만큼 점프하고, 0 은 제자리입니다. 토끼는 1번 발판에서 출발합니다.

## 지시사항
1. 발판 수 `n` (1 이상 10 이하)과 각 발판의 숫자 n 개(-10 이상 10 이하 정수)를 입력받아 크기 11 인 정수 배열에 저장하세요(발판 번호 1 이 인덱스 1 이 되도록 인덱스 0 은 쓰지 않아도 됩니다).
2. 현재 위치 `p` 를 1 로 두고 시작합니다. 1번 발판은 '밟은 발판' 으로 기록합니다.
3. 한 번 점프할 때마다 점프 횟수를 1 늘리고 `p` 에 현재 발판의 숫자를 더하세요. 그 직후 다음 순서로 판정합니다. ① p 가 n 보다 크면 `건넘`, ② p 가 1 보다 작으면 `추락`, ③ 이미 밟은 발판이면 `갇힘` 으로 끝냅니다. 어느 것도 아니면 그 발판을 밟은 것으로 기록하고 계속 점프합니다.
4. 끝나면 판정 단어, 공백 한 칸, 점프 횟수 순서로 한 줄에 출력하세요. 예를 들어 3번 점프해서 건넜다면 `건넘 3` 입니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
5
2 9 2 9 1
```
## 출력 예시 1
```
건넘 3
```

## 입력 예시 2
```
3
1 -2 1
```
## 출력 예시 2
```
추락 2
```

## Tips
배열에 접근하기 전에 위치가 범위 안인지 먼저 확인해야 합니다. 판정 순서(건넘, 추락, 갇힘)를 지키면 범위 밖 인덱스를 읽지 않습니다. 0 이 적힌 발판은 같은 곳에 다시 서게 되므로 '갇힘' 입니다.

# k번째로 큰 서로 다른 점수

여왕의 재판관은 점수 중복을 싫어합니다. 같은 점수는 하나로 치고 k 번째로 큰 점수를 찾아 그 점수가 처음 접수된 순서까지 알려 달라고 합니다.

## 지시사항
1. 정수 `n` 과 `k` 를 한 줄에 공백으로 구분해 입력받으세요. n 은 1 이상 15 이하, k 는 1 이상 15 이하입니다.
2. 다음 줄에서 n 개의 정수(-2000000000 이상 2000000000 이하, `int` 로 저장 가능)를 입력받아 크기 15 의 배열 `orig` 에 저장하세요.
3. `orig` 를 같은 크기의 배열 `sorted` 에 복사한 뒤 `qsort` 로 내림차순 정렬하세요. 비교 함수 `int cmp(const void *a, const void *b)` 는 두 값을 뺀 값을 반환하면 값이 클 때 오버플로가 나므로, 대소만 비교해 -1, 0, 1 중 하나를 반환하게 작성하세요.
4. 정렬된 배열에서 서로 다른 값만 큰 순서로 세었을 때 k 번째 값을 찾으세요. 서로 다른 값이 k 가지 이상이면 첫 줄에 `○번째: ○` 를 출력합니다(앞의 ○ 는 입력받은 k 값, 뒤의 ○ 는 찾은 점수. 예: k 가 3 이면 `3번째: ...`).
5. k 번째 값이 있으면 둘째 줄에 `처음 위치: ○` 를 출력하세요. `orig` 를 앞에서부터 선형 탐색하여 그 값이 처음 나오는 인덱스(0 부터)입니다.
6. 서로 다른 값이 k 가지보다 적으면 `○번째: 없음` 한 줄만(○ 는 입력받은 k 값) 출력하고 끝냅니다.

## 입력 예시 1
```
6 2
50 90 90 70 50 10
```
## 출력 예시 1
```
2번째: 70
처음 위치: 3
```

4 3

```

```

## Tips
내림차순은 비교 함수에서 두 인자의 자리를 바꾸면 됩니다. 정렬 뒤 앞에서부터 보며 '직전 값과 다를 때만' 개수를 올리면 중복이 하나로 셉니다.

# 교대 급수 계산기

도마뱀 빌이 분수 `1/1`, `1/2`, `1/3` ... 을 부호를 번갈아 바꿔 가며 더하는 계산기를 만들었습니다. 첫 항은 더하고, 둘째 항은 빼고, 셋째 항은 더하는 식입니다. 정수끼리의 나눗셈에 조심하세요.

## 지시사항
1. 항의 개수 `int n` (1 이상 1000 이하)을 입력받으세요. i 번째 항은 i 가 홀수면 `+1/i`, 짝수면 `-1/i` 입니다.
2. `for` 문으로 n 개의 항을 모두 더한 값을 `double` 로 구해 첫째 줄에 `전체 합: ○` 로 출력하세요. 소수점 다섯째 자리까지 나타냅니다.
3. 같은 반복문 안에서, 분모 i 가 3 의 배수인 항은 제외하고 더한 값도 구해 둘째 줄에 `3의 배수 항 제외: ○` 로 출력하세요. (소수점 다섯째 자리까지)
4. 셋째 줄에는 마지막 항을 `마지막 항: ○1/○` 형식으로 출력하세요. 부호(`+` 또는 `-`)가 첫 칸에, 이어서 `1/` 와 n 이 옵니다. 예: 항이 7개이면 `마지막 항: +1/7`. 부호는 `printf` 의 문자 출력으로 처리하세요.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
7
```
## 출력 예시 1
```
전체 합: 0.75952
3의 배수 항 제외: 0.59286
마지막 항: +1/7
```

## 입력 예시 2
```
1
```
## 출력 예시 2
```
전체 합: 1.00000
3의 배수 항 제외: 1.00000
마지막 항: +1/1
```

## Tips
`1/i` 는 정수 나눗셈이라 1 이외에는 0 이 됩니다. `1.0 / i` 처럼 실수로 만드세요. 항의 개수가 n 개이므로 반복 변수의 시작값과 끝값(`<` 인지 `<=` 인지)에 주의하세요.

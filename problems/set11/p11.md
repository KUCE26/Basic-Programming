# 자릿수 해부실

체셔 고양이가 숫자를 한 자리씩 뜯어 보는 해부실을 차렸습니다. 0 이라는 숫자도 한 자리 숫자임을 잊지 마세요.

## 지시사항
1. 0 이상 999999999 이하의 정수 `int n` 을 입력받으세요.
2. `do-while` 문 하나로 일의 자리부터 한 자리씩 떼어 내며 처리하세요. (`n` 이 0 이어도 반드시 한 자리로 처리되어야 합니다.)
3. 다음 네 줄을 출력하세요. `자릿수: ○`, `자릿수의 합: ○`, `가장 큰 자릿수: ○`, `뒤집은 수: ○` (일의 자리부터 읽어 만든 수이며, 앞쪽에 오는 0 은 사라집니다. 예: 1000 을 뒤집으면 1).
4. 다섯째 줄에는 뒤집은 수가 원래 수와 같으면 `회문`, 다르면 `회문 아님` 을 출력하세요.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
12345
```
## 출력 예시 1
```
자릿수: 5
자릿수의 합: 15
가장 큰 자릿수: 5
뒤집은 수: 54321
회문 아님
```

## 입력 예시 2
```
0
```
## 출력 예시 2
```
자릿수: 1
자릿수의 합: 0
가장 큰 자릿수: 0
뒤집은 수: 0
회문
```

## Tips
`while` 로 쓰면 `n` 이 0 일 때 몸통이 한 번도 실행되지 않습니다. 원래 수는 처리 중에 변하므로 비교를 위해 복사해 두세요. 뒤집은 수는 `rev = rev * 10 + 한 자리` 로 만듭니다.

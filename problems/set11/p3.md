# 자릿수 맞추기

엘리스 토끼가 두 실수의 합을 여러 가지 모양으로 출력하려고 합니다. 소수점 자릿수와 칸 맞춤을 정확히 지켜 보세요.

## 지시사항
1. 실수 두 개를 한 줄에 공백으로 구분해 `double` 로 입력받으세요. (`%lf`) 두 수의 합의 절댓값은 10000 미만입니다.
2. 두 수의 합을 구한 뒤, 아래 다섯 줄을 순서대로 출력하세요. 출력 형식은 `printf` 의 형식 지정자를 스스로 골라 맞춥니다.
3. 첫째 줄: 합을 소수점 이하 0자리로 출력합니다.
4. 둘째 줄: 합을 소수점 이하 1자리로 출력합니다.
5. 셋째 줄: 합을 소수점 이하 3자리로 출력합니다.
6. 넷째 줄: 합을 폭 10칸, 소수점 이하 3자리, 오른쪽 정렬로 출력하고 양옆을 대괄호 `[` `]` 로 감쌉니다.
7. 다섯째 줄: 합을 폭 10칸, 소수점 이하 3자리, 왼쪽 정렬로 출력하고 양옆을 대괄호 `[` `]` 로 감쌉니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
3.14159 2.71828
```
## 출력 예시 1
```
6
5.9
5.860
[     5.860]
[5.860     ]
```

## 입력 예시 2
```
1.3 1.3
```
## 출력 예시 2
```
3
2.6
2.600
[     2.600]
[2.600     ]
```

## Tips
`%.nf` 는 소수점 아래 n자리까지 반올림해서 출력합니다. 폭은 부호와 소수점도 한 칸씩 차지합니다.

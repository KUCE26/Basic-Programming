# 자릿수 맞추기

엘리스 토끼가 두 실수의 합을 여러 가지 모양으로 출력하려고 합니다. 소수점 자릿수와 칸 맞춤을 정확히 지켜 보세요.

## 지시사항
1. 실수 두 개를 한 줄에 공백으로 구분해 `double` 로 입력받으세요. (`%lf`)
2. 두 수의 합을 구한 뒤, 아래 다섯 줄을 순서대로 출력하세요.
3. 소수점 이하 0자리: `%.0f`
4. 소수점 이하 1자리: `%.1f`
5. 소수점 이하 3자리: `%.3f`
6. 폭 10칸, 소수점 이하 3자리, 오른쪽 정렬을 대괄호로 감싸서: `[%10.3f]`
7. 폭 10칸, 소수점 이하 3자리, 왼쪽 정렬을 대괄호로 감싸서: `[%-10.3f]`

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
3.14159 2.71828
```
## 출력 예시 1
```
6
5.9
5.860
[     5.860]
[5.860     ]
```

## 입력 예시 2
```
1.25 1.25
```
## 출력 예시 2
```
2
2.5
2.500
[     2.500]
[2.500     ]
```

## Tips
`%.nf` 는 반올림해서 출력하고, 정확히 중간인 값(예: 2.5)은 짝수 쪽으로 반올림됩니다. 폭은 부호와 소수점도 한 칸씩 차지합니다.

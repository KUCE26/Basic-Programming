# 토끼의 비밀 편지

엘리스 토끼가 친구에게 비밀 편지를 보냅니다. 글자마다 알파벳 순서로 세 칸씩 뒤의 글자로 바꾸는 시저 암호를 만들어 보세요.

## 지시사항
1. `getchar()` 를 4번 호출해 소문자 4글자를 `char` 변수에 차례로 저장하세요. 입력은 항상 `a` ~ `z` 사이의 소문자 4글자이고, 그 뒤에 줄바꿈이 옵니다.
2. 각 글자를 알파벳 순서로 세 칸 뒤의 글자로 바꾸어 `putchar()` 로 차례로 출력하세요. `z` 다음은 다시 `a` 로 돌아갑니다.
3. 4글자를 모두 출력한 뒤 `putchar('\n')` 으로 줄을 바꾸세요.
4. `printf` 와 `scanf` 는 사용하지 마세요.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
abcd
```
## 출력 예시 1
```
defg
```

## 입력 예시 2
```
bear
```
## 출력 예시 2
```
ehdu
```

## Tips
`char` 에 정수를 더하면 아스키 코드 값끼리의 덧셈이 됩니다. `'a' + 3` 은 `'d'` 의 코드와 같습니다. `putchar` 에 그 값을 그대로 넘기면 문자로 출력됩니다. 알파벳 끝에서 처음으로 돌아가려면 `((c - 'a' + 3) % 26) + 'a'` 처럼 나머지 연산을 쓰는 방법이 있습니다.

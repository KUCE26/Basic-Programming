# 임시 변수 없는 교환

모자 장수는 임시 변수 없이 세 모자의 크기를 서로 바꾸는 마술을 합니다. 하지만 같은 모자를 자기 자신과 바꾸라고 하면 마술이 실패합니다. 결과를 그대로 재현하세요.

## 지시사항
1. `void magic(int *a, int *b)` 함수를 정의하세요. 임시 변수를 쓰지 않고 다음 세 단계를 순서대로 수행합니다. (1) `*a` 에 두 값의 합을 저장합니다. (2) `*b` 에 (새로운 `*a`) 에서 `*b` 를 뺀 값을 저장합니다. (3) `*a` 에 (새로운 `*a`) 에서 (새로운 `*b`) 를 뺀 값을 저장합니다.
2. `main` 에서 크기 3 인 배열 `v` 에 정수 세 개를 입력받으세요(각각 -1000 이상 1000 이하). 그다음 정수 `q` (1 이상 8 이하)를 입력받으세요.
3. 다음 q 줄에 걸쳐 정수 `i`, `j` (각각 0 이상 2 이하, 같을 수 있음)를 공백으로 구분해 입력받아, 매번 `magic(&v[i], &v[j])` 를 호출하세요.
4. 호출할 때마다 한 줄에 `○번: ` 뒤에 `v[0]`, `v[1]`, `v[2]` 를 공백 한 칸으로 구분해 출력하세요(○ 는 1 부터 시작하는 호출 순서, 줄 끝 공백 없음).

## 시작 코드
```c
#include <stdio.h>

void magic(int *a, int *b) {
    // 지시사항을 참고하여 완성하세요.
}

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
3 5 7
2
0 1
1 2
```
## 출력 예시 1
```
1번: 5 3 7
2번: 5 7 3
```

## 입력 예시 2
```
1 2 3
3
1 1
0 2
2 2
```
## 출력 예시 2
```
1번: 1 0 3
2번: 3 0 1
3번: 3 0 0
```

## Tips
`i` 와 `j` 가 같으면 `a` 와 `b` 는 같은 변수를 가리킵니다. 각 단계 뒤에 그 변수의 값이 어떻게 되는지 직접 따라가 보세요.

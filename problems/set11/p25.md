# 모자 상자 속 최고 점수

재판정에 정수 점수와 실수 점수가 섞여 도착했습니다. 점수를 각자의 자료형 그대로 보관하되, 주소는 모두 `void *` 배열에 모아 두었다가 공정하게 비교하세요.

## 지시사항
1. 정수 `n`(1 이상 20 이하)을 입력받으세요.
2. 이어서 n 줄에 걸쳐 `종류 값` 을 입력받으세요. 종류가 `i` 이면 정수(-1000 이상 1000 이하), `d` 이면 실수(-1000.0 이상 1000.0 이하, 소수점 아래 정확히 한 자리, `-0.0` 은 주어지지 않음)입니다. 종류 문자 앞에는 공백이 있을 수 있으니 `scanf(" %c", ...)` 를 사용하세요.
3. 정수는 `int` 배열에, 실수는 `double` 배열에 저장하고, i 번째 점수의 주소를 `void *items[20]` 의 i 번째 칸에 저장하세요. 종류 문자는 따로 배열에 보관합니다.
4. `double asDouble(void *vp, char type)` 를 작성하세요. `type` 에 맞게 형 변환하여 값을 읽고 `double` 로 반환합니다.
5. `asDouble` 로 모든 점수를 같은 기준으로 비교해 가장 큰 점수를 찾으세요. 값이 같으면(예: 정수 3 과 실수 3.0) 먼저 입력된 점수를 고릅니다.
6. 첫 줄에 `최고 점수: ○ (△번째)` 를 출력하세요. 정수 점수는 정수 그대로, 실수 점수는 소수점 아래 한 자리까지 출력하고, △ 는 입력 순서(1 부터)입니다.
7. 둘째 줄에 `전체 합: ○` 를 출력하세요. 모든 점수를 더한 값을 소수점 아래 한 자리까지 출력합니다.

## 입력 예시 1
```

```

```
최고 점수: 3.5 (4번째)

```

3

## Tips
`void *` 로 저장해 두면 원래 자료형 정보가 사라지므로, 읽을 때 반드시 보관해 둔 종류에 맞는 형 변환을 해야 합니다. `int` 를 `double *` 로 읽으면 엉뚱한 값이 나옵니다.

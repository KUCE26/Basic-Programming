# 레벨 보상 누적 상자

토끼 게임에서는 레벨 n 에 도달하면 n 이하의 모든 레벨 보상을 한꺼번에 받습니다. 도달한 레벨을 입력하면 누적 보상을 계산해 주세요.

## 지시사항
1. 도달한 레벨을 정수로 입력받아 `int level` 에, 누적 코인과 상자 수를 `int coin`, `int box` 에 저장하세요. (둘 다 0 으로 시작)
2. 레벨별 보상: 1레벨 코인 10개 / 2레벨 코인 50개와 상자 1개 / 3레벨 코인 100개 / 4레벨 코인 200개와 상자 1개 / 5레벨 코인 500개. 도달한 레벨까지의 보상을 모두 더하세요. `switch` 하나로 `break` 를 일부러 빼서 구현해 보세요.
3. 레벨이 1~5 가 아니면 `레벨은 1부터 5까지입니다.` 한 줄만 출력하고 끝내세요.
4. 정상 입력이면 `획득 코인: ○`, `획득 상자: ○개` 두 줄을 출력하세요.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
3
```
## 출력 예시 1
```
획득 코인: 160
획득 상자: 1개
```

## 입력 예시 2
```
5
```
## 출력 예시 2
```
획득 코인: 860
획득 상자: 2개
```

## Tips
`break` 가 없으면 해당 `case` 부터 아래쪽 문장이 모두 실행됩니다. 큰 레벨부터 위에서 아래로 `case` 를 배치하면 누적 합이 자연스럽게 만들어집니다. `default` 에서 `return 0;` 으로 프로그램을 끝낼 수 있습니다.

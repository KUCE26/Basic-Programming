# 곱셈 상자의 한계

엘리스 토끼의 곱셈 상자는 `int` 만큼만 담을 수 있습니다. 같은 두 수를 `int` 로 곱했을 때와 `long long` 으로 곱했을 때 결과가 어떻게 다른지 비교해 보세요.

## 지시사항
1. 정수 두 개를 한 줄에 공백으로 구분해 `int` 변수 a, b 에 입력받으세요. 두 수의 절댓값은 각각 2,000,000,000 이하이며 음수일 수 있습니다.
2. `int` 변수 `small` 에 `a * b` 를 저장하고 `int 곱: ○○` 형식으로 출력하세요. `int` 로 계산한 결과는 오버플로로 이상한 값이 나올 수 있고, 그 값을 그대로 출력하면 됩니다.
3. `long long` 변수 `big` 에 `(long long)a * b` 를 저장하고 `long long 곱: ○○` 형식으로 출력하세요. (`%lld`)
4. 채점은 `gcc -O0` 로 하며, `int` 곱이 범위를 넘으면 2의 보수 방식으로 넘친 비트가 잘려 나온 값이 출력됩니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
12 34
```
## 출력 예시 1
```
int 곱: 408
long long 곱: 408
```

## 입력 예시 2
```
50000 50000
```
## 출력 예시 2
```
int 곱: -1794967296
long long 곱: 2500000000
```

## Tips
`int` 의 최댓값은 2147483647 입니다. `(long long)a * b` 는 a 를 먼저 `long long` 으로 바꾼 뒤 곱하므로 넘치지 않습니다. `(long long)(a * b)` 는 이미 넘친 뒤라서 소용이 없습니다.

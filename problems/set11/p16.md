# 진법 변환 재귀 기계

체셔 고양이의 기계는 십진수를 2 진수부터 9 진수까지 어떤 진법으로도 바꿔 줍니다. 재귀로 변환하고 자릿수도 재귀로 세어 보세요.

## 지시사항
1. 0 이상의 정수 `n` 을 `b` 진수(2 ≤ b ≤ 9)로 출력하는 `void to_base(int n, int b)` 를 **재귀 함수**로 정의하세요. 반환값은 없고, 가장 높은 자리부터 줄바꿈 없이 이어서 출력합니다. `n` 이 0 이면 `0` 하나를 출력합니다.
2. `n` 을 `b` 진수로 나타냈을 때의 자릿수를 반환하는 `int count_digits(int n, int b)` 를 **재귀 함수**로 정의하세요. `n` 이 0 이면 1 입니다. 두 함수의 원형은 `main()` 위에 선언하세요.
3. `main()` 에서 `n b` 를 한 줄에 하나씩 계속 입력받다가, `n` 이 -1 이면 멈추세요(그 줄의 b 는 입력되지 않습니다). 각 `n` 은 1000000 이하이고, 입력은 공백이나 줄바꿈으로 구분됩니다.
4. 쌍마다 한 줄씩 `○ -> ○진수: ○ (○자리)` 를 출력하세요. 처음 ○ 은 십진수 n, 둘째는 진법 b, 셋째는 변환한 수, 마지막은 자릿수입니다.
5. 입력이 끝나면 마지막 줄에 `변환 횟수: ○` 를 출력하세요.

## 시작 코드
```c
#include <stdio.h>

void to_base(int n, int b);
int count_digits(int n, int b);

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}

// to_base(), count_digits() 를 여기에 정의하세요.
```

## 입력 예시 1
```
19 2
255 8
-1
```
## 출력 예시 1
```
19 -> 2진수: 10011 (5자리)
255 -> 8진수: 377 (3자리)
변환 횟수: 2
```

## 입력 예시 2
```
0 5
7 9
-1
```
## 출력 예시 2
```
0 -> 5진수: 0 (1자리)
7 -> 9진수: 7 (1자리)
변환 횟수: 2
```

## Tips
출력 순서에 주의하세요. 높은 자리부터 나와야 합니다. 입력이 -1 이면 `b` 를 읽지 않도록 반복문 구조를 정하세요.

# 세 수의 최댓값과 중앙값

정렬 없이 세 정수의 최댓값과 중앙값을 구하고, 세 수 중 0 이 있는지도 알아보려 합니다. `if`-`else` 만으로 만들어 보세요.

## 지시사항
1. 세 정수를 공백으로 구분해 입력받아 `int a, b, c` 에 저장하세요. 각 값은 -1000 이상 1000 이하이고, 같은 값이 있을 수 있습니다.
2. 첫째 줄에 `최댓값: ○` 를 출력하세요.
3. 둘째 줄에 `중앙값: ○` 를 출력하세요. 중앙값은 크기순으로 세웠을 때 가운데 값입니다. (예: 5 5 2 의 중앙값은 5)
4. 셋째 줄에 세 수 중 하나라도 0 이면 `0 포함`, 아니면 `0 없음` 을 출력하세요. 세 수의 곱을 변수에 저장해 그 변수를 그대로 조건식에 사용하세요. (`==` 비교 없이 참/거짓만 이용)

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
3 9 5
```
## 출력 예시 1
```
최댓값: 9
중앙값: 5
0 없음
```

## 입력 예시 2
```
7 7 2
```
## 출력 예시 2
```
최댓값: 7
중앙값: 7
0 없음
```

## Tips
최댓값이 정해지면 나머지 두 수 중 큰 쪽이 중앙값입니다. 같은 값이 여러 개일 때 `>` 와 `>=` 중 무엇을 쓰는지에 따라 분기가 어긋날 수 있으니 주의하세요. 곱이 0 이 아니면 참입니다.

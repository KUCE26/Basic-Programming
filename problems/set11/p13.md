# 곱셈 짝꿍 찾기

체셔 고양이는 정수 n 을 두 수의 곱으로 나타내는 방법을 모두 찾으려 합니다. 시간을 아끼려고 안쪽 반복문에서는 곱이 n 을 넘으면 바로 그만두고, 바깥 반복문은 두 수가 뒤바뀌는 순간 끝냅니다.

## 지시사항
1. 정수 `int n` (2 이상 200 이하)을 입력받으세요.
2. 바깥 `for` 문은 `a` 를 1 부터 1 씩 늘립니다. 매 회차 맨 처음에 a × a 가 n 보다 크면 바깥 반복을 `break` 로 끝내세요.
3. 안쪽 `for` 문은 `b` 를 a 부터 n 까지 1 씩 늘립니다. 안쪽 반복의 본문이 실행될 때마다 가장 먼저 `비교 횟수` 를 1 늘리세요(이후 `break` 하는 회차도 센 뒤에 끝냅니다). 그다음 a × b 가 n 보다 크면 안쪽 반복만 `break` 하고, a × b 가 n 과 같으면 `a x b = n` 형식(곱셈 기호는 소문자 x, 양옆 공백 한 칸)으로 한 줄 출력하고 쌍의 개수를 1 늘리세요.
4. 반복이 모두 끝나면 `비교 횟수: ○`, `쌍 개수: ○` 를 한 줄씩 출력하세요.
5. 마지막 줄에는 쌍이 정확히 하나뿐이면 `소수입니다`, 아니면 `소수가 아닙니다` 를 출력하세요.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
12
```
## 출력 예시 1
```
1 x 12 = 12
2 x 6 = 12
3 x 4 = 12
비교 횟수: 21
쌍 개수: 3
소수가 아닙니다
```

## 입력 예시 2
```
7
```
## 출력 예시 2
```
1 x 7 = 7
비교 횟수: 10
쌍 개수: 1
소수입니다
```

## Tips
안쪽 `break` 는 안쪽 반복만 끝내므로, 바깥 반복은 a 가 커질 때까지 계속됩니다. 비교 횟수는 직접 손으로 세어 보며 검증해 보세요. n = 12 이면 쌍은 `1 x 12`, `2 x 6`, `3 x 4` 로 세 개입니다.

# 엘리스 토끼 명함

엘리스 토끼가 새 명함을 만들기로 했습니다. 이름, 직책, 전화번호를 입력받아 테두리가 있는 명함 모양으로 출력해 보세요.

## 지시사항
1. 이름, 직책, 전화번호를 각각 `scanf("%s", ...)` 로 입력받으세요. 모두 공백 없는 한 단어이고, 길이는 14글자 이하입니다.
2. 첫 줄과 마지막 줄은 `+` 하나, `-` 23개, `+` 하나로 이루어진 테두리입니다.
3. 둘째 줄은 `| "Bunny\Card"` 뒤에 공백 10개, 그리고 `|` 를 붙여 출력하세요. 큰따옴표와 역슬래시는 이스케이프 시퀀스로 출력해야 합니다.
4. 이어서 `| Name : `, `| Title: `, `| Tel  : ` 로 시작하는 세 줄을 출력하세요. 각 줄에서 입력받은 값은 폭 14칸 왼쪽 정렬(`%-14s`)로 출력하고, 그 뒤에 공백 하나와 `|` 를 붙입니다.
5. 모든 줄의 길이는 25글자로 같아야 합니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
Alice
Leader
010-1234-5678
```
## 출력 예시 1
```
+-----------------------+
| "Bunny\Card"          |
| Name : Alice          |
| Title: Leader         |
| Tel  : 010-1234-5678  |
+-----------------------+
```

## 입력 예시 2
```
Bob
Dev
02-880-1234
```
## 출력 예시 2
```
+-----------------------+
| "Bunny\Card"          |
| Name : Bob            |
| Title: Dev            |
| Tel  : 02-880-1234    |
+-----------------------+
```

## Tips
폭 지정은 문자열이 짧을 때만 공백을 채웁니다. `\"` 와 `\\` 는 출력에서 각각 `"` 와 `\` 한 글자가 됩니다.

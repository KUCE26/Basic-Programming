# 이름이 같은 레벨

같은 이름의 변수가 전역과 지역, 매개변수에 동시에 있으면 어느 쪽이 바뀌는지 따져 봐야 합니다. 토끼 캐릭터의 레벨을 올리면서 그 차이를 확인하세요.

## 지시사항
1. 정수형 전역 변수 `level` 을 선언하고 1 로 초기화하세요.
2. 전역 변수 `level` 을 그대로 반환하는 `int get_level(void)`, 전역 변수 `level` 에 `n` 을 더하는 `void raise_level(int n)` 을 정의하세요.
3. 매개변수의 이름도 `level` 인 `int upgrade(int level)` 을 정의하세요. 이 함수 안에서 매개변수 `level` 에 (자기 자신 × 2 + 1) 을 대입한 뒤 그 값을 반환합니다. 전역 변수는 바뀌지 않아야 합니다.
4. 매개변수의 이름도 `level` 인 `void show(int level)` 을 정의하세요. `인자 ○, 전역 ○` 를 출력하고 줄을 바꿉니다. 첫 ○ 은 받은 매개변수 값, 둘째 ○ 은 `get_level()` 로 얻은 전역 `level` 값입니다.
5. `main()` 에서 정수 세 개 `a`, `b`, `c` 를 한 줄에 공백으로 구분해 입력받으세요(1 이상 50 이하). 이어서 아래 순서대로 실행하고, 출력은 한 줄에 하나씩입니다.
   1. `raise_level(a)` 를 호출합니다.
   2. `upgrade(b) = ○` 를 출력합니다(`upgrade(b)` 의 반환값).
   3. `show(c)` 를 호출합니다.
   4. `main()` 안에 `level` 이라는 이름의 지역 변수를 선언해 (a + b) 로 정하고, `main 지역 level = ○` 를 출력합니다. 그 값을 `raise_level()` 의 인자로 넘겨 호출합니다.
   5. `최종 전역 level = ○` 를 출력합니다(`get_level()` 의 반환값).

## 시작 코드
```c
#include <stdio.h>

int level = 1;

int get_level(void);
void raise_level(int n);
int upgrade(int level);
void show(int level);

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}

// 네 함수를 여기에 정의하세요.
```

## 입력 예시 1
```
2 3 4
```
## 출력 예시 1
```
upgrade(b) = 7
인자 4, 전역 3
main 지역 level = 5
최종 전역 level = 8
```

## 입력 예시 2
```
1 1 1
```
## 출력 예시 2
```
upgrade(b) = 3
인자 1, 전역 2
main 지역 level = 2
최종 전역 level = 4
```

## Tips
같은 이름이 여러 곳에 있으면 가장 가까운 범위의 변수가 바깥 변수를 가립니다. 함수 안의 `level` 이 매개변수인지 지역 변수인지 전역 변수인지 하나씩 표시해 보세요. 전역 값을 바꾸려면 그 이름이 가려지지 않은 곳(`raise_level`)에서 바꿔야 합니다.

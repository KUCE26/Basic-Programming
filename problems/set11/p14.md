# 속 빈 거꾸로 피라미드

하트 여왕이 거꾸로 선 피라미드 모양의 정원 울타리를 만들라고 명령했습니다. 울타리는 테두리 문자로 두르고 속은 다른 문자로 채웁니다.

## 지시사항
1. 높이 `int n`, 테두리 문자 `char border`, 속 문자 `char inner` 를 한 줄에 공백으로 구분해 입력받으세요. n 은 1 이상 9 이하이고 두 문자는 공백이 아닌 서로 다른 한 글자입니다.
2. i 번째 줄(1 부터 n 까지)은 맨 앞에 공백 (i - 1) 개를 쓴 뒤, 길이 (2 × (n - i) + 1) 인 문자열을 출력합니다. 첫 번째 줄은 전부 테두리 문자이고, 그 아래 줄들은 양 끝만 테두리 문자, 그 사이는 속 문자입니다. 길이가 1 인 줄은 테두리 문자 하나뿐입니다.
3. 줄마다 출력이 끝나면 줄을 바꾸세요.
4. 모든 줄 뒤에 `테두리: ○개` 를 출력하세요. 출력된 테두리 문자의 총 개수입니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
5 # .
```
## 출력 예시 1
```
#########
 #.....#
  #...#
   #.#
    #
테두리: 16개
```

## 입력 예시 2
```
4 * -
```
## 출력 예시 2
```
*******
 *---*
  *-*
   *
테두리: 12개
```

## Tips
공백, 문자 출력용 안쪽 반복문을 각각 따로 두세요. 줄의 첫 칸과 끝 칸, 그리고 첫 번째 줄을 구분하는 조건을 정리해 보면 쉽습니다. 문자 입력은 `" %c"` 로 받으면 앞 공백을 건너뜁니다.

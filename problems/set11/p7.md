# 조건문 없는 가위바위보 심판

엘리스 토끼와 체셔가 가위바위보를 합니다. 가위는 0, 바위는 1, 보는 2 로 적습니다. 아직 조건문을 배우지 않았으니 산술·나머지·삼항 연산자만으로 승패를 가려 보세요.

## 지시사항
1. 토끼가 낸 수와 체셔가 낸 수를 공백으로 구분해 한 줄에 정수로 입력받으세요. (각각 0, 1, 2 중 하나)
2. 첫째 줄에 `토끼: ○ / 체셔: ○` 형식으로 각자 낸 것을 `가위`, `바위`, `보` 라는 이름으로 출력하세요.
3. 둘째 줄에 승패를 출력하세요. 두 사람이 같은 것을 내면 `결과: 무승부`, 토끼가 이기면 `결과: 토끼 승`, 체셔가 이기면 `결과: 체셔 승` 입니다. 바위는 가위를, 가위는 보를, 보는 바위를 이깁니다.
4. 셋째 줄에 두 사람이 낸 수의 합이 짝수이면 `합: 짝수`, 홀수이면 `합: 홀수` 를 출력하세요.
5. `if`, `switch` 는 쓰지 않습니다. 세 갈래 판정은 삼항 연산자를 겹쳐서 처리하세요.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
1 0
```
## 출력 예시 1
```
토끼: 바위 / 체셔: 가위
결과: 토끼 승
합: 홀수
```

## 입력 예시 2
```
0 2
```
## 출력 예시 2
```
토끼: 가위 / 체셔: 보
결과: 토끼 승
합: 짝수
```

## Tips
(토끼 - 체셔 + 3) % 3 을 계산하면 0 은 무승부, 1 은 토끼 승, 2 는 체셔 승입니다. 왜 그런지 세 경우를 손으로 따져 보세요. 삼항 연산자는 `a ? b : (c ? d : e)` 처럼 겹쳐 쓸 수 있고, 결과를 `%s` 자리에 문자열로 넣을 수도 있습니다.

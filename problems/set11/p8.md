# 권한 비트 판독기

엘리스 토끼 서버의 사용자 권한은 정수 하나에 비트로 저장됩니다. 가장 오른쪽 비트(1)가 읽기, 다음(2)이 쓰기, 그다음(4)이 실행, 그다음(8)이 관리 권한입니다. 비트 연산자로 권한을 읽어 보세요.

## 지시사항
1. 권한 값 `flags` 를 `int` 로 입력받으세요. (0 이상 15 이하)
2. 비트 연산자로 각 권한이 켜져 있는지 1 또는 0 으로 구해 `읽기: ○`, `쓰기: ○`, `실행: ○`, `관리: ○` 를 한 줄씩 출력하세요. 비교 연산자나 조건문 없이 `>>` 와 `&` 만으로 하세요.
3. 권한 수 `cnt` 를 위 네 값의 합으로 구해 `권한 수: ○` 를 출력하세요.
4. 등급을 `등급: ○○` 형식으로 출력하세요. 관리 권한이 있으면 `관리자`, 없고 쓰기 권한이 있으면 `작성자`, 둘 다 없고 읽기 권한이 있으면 `독자`, 모두 없으면 `없음` 입니다. 삼항 연산자를 중첩해서 쓰세요.
5. 전체 네 권한 중 켜진 비율을 퍼센트로 소수점 첫째 자리까지 `켜진 비율: ○○.○%` 형식으로 출력하세요.
6. `flags` 의 아래 네 비트를 모두 뒤집은 값(비트 반전 후 아래 네 비트만 남김)을 `반전: ○○` 로 출력하세요.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
13
```
## 출력 예시 1
```
읽기: 1
쓰기: 0
실행: 1
관리: 1
권한 수: 3
등급: 관리자
켜진 비율: 75.0%
반전: 2
```

## 입력 예시 2
```
6
```
## 출력 예시 2
```
읽기: 0
쓰기: 1
실행: 1
관리: 0
권한 수: 2
등급: 작성자
켜진 비율: 50.0%
반전: 9
```

## Tips
`(flags >> k) & 1` 은 k 번째 비트(오른쪽이 0 번째)를 꺼냅니다. 정수끼리 `cnt / 4 * 100` 은 0 이 되니 `(double)` 을 먼저 붙이세요. `%` 문자를 출력하려면 `%%` 라고 씁니다.

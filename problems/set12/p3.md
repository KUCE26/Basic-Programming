# 토끼 점수 줄 세우기

엘리스 토끼가 시험 점수를 낮은 순과 높은 순으로 한 번씩 적어 두려고 합니다. `vector` 와 `sort` 로 정렬해 보세요.

## 지시사항
1. 첫 줄에 정수의 개수 `N`, 둘째 줄에 `N` 개의 정수를 입력받아 `vector<int> v` 에 저장하세요. (1 ≤ N ≤ 1000, 절댓값 1000 이하)
2. `sort` 로 오름차순 정렬한 결과를 공백으로 구분해 한 줄에 출력하세요.
3. 이어서 내림차순으로 정렬한 결과를 공백으로 구분해 둘째 줄에 출력하세요. (`greater<int>()` 또는 `rbegin()`/`rend()` 사용)
4. 각 줄의 마지막 숫자 뒤에는 공백을 넣지 않아도 됩니다. (줄 끝 공백은 채점에서 무시됩니다)

## 시작 코드
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <functional>
using namespace std;

int main() {
    int n;
    vector<int> v;

    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
5
3 1 4 1 5
```
## 출력 예시 1
```
1 1 3 4 5
5 4 3 1 1
```

## 입력 예시 2
```
6
-2 10 0 -7 10 3
```
## 출력 예시 2
```
-7 -2 0 3 10 10
10 10 3 0 -2 -7
```

## Tips
`sort(v.begin(), v.end())` 는 기본이 오름차순입니다. 내림차순은 세 번째 인자에 `greater<int>()` 를 넘기세요 (`<functional>` 필요). `vector<int> v(n)` 으로 크기를 먼저 잡으면 `v[i]` 에 바로 읽어 넣을 수 있습니다.

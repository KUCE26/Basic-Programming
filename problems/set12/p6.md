# 토끼 굴 괄호 검사

엘리스 토끼가 만든 암호문에는 `()`, `[]`, `{}` 괄호만 들어 있습니다. 괄호의 짝이 올바르게 맞는지 `stack` 으로 검사해 주세요.

## 지시사항
1. 괄호로만 이루어진 문자열 한 줄을 `string s` 로 입력받으세요. 문자는 `(`, `)`, `[`, `]`, `{`, `}` 중 하나이고 길이는 1~1000입니다.
2. 여는 괄호를 만나면 `stack<char>` 에 넣고, 닫는 괄호를 만나면 스택의 맨 위 여는 괄호와 종류가 같은지 확인하세요.
3. 닫는 괄호를 만났는데 스택이 비어 있거나 종류가 다르면 짝이 맞지 않는 것입니다. 끝까지 본 뒤 스택이 비어 있어야 합니다.
4. 모든 짝이 맞으면 `YES`, 아니면 `NO` 를 출력하세요.

## 시작 코드
```cpp
#include <iostream>
#include <stack>
#include <string>
using namespace std;

int main() {
    string s;
    stack<char> st;

    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
([]{})
```
## 출력 예시 1
```
YES
```

## 입력 예시 2
```
([)]
```
## 출력 예시 2
```
NO
```

## Tips
`st.top()` 과 `st.pop()` 은 스택이 비어 있을 때 호출하면 오류가 나므로 반드시 `st.empty()` 를 먼저 확인하세요. `pop()` 은 값을 돌려주지 않아서 `top()` 으로 먼저 읽어 두어야 합니다. 끝까지 읽은 뒤 스택이 남아 있으면 `NO` 입니다.

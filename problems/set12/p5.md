# 토끼 단어 빈도 세기

엘리스 토끼가 일기에 쓴 단어들이 몇 번씩 나왔는지 세어 보려고 합니다. `map` 으로 단어별 등장 횟수를 정리해 주세요.

## 지시사항
1. 첫 줄에 단어의 개수 `N` 을 입력받으세요. (1 ≤ N ≤ 1000)
2. 둘째 줄부터 공백으로 구분된 단어 `N` 개를 입력받으세요. 단어는 소문자 영문자 1~10글자입니다. (줄바꿈이 섞여 있어도 `cin >>` 으로 차례대로 읽으면 됩니다)
3. `map<string, int>` 에 단어별 등장 횟수를 저장하세요.
4. 단어를 사전순으로 한 줄에 하나씩 `단어 횟수` 형식으로 출력하세요.

## 시작 코드
```cpp
#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    int n;
    map<string, int> cnt;

    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
6
apple rabbit apple tea rabbit apple
```
## 출력 예시 1
```
apple 3
rabbit 2
tea 1
```

## 입력 예시 2
```
5
b a c a b
```
## 출력 예시 2
```
a 2
b 2
c 1
```

## Tips
`map` 은 키를 항상 정렬된 상태로 보관하므로 순회하면 자동으로 사전순입니다. `cnt[w]++` 는 키가 없으면 값 0 으로 새로 만든 뒤 증가시켜 주므로 따로 초기화할 필요가 없습니다. 순회는 `for (auto& kv : cnt)` 로 하고 `kv.first`, `kv.second` 를 씁니다.

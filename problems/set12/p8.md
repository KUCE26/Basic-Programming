# 토끼 지도 돌리기

엘리스 토끼가 정사각형 보물 지도를 받았는데 방향이 틀어져 있었습니다. 지도를 시계 방향으로 90도 돌려서 바로잡아 주세요.

## 지시사항
1. 첫 줄에 지도의 크기 `N` 을 입력받으세요. (1 ≤ N ≤ 10)
2. 이어서 `N` 줄에 걸쳐 `N` 개의 정수를 공백으로 구분해 입력받아 `a[i][j]` 에 저장하세요. (절댓값 100 이하)
3. 새 격자 `b` 를 만들어, 시계 방향으로 90도 회전한 결과를 저장하세요. 회전 후 `b[i][j]` 는 원래 격자의 `a[N-1-j][i]` 입니다.
4. `b` 를 `N` 줄에 걸쳐 출력하세요. 각 줄은 정수를 공백으로 구분합니다.

## 시작 코드
```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    int a[10][10];
    int b[10][10];

    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
3
1 2 3
4 5 6
7 8 9
```
## 출력 예시 1
```
7 4 1
8 5 2
9 6 3
```

## 입력 예시 2
```
2
1 2
3 4
```
## 출력 예시 2
```
3 1
4 2
```

## Tips
회전은 값을 옮기는 규칙을 먼저 손으로 확인하세요. 원래 첫 번째 **열**을 아래에서 위로 읽으면 새 격자의 첫 번째 **행**이 됩니다. 제자리에서 돌리려 하면 값이 덮어써지므로 새 배열 `b` 를 따로 쓰는 편이 안전합니다. 이 인덱스 변환은 SWEA 구현 문제에서 격자를 다룰 때 자주 쓰입니다.

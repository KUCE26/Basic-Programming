# 거꾸로 읽는 토끼 문장

엘리스 토끼가 비밀 편지를 쓰려고 합니다. 한 줄짜리 문장의 단어 수를 세고, 문장 전체를 거꾸로 뒤집어 보세요.

## 지시사항
1. 공백이 포함된 한 줄 문장을 `getline(cin, s)` 로 `string s` 에 입력받으세요. 문장은 영문자와 공백으로만 이루어지고, 맨 앞과 맨 뒤에 공백이 없으며 단어 사이 공백은 하나입니다. (1 ≤ 길이 ≤ 100)
2. 단어의 개수를 세어 `단어 수: ○` 형식으로 첫 줄에 출력하세요. (공백의 개수 + 1 입니다)
3. 문장 전체를 글자 단위로 뒤집은 문자열을 둘째 줄에 출력하세요. `<algorithm>` 의 `reverse` 를 사용하세요.

## 시작 코드
```cpp
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

int main() {
    string s;

    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
hello alice rabbit
```
## 출력 예시 1
```
단어 수: 3
tibbar ecila olleh
```

## 입력 예시 2
```
I am a rabbit in wonderland
```
## 출력 예시 2
```
단어 수: 6
dnalrednow ni tibbar a ma I
```

## Tips
`cin >> s` 는 공백에서 멈추므로 공백 포함 한 줄은 `getline(cin, s)` 를 쓰세요. 앞에서 `cin >> n` 으로 숫자를 읽었다면 남은 줄바꿈을 먼저 버려야 하지만, 이 문제는 첫 입력이 문장이라 그럴 필요가 없습니다. `reverse(s.begin(), s.end())` 는 `s` 자체를 바꿉니다. 글자를 하나씩 보려면 `for (int i = 0; i < (int)s.size(); i++)` 로 돌면서 `s[i]` 로 읽으면 됩니다.

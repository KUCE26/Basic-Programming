# 토끼 미로 탈출

엘리스 토끼가 격자 모양 미로의 왼쪽 위에서 출발해 오른쪽 아래 출구까지 가려고 합니다. 가장 적게 움직이는 횟수를 `queue` 로 구해 주세요.

## 지시사항
1. 첫 줄에 격자의 세로 `N` 과 가로 `M` 을 입력받으세요. (1 ≤ N, M ≤ 20)
2. 이어서 `N` 줄에 걸쳐 `M` 개의 0 또는 1 을 공백으로 구분해 입력받아 `grid` 에 저장하세요. `1` 은 벽, `0` 은 길이며 출발점 `(0,0)` 과 도착점 `(N-1,M-1)` 은 항상 `0` 입니다.
3. 토끼는 상하좌우 한 칸씩 이동할 수 있고 벽과 격자 밖으로는 갈 수 없습니다.
4. `queue<pair<int,int>>` 로 BFS 를 수행해 `(0,0)` 에서 `(N-1,M-1)` 까지 가는 최소 이동 횟수를 출력하세요. 갈 수 없으면 `-1` 을 출력하세요. (`N = M = 1` 이면 `0`)

## Tips
BFS 는 큐에서 꺼낼 때가 아니라 **넣을 때** 방문 표시(`dist` 갱신)를 해야 같은 칸이 중복으로 들어가지 않습니다. `dist` 를 `-1` 로 채워 두면 방문 여부와 거리를 한 배열로 관리할 수 있습니다. 격자 밖 검사를 벽 검사보다 먼저 하세요.

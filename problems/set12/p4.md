# 토끼 퀴즈 순위표

엘리스 토끼 퀴즈 대회가 끝났습니다. 참가자의 이름과 점수로 순위표를 만들어 주세요. 점수가 높은 사람이 먼저이고, 점수가 같으면 이름이 사전순으로 앞서는 사람이 먼저입니다.

## 지시사항
1. 첫 줄에 참가자 수 `N` 을 입력받으세요. (1 ≤ N ≤ 100)
2. 이어서 `N` 줄에 걸쳐 `이름 점수` 를 입력받으세요. 이름은 공백 없는 영문자 1~10글자, 점수는 0~100 정수입니다.
3. `vector<pair<int, string>>` 처럼 점수와 이름을 `pair` 로 묶어 저장하세요.
4. 점수 내림차순, 점수가 같으면 이름 오름차순으로 정렬하세요. (`sort` 에 비교 함수나 람다를 넘기거나, 점수에 `-` 를 붙여 저장하는 방법이 있습니다)
5. 정렬된 순서대로 `이름 점수` 를 한 줄에 한 명씩 출력하세요.

## 시작 코드
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
using namespace std;

int main() {
    int n;
    vector<pair<int, string>> v;

    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

```

alice 90
```

```
3

amy 50
```


## Tips
`pair` 는 `first` 가 같으면 `second` 로 넘어가며 비교하므로 `pair<int,string>` 을 그냥 `sort` 하면 점수 오름차순·이름 오름차순이 됩니다. 점수만 내림차순으로 만들려면 점수를 음수로 저장하거나 람다 비교 함수를 쓰세요. 대문자는 소문자보다 사전순에서 앞섭니다.

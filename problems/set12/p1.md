# 토끼 점수판 합산

엘리스 토끼가 퀴즈 대회 점수 N개를 한꺼번에 입력받아 요약하려고 합니다. 입력이 많아도 빠르게 읽는 C++ 방식으로 합계와 최댓값, 최솟값을 구해 보세요.

## 지시사항
1. 첫 줄에 점수의 개수 `N` 을, 둘째 줄에 `N` 개의 정수를 공백으로 구분해 입력받으세요. (1 ≤ N ≤ 100000, 각 점수의 절댓값은 10억 이하)
2. 입력은 `cin` 으로 받으세요. 합계는 `int` 범위를 넘을 수 있으니 `long long` 변수에 저장하세요.
3. 합계, 최댓값, 최솟값을 구해 `합계: ○ 최댓값: ○ 최솟값: ○` 형식으로 한 줄에 출력하세요. (출력은 `cout` 사용)

## 시작 코드
```cpp
#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
5
80 95 70 100 85
```
## 출력 예시 1
```
합계: 430 최댓값: 100 최솟값: 70
```

## 입력 예시 2
```
4
-3 7 0 -10
```
## 출력 예시 2
```
합계: -6 최댓값: 7 최솟값: -10
```

## Tips
`ios::sync_with_stdio(false); cin.tie(nullptr);` 는 `cin`/`cout` 을 C 의 `scanf`/`printf` 와 분리하고 `cin` 이 `cout` 을 매번 비우는 동작을 끄는 코드입니다. 입출력이 많을 때 훨씬 빨라지지만, 이걸 쓴 뒤에는 `cin`/`cout` 과 `scanf`/`printf` 를 섞어 쓰면 안 됩니다. 줄바꿈은 `endl` 대신 `"\n"` 이 빠릅니다.

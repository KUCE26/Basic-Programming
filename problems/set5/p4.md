# 학급 투표

엘리스 토끼네 반에서 반장 선거가 열렸습니다. 투표용지에 적힌 이름이 한 줄로 주어질 때 후보별 득표수와 당선자를 알려 주세요.

## 지시사항
1. 후보 이름들을 공백으로 구분하여 한 줄로 입력받으세요. 같은 이름이 나온 횟수가 그 후보의 득표수입니다.
2. 빈 딕셔너리를 만들고, 이름이 처음 나오면 값 1로 추가하고, 이미 있으면 값을 1 증가시키세요.
3. 첫째 줄에 득표수 딕셔너리를 그대로 출력하세요. (이름이 처음 입력된 순서대로)
4. 둘째 줄에 `당선: 이름` 형식으로 가장 득표수가 많은 후보를 출력하세요. 득표수가 같으면 먼저 나온 후보를 출력합니다.

## 입력 예시 1
```
민수 지영 민수 철수 지영 민수
```
## 출력 예시 1
```
{'민수': 3, '지영': 2, '철수': 1}
당선: 민수
```

## 입력 예시 2
```
하나 둘 하나 둘
```
## 출력 예시 2
```
{'하나': 2, '둘': 2}
당선: 하나
```

## Tips
`for 키, 값 in 딕셔너리.items():` 로 키와 값을 함께 꺼낼 수 있습니다. 더 클 때만 갱신하면 동률일 때 먼저 나온 후보가 남습니다.

# 리스트 변환기

엘리스 토끼는 리스트의 모든 원소에 같은 규칙을 적용해 새 리스트를 만들고 싶습니다. 규칙을 함수로 넘겨받는 `apply` 함수를 만들어 보세요.

## 지시사항
1. `apply(func, nums)` 함수를 완성하세요. 리스트 `nums`의 각 원소에 함수 `func`를 적용한 결과를 담은 새 리스트를 `return`하세요.
2. `double`에 원소를 2배로 만드는 `lambda`를 저장하세요.
3. `mod3`에 원소를 3으로 나눈 나머지로 만드는 `lambda`를 저장하세요.
4. 메인 코드는 첫째 줄에 `double`을 적용한 리스트, 둘째 줄에 `mod3`을 적용한 리스트를 출력합니다. 리스트는 `print(리스트)` 그대로 출력합니다. 메인 코드는 수정하지 마세요.

def apply(func, nums):

## 입력 예시 1
```

```

## Tips

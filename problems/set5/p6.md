# 놀이기구 탑승

엘리스 토끼는 놀이공원에서 롤러코스터를 타려고 합니다. 이 놀이기구는 키와 나이 제한이 있습니다. 탑승 가능 여부를 판정해 보세요.

## 지시사항
1. 첫째 줄에 키(정수, cm), 둘째 줄에 나이(정수)를 입력받으세요.
2. 키가 140 이상이고 나이가 8 이상이면 `탑승 가능`을 출력하세요.
3. 키 조건만 맞지 않으면 `키 제한`을 출력하세요.
4. 나이 조건만 맞지 않으면 `나이 제한`을 출력하세요.
5. 키와 나이 조건이 모두 맞지 않으면 `탑승 불가`를 출력하세요.

## 입력 예시 1
```
150
10
```
## 출력 예시 1
```
탑승 가능
```

## 입력 예시 2
```
130
10
```
## 출력 예시 2
```
키 제한
```

## Tips
논리 연산자 `and`로 두 조건을 한 번에 검사할 수 있습니다.

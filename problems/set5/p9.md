# 이름 정리하기

엘리스 토끼는 출석부의 이름 표기가 제각각이라 깔끔하게 정리하려고 합니다. 양쪽 공백을 없애고 첫 글자만 대문자로 만드는 함수를 완성해 보세요.

## 지시사항
1. `clean_name(name)` 함수를 완성하세요.
2. `name`의 양쪽 공백을 제거하세요.
3. 공백을 제거한 이름의 첫 글자는 대문자로, 나머지 글자는 소문자로 바꾸세요. `upper()`, `lower()`와 슬라이싱을 사용하고 `capitalize()`는 사용하지 마세요.
4. 만든 문자열을 `return`으로 돌려주세요.
5. 아래 코드는 수정하지 마세요. 메인 코드는 첫째 줄에서 이름의 수 N을 입력받고, 이어지는 N줄의 이름을 각각 `clean_name`으로 정리해 출력합니다. 각 이름은 공백 제거 후 한 글자 이상입니다.

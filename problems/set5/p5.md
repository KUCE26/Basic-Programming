# 공백 바꾸기

엘리스 토끼는 파일 이름에 공백이 들어가면 곤란하다는 것을 알게 되었습니다. 문장의 공백을 밑줄로 바꾸고, 특정 글자를 찾아 보세요.

## 지시사항
1. 첫째 줄에 문장을, 둘째 줄에 찾을 글자 한 개를 입력받으세요.
2. 첫째 줄에 문장의 모든 공백을 `_`로 바꾼 문자열을 출력하세요.
3. 둘째 줄에 문장에 찾을 글자가 몇 번 나오는지 출력하세요. (`count`)
4. 셋째 줄에 찾을 글자가 처음 나오는 위치(인덱스)를 출력하세요. 없으면 `-1`을 출력합니다. (`find`)
5. 입력받은 문장의 공백은 따로 지우지 말고 그대로 사용하세요. 공백을 바꾼 결과가 아니라 원래 문장에서 개수와 위치를 구합니다.

## 입력 예시 1
```
i love python programming
o
```
## 출력 예시 1
```
i_love_python_programming
3
3
```

## 입력 예시 2
```
my first report
z
```
## 출력 예시 2
```
my_first_report
0
-1
```

## Tips
`find`는 글자가 없으면 `-1`을 돌려줍니다.

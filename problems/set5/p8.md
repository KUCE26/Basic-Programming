# 밥값 더치페이

엘리스 토끼와 친구들은 식사 후 각자 먹은 만큼 돈을 냈습니다. 총액과 1인당 부담액, 가장 많이 낸 금액을 정리해 보세요.

## 지시사항
1. 첫째 줄에 사람 수(1 이상)를 입력받으세요. 이어서 사람 수만큼, 한 줄에 한 명씩 낸 금액(0 이상의 정수)이 입력됩니다.
2. `while`문을 사용하여 사람 수만큼 금액을 입력받으세요.
3. 첫째 줄에 `총액: (값)`, 둘째 줄에 `1인당 부담액: (값)`, 셋째 줄에 `가장 많이 낸 금액: (값)` 형식으로 출력하세요.
4. 1인당 부담액은 `총액 // 사람 수` 입니다.
5. 가장 많이 낸 금액은 `max()`를 사용하지 말고 직접 비교하여 구하세요.

## 입력 예시 1
```
4
12000
8000
15000
5000
```
## 출력 예시 1
```
총액: 40000
1인당 부담액: 10000
가장 많이 낸 금액: 15000
```

## 입력 예시 2
```
3
10000
10000
10000
```
## 출력 예시 2
```
총액: 30000
1인당 부담액: 10000
가장 많이 낸 금액: 10000
```

## Tips
반복할 때마다 횟수를 1씩 늘리는 변수를 두고 `while 횟수 < 사람 수:` 로 반복합니다.

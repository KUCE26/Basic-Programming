# 단어장 정리

엘리스 토끼가 공책에 적은 영어 단어들을 정리하려고 합니다. 중복된 단어가 얼마나 있는지, 사전순으로는 어떻게 되는지 알아보세요.

## 지시사항
1. 공백으로 구분된 단어들을 한 줄로 입력받아 리스트로 만드세요.
2. 첫째 줄에 리스트의 길이를 출력하세요.
3. 둘째 줄에 중복을 제거한 단어의 개수를 출력하세요. (`set()` 또는 `in`을 활용하세요.)
4. 셋째 줄에 단어를 사전순으로 정렬한 리스트를 출력하세요.
5. 넷째 줄에 단어를 사전 역순으로 정렬한 리스트를 출력하세요.
6. 원래 리스트는 정렬로 바꾸지 말고 `sorted()`로 새 리스트를 만들어 출력하세요. 리스트는 `print(리스트)` 그대로 출력합니다.

## 입력 예시 1
```
apple banana apple cherry banana apple
```
## 출력 예시 1
```
6
3
['apple', 'apple', 'apple', 'banana', 'banana', 'cherry']
['cherry', 'banana', 'banana', 'apple', 'apple', 'apple']
```

## 입력 예시 2
```
dog cat bird
```
## 출력 예시 2
```
3
3
['bird', 'cat', 'dog']
['dog', 'cat', 'bird']
```

## Tips
`sorted(리스트, reverse=True)`는 역순으로 정렬한 새 리스트를 돌려줍니다.

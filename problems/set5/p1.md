# 피자 나누기

엘리스 토끼는 친구들과 피자 파티를 열었습니다. 피자를 몇 판 주문했는지, 한 판이 몇 조각인지, 사람이 몇 명인지 알 때 한 사람이 몇 조각씩 먹을 수 있는지 계산해 보세요.

## 지시사항
1. 첫째 줄에 피자 판 수, 둘째 줄에 한 판의 조각 수, 셋째 줄에 사람 수(1 이상)를 정수로 입력받으세요.
2. 전체 조각 수를 구하세요.
3. 전체 조각을 사람들에게 똑같이 나눌 때, 한 사람당 받는 조각 수를 `//` 연산자로 구하세요.
4. 나누고 남는 조각 수를 `%` 연산자로 구하세요.
5. 첫째 줄에 `한 사람당 조각 수: (값)`, 둘째 줄에 `남는 조각 수: (값)` 형식으로 출력하세요.

## 입력 예시 1
```
3
8
5
```
## 출력 예시 1
```
한 사람당 조각 수: 4
남는 조각 수: 4
```

## 입력 예시 2
```
2
6
4
```
## 출력 예시 2
```
한 사람당 조각 수: 3
남는 조각 수: 0
```

## Tips
`//`는 몫, `%`는 나머지를 구합니다.

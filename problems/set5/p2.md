# 할인 가격표

엘리스 토끼의 가게에서 세일을 시작합니다. 상품 이름, 정가, 할인율을 입력받아 가격표 문구를 만들어 보세요.

## 지시사항
1. 첫째 줄에 상품명, 둘째 줄에 정가(정수), 셋째 줄에 할인율(정수, 단위 %)을 입력받으세요.
2. 할인가는 `정가 * (100 - 할인율) / 100` 으로 계산한 뒤 `int()`로 소수점 이하를 버려 정수로 만드세요.
3. f-string을 사용하여 `상품명: 할인가원 (정가 정가원, 할인율% 할인)` 형식으로 한 줄에 출력하세요. 띄어쓰기와 괄호, 쉼표 위치를 예시와 똑같이 맞추세요.

## 입력 예시 1
```
후드티
39900
20
```
## 출력 예시 1
```
후드티: 31920원 (정가 39900원, 할인율 20% 할인)
```

## 입력 예시 2
```
양말
3500
15
```
## 출력 예시 2
```
양말: 2975원 (정가 3500원, 할인율 15% 할인)
```

## Tips
`/` 연산의 결과는 실수(float)이므로 `int()`로 감싸면 소수점 아래가 버려집니다.

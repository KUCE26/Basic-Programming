# [24차시 과제2] 시험 점수

엘리스 토끼는 친구들에게 평균점수를 넘지 못했을 거라는 소식을 전했지만 친구들이 믿지 않아, 누가 평균을 넘지 못했는지 공개하려 합니다.

## 지시사항
1. `grades` 배열에 친구들의 성적이 들어있습니다. `grades` 배열의 평균을 구하세요.
2. 0번부터 29번까지의 친구들 중 평균을 넘지 못한 친구들(점수가 평균 이하인 친구들)의 인덱스를 작은 번호부터 공백을 기준으로 한 줄에 출력하세요. (이 배열에는 평균과 같은 점수가 없으므로 "이하"와 "미만"의 결과가 같습니다.)
3. 마지막 인덱스 뒤에는 공백 없이 줄바꿈만 출력합니다. 입력은 없습니다.

## 시작 코드
```c
#include <stdio.h>

float grades[30] = {3.5, 4.0, 3.5, 2.5, 4.5, 1.0, 0.0, 4.5, 3.5, 4.5,
                    1.5, 2.0, 4.5, 3.0, 3.5, 3.5, 3.5, 4.0, 2.0, 1.0,
                    1.0, 3.0, 2.5, 2.0, 2.5, 3.5, 4.0, 4.0, 3.5, 4.5};

int main(void) {
    //위의 grades 배열의 평균을 구하고 평균을 넘지 못한 친구들의 번호를 출력해 봅시다.

    return 0;
}
```

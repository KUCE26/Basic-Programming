# [24차시 과제1] 함수

엘리스 토끼는 친구들의 평균점수를 계산하려 합니다. 친구들이 점수를 4.0, 3.0 같은 수가 아니라 A, B 같은 알파벳으로 알려주었습니다. 알파벳으로 된 점수를 실수로 된 점수로 바꾸는 함수를 작성해 봅시다!

## 지시사항
1. `char2num` 함수를 작성해 출력 예시대로 출력하도록 해봅시다. 입력은 없습니다.
2. `char2num` 은 문자 하나를 받아 실수 점수를 반환합니다. A 는 4.0, B 는 3.0, C 는 2.0, D 는 1.0, F 는 0.0 입니다.
3. `main` 함수는 수정하지 마세요.

## 시작 코드
```c
#include <stdio.h>

//여기에 char2num함수를 작성해 주세요.

int main(void)
{
    // 아래는 수정하지 마세요.
    printf("A grade : %.1f\n", char2num('A'));
    printf("B grade : %.1f\n", char2num('B'));
    printf("C grade : %.1f\n", char2num('C'));
    printf("D grade : %.1f\n", char2num('D'));
    printf("F grade : %.1f\n", char2num('F'));
    return 0;
}
```

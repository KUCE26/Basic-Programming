# [24차시 과제5] 달팽이 나라의 엘리스 토끼

이상한 달팽이의 세계로 간 엘리스 토끼가 미스터 스네이크를 도와 달팽이 크기를 확인합니다.

## 지시사항
1. 정수 n 이 입력됩니다(1 이상 9 이하). n x n 크기의 2차원 배열 `snail` 을 만들고, 바깥쪽 왼쪽 위 칸에서 시작해 시계 방향 나선을 그리며 안쪽으로 들어가면서 1 부터 n x n 까지의 수를 차례로 채우세요. (n = 3 이면 첫 줄이 1 2 3, 둘째 줄이 8 9 4, 셋째 줄이 7 6 5)
2. 출력 코드는 시작 코드에 있습니다. 각 칸을 폭 3칸 오른쪽 정렬(`%3d`)로 출력하고 행마다 줄을 바꿉니다. 출력 코드는 수정하지 마세요.
3. 변수 `n`, `i`, `j` 와 배열 `snail` 의 선언은 시작 코드의 주석 자리에 직접 작성해야 합니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 정수 n, i, j 와 n x n 2차원 배열 snail (최대 9 x 9) 을 선언하세요.

    // n 을 입력받으세요.

    // 배열 snail 을 달팽이 모양으로 채우세요.

    // 아래는 수정하지 마세요.
    for (i = 0; i < n; i++) {
        for (j = 0; j < n; j++) {
            printf("%3d", snail[i][j]);
        }
        printf("\n");
    }
    return 0;
}
```

## 입력 예시 1
```
5
```
## 출력 예시 1
```
  1  2  3  4  5
 16 17 18 19  6
 15 24 25 20  7
 14 23 22 21  8
 13 12 11 10  9
```

## 입력 예시 2
```
3
```
## 출력 예시 2
```
  1  2  3
  8  9  4
  7  6  5
```

## Tips
배열을 먼저 0 으로 비워 두면 "이미 채워진 칸"을 쉽게 알 수 있어요. 오른쪽 → 아래 → 왼쪽 → 위 순서로 방향을 바꿉니다.

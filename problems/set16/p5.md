# [20차시 과제5] 대각선 그리기

엘리스 토끼는 반복문을 활용하여 입력된 줄 개수에 따라 해당 줄만큼의 대각선을 그리고 싶어합니다. 출력 예시를 참고하여 입력받은 줄 개수만큼의 대각선을 그리는 코드를 작성하세요.

## 지시사항
1. 정수를 입력받습니다(1 이상 20 이하). 입력된 정수 줄 개수만큼 우측 하향 대각선을 그립니다. 대각선은 `*` 로 그릴 수 있습니다.
2. 각 줄의 길이는 입력된 정수와 같습니다. 별 앞뒤의 나머지 칸은 공백으로 채웁니다. (채점에서는 줄 끝 공백이 있어도 없어도 같게 봅니다.)
3. i 번째 줄(1부터 셉니다)에는 i 번째 칸에 별이 하나 있습니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
5
```
## 출력 예시 1
```
*    
 *   
  *  
   * 
    *
```

## 입력 예시 2
```
3
```
## 출력 예시 2
```
*  
 * 
  *
```

## Tips
이중 for 문에서 줄 번호와 칸 번호가 같을 때만 별을 찍으면 됩니다.

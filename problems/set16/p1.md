# [20차시 과제1] 단위 바꾸기

엘리스 토끼는 이사를 하기 위해 집을 알아보고 있습니다. 엘리스 토끼는 집의 넓이를 평으로 재는 것이 익숙한데, 부동산에서는 항상 m^2 로 알려줍니다. 1 m^2 는 대략 0.3평 정도 되는데, 10배, 100배 등으로 정확히 떨어지지 않아서 헷갈립니다. 우리가 헷갈리는 엘리스를 도와주도록 합시다!

## 지시사항
1. 엘리스가 확인한 집의 넓이가 m^2 단위의 정수로 입력됩니다(1 이상 1000 이하). 한 줄에 정수 하나입니다.
2. 입력된 넓이를 평으로 변환해서 소수점 한 자리까지 출력해 주세요. (1 m^2 = 0.3평으로 계산합니다.)
3. 결과 뒤에는 줄바꿈을 한 번 출력합니다. 다른 글자는 출력하지 않습니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
25
```
## 출력 예시 1
```
7.5
```

## 입력 예시 2
```
100
```
## 출력 예시 2
```
30.0
```

## Tips
평수를 실수로 계산해야 합니다. 정수끼리의 계산으로 소수점이 사라지지 않게 주의하세요.

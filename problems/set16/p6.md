# [20차시 과제6] 엘리스와 별 헤는 밤

밤이 깊어지자 엘리스 머리 위에는 별이 보이기 시작했습니다. 주어진 조건(별의 거리)에 따라 달라지는 별을 출력해 봅시다.

## 지시사항
1. 별의 거리 i가 입력으로 주어질 때(2 이상 15 이하의 정수), 별 사이의 거리가 i인 W모양의 대칭인 별자리를 출력하세요. 단, 별의 거리 i가 짝수이면 2행의 두 별 사이의 거리는 i-1입니다.
2. 별 사이의 거리는 두 별 사이에 있는 공백의 개수입니다. 1행에는 별이 3개, 2행에는 별이 2개 있고, 2행의 별은 1행의 별 사이 가운데에 대칭이 되도록 놓입니다. (i = 3 이면 같은 행의 별 사이 공백 3칸, i = 4 이면 1행은 공백 4칸, 2행은 공백 3칸)
3. 각 줄 끝에는 공백을 출력하지 않습니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
3
```
## 출력 예시 1
```
*   *   *
  *   *
```

## 입력 예시 2
```
4
```
## 출력 예시 2
```
*    *    *
   *   *
```

## Tips
2행은 앞 공백 개수와 별 사이 공백 개수를 따로 계산해야 합니다. 홀수·짝수 두 경우를 모두 손으로 그려 보세요.

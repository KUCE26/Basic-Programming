# [24차시 과제4] 파스칼의 삼각형

첫째 줄에 1, 그 아래부터는 위에 있는 두 수를 합한 값을 적는 파스칼의 삼각형을 출력해 봅시다.

## 지시사항
1. 줄 수를 나타내는 정수 하나가 입력됩니다(1 이상 15 이하).
2. 입력된 정수만큼의 줄을 가진 파스칼의 삼각형을 왼쪽 정렬로 출력하세요. 각 줄의 수는 한 칸의 공백으로 구분하고, 줄 끝에는 공백을 출력하지 않습니다.
3. i 번째 줄에는 수가 i 개 있고, 각 줄의 처음과 끝 수는 1 입니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
5
```
## 출력 예시 1
```
1
1 1
1 2 1
1 3 3 1
1 4 6 4 1
```

## 입력 예시 2
```
3
```
## 출력 예시 2
```
1
1 1
1 2 1
```

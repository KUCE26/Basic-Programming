# [20차시 과제3] 중간값 찾기

엘리스 토끼는 3개의 값이 입력되면 자동으로 중간값을 찾아주는 프로그램을 구현하고자 합니다.

## 지시사항
1. 공백을 기준으로 세 개의 정수를 입력받습니다(한 줄, -1000 이상 1000 이하). 세 정수는 서로 다르지 않을 수도 있습니다.
2. 출력 예시를 참고하여 입력된 정수 중에서 중간값을 찾아서 출력합니다. 같은 값이 있어도 세 수를 작은 순서로 정렬했을 때 가운데 오는 값이 중간값입니다. (예: 5 5 3 이면 5)
3. `중간값은 N입니다.` 형식으로 한 줄 출력합니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
10 100 50
```
## 출력 예시 1
```
중간값은 50입니다.
```

## 입력 예시 2
```
7 3 9
```
## 출력 예시 2
```
중간값은 7입니다.
```

## Tips
배열이나 함수 없이 비교만으로 충분합니다. 같은 값이 있을 때 `<` 와 `<=` 를 어떻게 쓸지 생각해 보세요.

# [24차시 과제3] 평균과 평균보다 큰 수

도마뱀 빌에게 수학을 가르쳤던 엘리스 토끼가 다른 동물들의 쪽지 시험 점수의 평균과 평균 이상의 점수를 조사하려 합니다.

## 지시사항
1. 첫째 줄에 점수의 개수 `len` (1 이상 20 이하)이, 둘째 줄에 `len` 개의 점수(0 이상 100 이하의 정수)가 공백을 기준으로 입력됩니다. 입력 부분은 시작 코드에 이미 작성되어 있습니다.
2. `solve` 함수를 완성하여 첫째 줄에 평균을 소수점 첫째 자리까지 출력하고, 다음 줄에 평균 이상인 값들을 입력된 순서대로 공백을 기준으로 출력하세요. (평균과 같은 값도 포함합니다. 원본 설명에는 "평균보다 큰 값"이라는 표현도 있으나, 지시사항 본문대로 평균 이상으로 합니다.)
3. 둘째 줄 마지막 값 뒤에는 공백 없이 줄바꿈만 출력합니다.

## 시작 코드
```c
#include <stdio.h>

void solve(int arr[], int len) {
    // 지시사항을 참고하여 코드를 작성하세요.

}

int main(void) {
    int len;
    int n[20];
    int i;
    scanf("%d", &len);
    for (i = 0; i < len; i++) {
        scanf("%d", &n[i]);
    }
    solve(n, len);
    return 0;
}
```

## 입력 예시 1
```
3
1 2 3
```
## 출력 예시 1
```
2.0
2 3
```

## 입력 예시 2
```
5
90 85 70 60 100
```
## 출력 예시 2
```
81.0
90 85 100
```

## Tips
평균은 실수로 계산해야 합니다. 평균과 정확히 같은 값(예: 5 5 5)도 출력 대상이에요.

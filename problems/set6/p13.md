# [8차시 과제5] 올바른 이메일인가요?

이메일 주소의 형식이 올바른지 확인하는 함수를 구현해 봅니다. 올바른 이메일은 **하나의 `@`**를 포함하고, `@` 뒤쪽 부분(도메인)은 **최소 한 개 이상의 `.`**을 포함하며, **연속된 `.`**을 가질 수 없습니다. (도메인이 `.`으로 시작하거나 끝나는 것도 안 됩니다. 즉 도메인을 `.`으로 `split`했을 때 빈 문자열이 없어야 합니다.)

## 지시사항
1. `validate_email(email)` 함수를 완성하세요. 조건을 만족하면 `True`, 아니면 `False`를 반환합니다.
2. `email.count('@')`로 `@`가 정확히 하나인지 확인하세요.
3. `email.split('@')[1]`로 도메인을 추출하고, `domain.count('.')`가 1개 이상인지 확인하세요.
4. 연속된 `.`이 없는지 확인하는 부분은 이미 완성돼 있습니다. 코드를 이해해 보세요.
5. 메인 코드는 수정하지 마세요. (여러 줄의 이메일을 입력받아 한 줄씩 결과를 출력합니다.)

## 시작 코드
```python
def validate_email(email):
    # 주소가 하나의 @을 포함하는지 확인합니다.


    # 주소에서 도메인을 추출합니다.
    domain = None

    # 도메인이 하나 이상의 점을 포함하는지 확인합니다.


    # 도메인을 점 기준으로 쪼개고, 연속하는 점이 없는지 확인합니다.
    # 아래의 코드는 완성되어 있습니다. 코드를 이해해 보세요.
    parts = domain.split(".")
    for part in parts:
        if part == "":
            return False

    return True


# 아래 코드는 수정하지 마세요.
n = int(input())
for _ in range(n):
    print(validate_email(input()))
```

## 입력 예시 1
```
4
elice@elice.io
elice@@elice.io
elice@eliceio
elice@elice..io
```
## 출력 예시 1
```
True
False
False
False
```

## Tips
`"a..b".split(".")`은 `['a', '', 'b']`가 되므로 빈 문자열이 있으면 연속된 점이 있다는 뜻이에요.

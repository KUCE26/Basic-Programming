# [8차시 과제1] 타격왕이 될거야

야구에서 타율은 안타를 타수로 나눈 비율입니다. 8타수 5안타라면 5/8 = 0.625로 **6할 2푼 5리**라고 읽습니다. 야구선수 엘리스 토끼의 현재 타율은 **16타수 6안타**입니다. 이후의 타수와 안타가 입력으로 주어질 때 엘리스 토끼의 타율을 할푼리로 출력해 보세요.

## 지시사항
1. 0 이상의 정수인 타수와 안타를 한 줄씩 입력받으세요. (안타는 타수보다 많지 않습니다.)
2. 16타수 6안타인 상태에서 입력받은 타수와 안타를 더한 타율을 구하세요.
3. 구한 타율을 **할, 푼, 리**를 한 줄에 하나씩 출력하세요. 소수점 넷째 자리 이하는 버리고, 값이 0인 자리는 출력하지 않습니다. (0.101 → `1할`, `1리`)

## 입력 예시 1
```
3
2
```
## 출력 예시 1
```
4할
2푼
1리
```

## 입력 예시 2
```
5
2
```
## 출력 예시 2
```
3할
8푼
```

## Tips
타율 × 1000을 정수로 만든 뒤 `//`와 `%`로 자리를 나누면 편해요. (0.421 → 421 → 4, 2, 1)

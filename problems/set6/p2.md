# [4차시 과제2] 음식 가격 계산하기

교장 선생님인 엘리스 토끼는 150명의 학생을 이끌고 수학여행을 가게 되었습니다. 휴게소에서 밥을 먹으려고 메뉴를 미리 골랐더니 한식 55명, 중식 43명, 양식 52명으로 나왔습니다. 한식은 7,000원, 중식은 6,000원, 양식은 8,500원이고, 휴게소에서 **한식은 10% 할인**해 줍니다.

## 지시사항
1. `korean`, `chinese`, `western` 변수에 각 메뉴의 가격을 넣으세요.
2. `discount_korean` 변수에 10% 할인된 한식 가격을 저장하세요. (정수가 되도록 `int()`로 바꾸거나 `7000 - 700`처럼 계산하세요.)
3. `total_price` 변수에 모든 학생이 고른 메뉴의 전체 예산을 계산해 저장하세요.
4. 출력 코드는 수정하지 마세요.

## 시작 코드
```python
# 한식 가격
korean = None

# 중식 가격
chinese = None

# 양식 가격
western = None

# 할인된 한식의 가격
discount_korean = None

# 전체 예산을 계산하여 저장해 보세요.
total_price = None

# 값을 확인해 보세요! 아래는 수정하지 마세요.
print("한식 : " + str(korean))
print("중식 : " + str(chinese))
print("양식 : " + str(western))
print("할인된 한식 : " + str(discount_korean))
print("전체 예산 : " + str(total_price))
```

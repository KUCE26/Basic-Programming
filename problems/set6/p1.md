# [4차시 과제1] 사칙 연산자 이해하기

파이썬의 사칙연산은 수학과 같습니다. 덧셈 `+`, 뺄셈 `-`, 곱셈 `*`, 나눗셈 `/`, 괄호 `()`는 먼저 계산, 거듭제곱은 `**`로 씁니다 (2의 3제곱은 `2**3`).

## 지시사항
1. `ret1`에 a와 b를 더한 값을 저장하세요.
2. `ret2`에 a에서 b를 뺀 값을 저장하세요.
3. `ret3`에 a와 b를 곱한 값을 저장하세요.
4. `ret4`에 a를 b로 나눈 값을 저장하세요.
5. `ret5`에 a의 b제곱을 저장하세요.
6. `ret6`에 `a + a * b / a`를 저장하세요.
7. `ret7`에 (a + b)와 (a - b)를 곱한 값을 저장하세요.
8. `ret8`에 b의 a제곱에 a를 곱한 값을 저장하세요.
9. 8개의 변수를 출력하는 코드는 이미 있습니다. 수정하지 마세요.

## 시작 코드
```python
# 아래 내용은 수정하지 마세요.
a = int(input())
b = int(input())

# 아래 8개의 변수에 지시사항에서 요구하는 사칙연산을 수행해 보세요.
ret1 = None
ret2 = None
ret3 = None
ret4 = None
ret5 = None
ret6 = None
ret7 = None
ret8 = None

# 아래는 출력을 위한 코드입니다. 수정하지 마세요.
print(ret1)
print(ret2)
print(ret3)
print(ret4)
print(ret5)
print(ret6)
print(ret7)
print(ret8)
```

## 입력 예시 1
```
2
4
```
## 출력 예시 1
```
6
-2
8
0.5
16
6.0
-12
32
```

## Tips
엘리스 원본은 `a = 2, b = 4`로 고정돼 있어요. 여기서는 여러 값으로 채점하려고 입력으로 받습니다.

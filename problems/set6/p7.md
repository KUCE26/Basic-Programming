# [4차시 과제7] 문자열에서 좌우 공백 제거하기

`lstrip()`은 문자열의 왼쪽 공백을, `rstrip()`은 오른쪽 공백을, `strip()`은 양쪽 공백을 모두 제거한 **새로운 문자열**을 돌려줍니다.

## 지시사항
1. 한 줄을 입력받아 `txt`에 저장하세요. (입력 줄의 앞뒤에 공백이 있을 수 있어요.)
2. `txt`의 왼쪽 공백을 제거한 후 `ret1`에 저장하세요.
3. `txt`의 오른쪽 공백을 제거한 후 `ret2`에 저장하세요.
4. `txt`의 왼쪽·오른쪽 공백을 제거한 후 `ret3`에 저장하세요.
5. 출력 코드는 수정하지 마세요.

## 시작 코드
```python
# 한 줄을 입력받습니다. 수정하지 마세요.
txt = input()

# 1. txt 문자열의 왼쪽 공백을 제거한 후 ret1에 저장하세요.
ret1 = None

# 2. txt 문자열의 오른쪽 공백을 제거한 후 ret2에 저장하세요.
ret2 = None

# 3. txt 문자열의 왼쪽, 오른쪽 공백을 제거한 후 ret3에 저장하세요.
ret3 = None

# 아래는 출력을 위한 코드입니다. 수정하지 마세요.
print("ret1 : " + "<" + ret1 + ">")
print("ret2 : " + "<" + ret2 + ">")
print("ret3 : " + "<" + ret3 + ">")
```

## 입력 예시 1
```
  양쪽에 공백이 있는 문자열입니다.     
```
## 출력 예시 1
```
ret1 : <양쪽에 공백이 있는 문자열입니다.     >
ret2 : <  양쪽에 공백이 있는 문자열입니다.>
ret3 : <양쪽에 공백이 있는 문자열입니다.>
```

## Tips
입력 예시의 앞뒤 공백은 보이지 않지만 들어 있어요. `입력` 탭에서 직접 공백을 넣어 실행해 보세요.

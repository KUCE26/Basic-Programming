# [4차시 과제5] 음식 궁합

음식마다 영양분이 달라서 궁합이 좋은 음식을 같이 먹으면 시너지가 납니다. 좋은 음식 궁합은 **치즈와 달걀**, **고구마와 김치**, **감자와 토마토**입니다. 입력으로 여러 음식이 공백을 기준으로 주어질 때, 좋은 궁합이 입력에 포함되어 있는지 확인해 봅시다.

## 지시사항
1. 여러 음식들을 공백을 기준으로 입력받으세요.
2. 입력된 음식 리스트에 궁합이 좋은 두 음식이 **하나라도 같이** 있다면 `True`, 그렇지 않으면 `False`를 출력하세요.

## 입력 예시 1
```
치즈 피자 달걀 우유
```
## 출력 예시 1
```
True
```

## 입력 예시 2
```
고구마 치즈 토마토
```
## 출력 예시 2
```
False
```

## Tips
`x = input().split()`으로 리스트를 만들고, `'치즈' in x and '달걀' in x`처럼 `in`과 `and`, `or`를 조합하세요.

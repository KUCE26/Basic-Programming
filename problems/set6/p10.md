# [8차시 과제2] 약수 찾기

정수가 어떤 수로 나누어 떨어질 때 그 수를 약수라고 합니다. 4의 약수는 1, 2, 4이고 12의 약수는 1, 2, 3, 4, 6, 12입니다. 어떤 수를 입력받았을 때 그 수의 약수들을 출력하는 코드를 작성해 봅시다.

## 지시사항
1. 자연수 N(2 이상 100,000 이하)을 입력받습니다.
2. 약수를 작은 수부터 한 줄에 10개씩, 한 칸씩 띄워서 출력합니다. 약수를 출력할 때마다 뒤에 공백을 붙이고(`print(i, end=" ")`), 10개를 출력하면 `print()`로 줄을 바꿉니다.

## 입력 예시 1
```
120
```
## 출력 예시 1
```
1 2 3 4 5 6 8 10 12 15
20 24 30 40 60 120
```

## 입력 예시 2
```
7
```
## 출력 예시 2
```
1 7
```

## Tips
채점은 줄 끝 공백을 무시하므로 마지막 공백은 신경 쓰지 않아도 돼요. 몇 개를 출력했는지 세는 변수(`count`)를 두고 `count % 10 == 0`일 때 줄을 바꾸세요.

# [8차시 과제6] 가장 큰 차이 구하기

리스트의 원소 중 두 개를 뽑았을 때 두 원소의 차이가 가장 크게 하려고 합니다. 그때 두 원소의 차이를 출력해 보세요. 단, 크기가 같은 원소가 있을 수 있습니다.

## 지시사항
1. 한 줄에 하나씩 주어지는 정수 5개를 리스트에 저장하세요.
2. 리스트 내 두 원소의 가장 큰 차이(최댓값 − 최솟값)를 출력하세요.

## 입력 예시 1
```
4
9
38
75
17
```
## 출력 예시 1
```
71
```

## 입력 예시 2
```
1
1
1
1
1
```
## 출력 예시 2
```
0
```

## Tips
`for`로 5번 `int(input())`을 받아 `append`하고, `max()`와 `min()`을 쓰세요.

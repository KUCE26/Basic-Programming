# [4차시 과제3] 과일 장수

과일 장수 엘리스 토끼는 가게를 운영하던 중 과일이 아닌 채소를 판매하고 있던 것을 알아차렸습니다. `fruits` 리스트에는 엘리스 토끼가 판매하는 것들이 담겨 있습니다. 판매 목록에서 채소를 제거해 주세요.

## 지시사항
1. 공백으로 구분된 입력으로 만들어지는 리스트 `fruits`에서 과일이 아닌 **콩**과 **무**를 제거하세요.
2. (참고) 채소는 콩과 무만 판매 중이고, 입력에 콩과 무가 각각 한 번씩 들어 있다고 가정합니다.
3. 제거한 뒤 `fruits` 리스트를 그대로 출력하세요 (출력 코드는 이미 있습니다).

## 시작 코드
```python
# 과일들을 입력받는 코드입니다. 수정하지 마세요!
fruits = list(input().split())

# 리스트 fruits에서 '콩'과 '무'를 제거해 주세요.


# 과일이 아닌 것을 잘 제거했는지 확인해봅시다.
print(fruits)
```

## 입력 예시 1
```
사과 오렌지 딸기 콩 무
```
## 출력 예시 1
```
['사과', '오렌지', '딸기']
```

## 입력 예시 2
```
콩 바나나 무 포도
```
## 출력 예시 2
```
['바나나', '포도']
```

## Tips
`리스트.remove(값)`은 그 값을 하나 지웁니다.

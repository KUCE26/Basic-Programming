# [4차시 과제8] 문자열 포맷팅 이해하기

`%s`(문자열), `%d`(정수) 포맷 문자열과 `%` 연산자로 문장을 만들어 보세요. `%` 기호 자체를 출력하려면 `%%`를 씁니다.

## 지시사항
0. 두 줄로 문자열 `txt1`, `txt2`를, 다음 두 줄로 정수 `num1`, `num2`를 입력받습니다 (입력 코드는 이미 있습니다).
1. 포맷 문자열을 이용해 `"나는 자바보다 파이썬에 더 익숙합니다."`를 출력하세요. (txt1, txt2 사용)
2. 포맷 문자열을 이용해 `"파이썬은 자바보다 10배 더 쉽습니다."`를 출력하세요. (txt2, txt1, num2 사용. 조사는 `은`으로 고정)
3. 포맷 문자열과 위 변수만을 이용해 `"5 + 10 = 15"`를 출력하세요.
4. 포맷 문자열을 이용해 `"작년 세계 경제 성장률은 전년에 비해 5% 포인트 증가했다."`를 출력하세요. (num1 사용)

## 시작 코드
```python
# 실습에 사용할 변수를 입력받습니다. 수정하지 마세요.
txt1 = input()
txt2 = input()
num1 = int(input())
num2 = int(input())

# 1. 포맷 문자열을 이용해 "나는 자바보다 파이썬에 더 익숙합니다."를 출력해 보세요.


# 2. 포맷 문자열을 이용해 "파이썬은 자바보다 10배 더 쉽습니다."를 출력해 보세요.


# 3. 포맷 문자열과 위 변수만을 이용해 "5 + 10 = 15"를 출력해 보세요.


# 4. 포맷 문자열을 이용해 "작년 세계 경제 성장률은 전년에 비해 5% 포인트 증가했다."를 출력해 보세요.

```

## 입력 예시 1
```
자바
파이썬
5
10
```
## 출력 예시 1
```
나는 자바보다 파이썬에 더 익숙합니다.
파이썬은 자바보다 10배 더 쉽습니다.
5 + 10 = 15
작년 세계 경제 성장률은 전년에 비해 5% 포인트 증가했다.
```

## 입력 예시 2
```
C
Python
3
2
```
## 출력 예시 2
```
나는 C보다 Python에 더 익숙합니다.
Python은 C보다 2배 더 쉽습니다.
3 + 2 = 5
작년 세계 경제 성장률은 전년에 비해 3% 포인트 증가했다.
```

## Tips
값이 여러 개면 `"%s와 %d" % (a, b)`처럼 튜플로 넘깁니다.

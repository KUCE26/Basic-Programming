# [4차시 과제4] 리스트 원소 정렬

리스트 안의 원소를 정렬하려면 `리스트이름.sort()`를 씁니다. 숫자는 오름차순, 문자열은 사전순으로 정렬됩니다.

```python
my_list = ['banana', 'apple', 'carrot']
my_list.sort()
print(my_list)   # ['apple', 'banana', 'carrot']
```

## 지시사항
1. 한 줄로 주어지는 정수들을 공백 기준으로 입력받아 정수 리스트 `my_list`를 만드세요.
2. `my_list`를 오름차순으로 정렬하세요.
3. 정렬한 `my_list`를 출력하세요.

## 입력 예시 1
```
5 4 3 2
```
## 출력 예시 1
```
[2, 3, 4, 5]
```

## 입력 예시 2
```
10 1 100 7 7
```
## 출력 예시 2
```
[1, 7, 7, 10, 100]
```

## Tips
엘리스 원본은 `[5, 4, 3, 2]`를 직접 만들어 정렬하는 문제예요. 정수 리스트는 `list(map(int, input().split()))` 또는 반복문으로 만들 수 있어요. 문자열인 채로 정렬하면 `'10'`이 `'7'`보다 앞에 오니 주의!

## 17차시 [실습2] 거꾸로 계산! (lecturepages/55662977, 13/18)

"나는 자연수 중 하나를 생각하고 있어. 그리고 그 수에서 829176을 더하고, 4927819를 뺀 다음, 243을 곱하고 1024로 나눴어. 그랬더니 23571이라는 수가 나오더라구!"

지시사항:

- num3이라는 실수형 변수를 하나 선언하고, 이전 값에 243을 나눈 값을 넣어줍시다.
- num4이라는 실수형 변수를 하나 선언하고, 이전 값에 4927819을 더한 값을 넣어줍시다.
- answer이라는 실수형 변수를 하나 선언하고, 이전 값에 829176을 뺀 값을 넣어줍시다.
- 체셔에게 외쳐봅시다. 체셔가 생각한 답은 answer야!

## 17차시 [실습3] BMI 계산하기 (55662978, 14/18)

BMI는 체질량 지수라는 뜻으로 키와 몸무게만으로 계산할 수 있습니다. 키가 h(m), 몸무게가 w(kg)일 때 BMI는 w / h^2 으로 계산합니다.
키와 몸무게 정보를 입력받고, 입력받은 키와 몸무게를 이용해 BMI를 계산해서 출력해 봅시다!

지시사항:
- 입력 예시를 참고하여 순서대로 실수(double)형 값인 키(cm 단위)와 몸무게(kg 단위)를 입력받습니다.
- 입력받은 값을 이용해 위의 공식을 적용하여 BMI를 계산하고 소수점 5자리까지 출력해 보세요. 예를 들어 BMI 값이 23.333333… 이라면 `23.33333`
입력 예시: `158.9` / `50.5`  → 출력 예시: `20.00063`
Tips: 단위에 주의하세요! 입력되는 키는 cm 단위, BMI 공식에는 m 단위로 사용되고 있습니다.

## 18차시 [실습1] if 조건문 사용해보기 (lectures/6781517/lecturepages/55662997, 9/15)

if 조건문의 사용법: `if (조건) { 명령문; }` — () 괄호 안에 조건의 결과 값이 참으로 나오면 {} 괄호 안에 있는 명령문을 수행합니다. 여기에서 참은 0이 아닌 모든 값을 의미합니다.
지시사항:
- scanf() 함수를 사용해서 정수형 변수 num에 값을 입력 받습니다.
- if 조건문을 사용해서 num의 값이 5보다 크거나 같다면 "입력 받은 수은(는) 5보다 크거나 같습니다."라는 문장을 출력합니다.
- if 조건문을 다시 한번 사용해서 num의 값이 5보다 작다면 "입력받은 수은(는) 5보다 작습니다." 라는 문장을 출력합니다.
입력 예시 1: `10` → `10은(는) 5보다 크거나 같습니다.`
입력 예시 2: `3` → `3은(는) 5보다 작습니다.`
시작 코드:
```c
#include <stdio.h>
int main(void) {
    int num;
    // 1. scanf 함수를 이용해 값을 입력 받습니다.

    // 2. 괄호 안에 올바른 조건을 채워 넣습니다.
    if () {
        printf("%d은(는) 5보다 크거나 같습니다.", num);
    }
    // 3. 반대의 경우도 있겠죠? 5보다 작은 경우도 채워 넣습니다.

    return 0;
}
```

## 18차시 [실습2] 금도끼, 은도끼! (55662998, 10/15)

if-else: `if (조건) { 명령문 A } else { 명령문 B }` — 조건을 만족하면 A, 아니라면 B. else는 반드시 if 문과 함께.
지시사항:
- 최대 길이 10의 문자열을 입력받을 수 있도록 문자열 변수 axe를 선언하고 사용자로부터 문자열을 입력받아 저장하세요.
- if문을 사용하여 axe에 저장된 값이 gold일때 "제 도끼입니다!" 를 출력하도록 합니다. 문자열이 동일한지 확인하기 위해서는 string.h 헤더의 strcmp 함수를 활용할 수 있습니다.
- else문을 사용하여 "gold"가 아니라면 "제 도끼가 맞는 거 같기도 하고... 아닌 거 같기도 하고..." 를 출력하도록 합니다.
입력 예시 1: `silver` → `제 도끼가 맞는 거 같기도 하고... 아닌 거 같기도 하고...`
입력 예시 2: `gold` → `제 도끼입니다!`
Tips: 선언한 문자열 변수의 최대 길이를 벗어나는 경우, 어떠한 결과가 나오는지 확인해보세요. 지시한 출력문 외에 다른 출력문이 포함되지 않아야 합니다.
(→ char 배열 문자열 + scanf("%s") + strcmp 는 18차시에서 이미 사용. 단, 배열 인덱싱·반복은 아직 아님.)

## 18차시 [실습5] 논리연산자와 조건문 (55663001, 13/15)

- 엘리스 토끼의 3개 과목의 점수(double형)가 아래 입력 예시와 같이 공백을 기준으로 순서대로 입력됩니다.

## 18차시 [실습6] 점심 메뉴 정하기 (55663002, 14/15)

| 약어 | 메뉴명 | 출력 문장 |  j 짜장면 "점심은 짜장면!" / b 뼈다귀 해장국 "점심은 뼈다귀 해장국!" / p 피자 "점심은 피자!" / h 햄버거 "점심은 햄버거!" / g 김밥 "점심은 김밥!"

지시사항:
- 사용자로부터 점심 메뉴의 약어를 입력받아 문자형 변수 choice 에 저장합니다.
- switch 문을 사용하여 입력된 약어에 따른 올바른 출력 문장을 화면에 출력하세요.
입력 예시 1: `j` → `점심은 짜장면!`
입력 예시 2: `l` → `그런 메뉴는 없습니다.`
Tips: break 문이 실행되면 switch 문의 실행이 종료됩니다.

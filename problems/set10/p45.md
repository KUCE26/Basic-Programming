# 버섯 크기 변환기

앨리스가 먹는 버섯의 크기 변화를 기록한 배열에 같은 변환을 한꺼번에 적용하려 합니다. 변환 종류는 호출할 때 정하도록 함수 포인터를 매개변수로 넘기세요.

## 지시사항
1. 시작 코드의 `square`(제곱), `negate`(부호 반대), `half`(2 로 나눈 몫, C 의 정수 나눗셈 그대로 0 쪽으로 버림)를 완성하세요.
2. `void apply(int arr[], int n, int (*op)(int))` 를 작성하세요. 배열의 모든 원소를 `op` 를 적용한 결과로 바꿉니다. 원소는 포인터를 증가시키며 순회하세요.
3. 먼저 변환 번호를 입력받으세요. 1 은 `square`, 2 는 `negate`, 3 은 `half` 입니다. 1~3 이 아니면 `잘못된 선택입니다.` 한 줄만 출력하고, 뒤에 오는 입력은 읽지 않고 끝냅니다.
4. 올바른 번호이면 다음 줄에서 정수 `n`(1 이상 10 이하), 다음 줄에서 n 개의 정수(-100 이상 100 이하)를 입력받으세요.
5. `apply` 로 변환한 뒤, 첫 줄에 변환된 값을 공백 한 칸으로 구분해 출력하고(마지막 값 뒤에는 공백이 없음), 둘째 줄에 `합계: ○` 를 출력하세요.

## Tips
`op(*p)` 의 결과를 `*p` 에 다시 저장하면 원소가 바뀝니다. 변환 번호에 맞는 함수 이름을 `apply` 의 세 번째 인자로 그대로 넘기세요. `-7 / 2` 는 `-3` 입니다.

# 입장 번호 실시간 정렬

정원 입구에서 들어오는 손님이 번호표를 하나씩 냅니다. 문지기는 번호표가 한 장 들어올 때마다 지금까지의 번호표를 qsort 로 작은 순서로 다시 정렬해 칠판에 적습니다.

## 지시사항
1. 1 이상 10000 이하의 정수를 한 줄에 하나씩 입력받습니다. 0 이 입력되면 입력을 마칩니다. 0 을 제외한 숫자는 최대 15 개이며, 숫자를 저장할 배열은 크기 15 로 선언하세요.
2. 0 이 아닌 숫자가 입력될 때마다 배열에 추가한 뒤, 지금까지 입력된 숫자 전체를 `qsort` 로 오름차순 정렬하세요. 비교 함수는 `int cmp(const void *a, const void *b)` 형태로 직접 작성하세요.
3. 숫자가 추가될 때마다 `추가 ○ -> ` 다음에 정렬된 배열 전체를 공백 한 칸으로 구분해 한 줄로 출력하세요. `○` 는 방금 입력된 숫자입니다.
4. 0 이 입력되어 끝난 뒤, 마지막 줄에 `최댓값과 최솟값의 차: ○` 를 출력하세요.
5. 단, 입력된 숫자가 하나도 없이 바로 0 이 들어왔다면 아무것도 정렬하지 않고 `입력 없음` 한 줄만 출력하세요.


## 출력 예시 1
```

추가 1 -> 1 5

추가 4 -> 1 2 4 5
추가 8 -> 1 2 4 5 8
최댓값과 최솟값의 차: 7
```

```

최댓값과 최솟값의 차: 20
```

## Tips
`qsort(arr, m, sizeof(arr[0]), cmp);` 에서 두 번째 인자는 지금까지 저장한 숫자의 개수 m 이어야 합니다. 배열 전체(15)를 넘기면 쓰레기 값이 섞입니다. 비교 함수 안에서는 `void *` 를 `*(const int *)a` 처럼 `int` 로 바꿔서 값을 꺼내 비교합니다.

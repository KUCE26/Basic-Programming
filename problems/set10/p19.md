# 기온 기록원

토끼 기상대의 기록원이 측정한 기온을 차례로 입력합니다. 측정이 끝나면 -999 를 입력해 알립니다. 기록을 정리해 주세요.

## 지시사항
1. 기온(정수)을 `while` 문으로 계속 입력받으세요. 기온은 -50 이상 60 이하이며, `-999` 가 입력되면 입력이 끝납니다. `-999` 는 기록에 포함하지 않으며, 첫 입력이 `-999` 인 경우는 없습니다.
2. 첫째 줄에 `측정 횟수: ○회` 를 출력하세요.
3. 둘째 줄부터 최고 기온, 최저 기온, 둘의 차이를 `최고: [○○○○○]`, `최저: [○○○○○]`, `차이: [○○○○○]` 형식으로 출력하세요. 대괄호 안은 모두 폭 5 로 오른쪽 정렬입니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
21
25
19
25
-999
```
## 출력 예시 1
```
측정 횟수: 4회
최고: [   25]
최저: [   19]
차이: [    6]
```

## 입력 예시 2
```
-3
-8
-999
```
## 출력 예시 2
```
측정 횟수: 2회
최고: [   -3]
최저: [   -8]
차이: [    5]
```

## Tips
최댓값·최솟값의 초기값을 0 으로 두면 기온이 모두 음수이거나 모두 양수일 때 틀립니다. 첫 번째 입력값으로 초기화하는 방법을 생각해 보세요.

# 제곱수 전광판

엘리스 토끼 광장의 전광판이 1 부터 n 까지의 제곱수를 보여 주고, 홀수·짝수 번호의 제곱수를 따로 모아 합을 알려 줍니다.

## 지시사항
1. `int n` (1 이상 30 이하)을 입력받으세요.
2. `for` 문으로 1 부터 n 까지 한 줄에 하나씩 `[번호] 제곱수` 형태로 출력하세요. 번호는 폭 2, 제곱수는 폭 4 로 오른쪽 정렬하고 대괄호와 제곱수 사이에는 공백 한 칸을 둡니다. 번호가 홀수인 줄은 끝에 공백 한 칸과 `*` 를 붙입니다.
3. 홀수 번호의 제곱수들의 합과 짝수 번호의 제곱수들의 합을 구할 때는, 누적식에 삼항 연산자를 사용하세요.
4. 반복이 끝난 뒤 `홀수 제곱합: ○`, `짝수 제곱합: ○` 를 한 줄씩 출력하세요. n 이 1 이면 짝수 제곱합은 0 입니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
5
```
## 출력 예시 1
```
[ 1]    1 *
[ 2]    4
[ 3]    9 *
[ 4]   16
[ 5]   25 *
홀수 제곱합: 35
짝수 제곱합: 20
```

## 입력 예시 2
```
1
```
## 출력 예시 2
```
[ 1]    1 *
홀수 제곱합: 1
짝수 제곱합: 0
```

## Tips
`sum += (조건) ? 값1 : 값2;` 형태로 쓸 수 있습니다. 번호가 홀수인지는 2 로 나눈 나머지로 판단합니다.

# 번호표 뽑기

엘리스 토끼가 은행에서 번호표를 뽑습니다. 번호를 한 장 쓸 때마다 번호가 하나씩 올라가는데, 올리고 나서 쓰는지 쓰고 나서 올리는지에 따라 값이 달라집니다.

## 지시사항
1. 정수 하나를 입력받아 `int n` 에 저장하세요. (-100 이상 100 이하)
2. `printf` 를 네 번 따로 써서, 아래 순서대로 한 줄씩 출력하세요. 한 `printf` 안에서 같은 변수를 두 번 이상 바꾸지 마세요.
   - `후위: ○` : 후위 증가(`n++`) 의 값을 출력
   - `이후: ○` : 그 직후의 `n`
   - `전위: ○` : 전위 증가(`++n`) 의 값을 출력
   - `이후: ○` : 그 직후의 `n`
3. 정수 `m` 에 `n` 의 후위 감소 값의 2 배를 저장하세요(`n--` 을 곱셈 식 안에서 사용). 그 뒤 `m: ○, n: ○` 형식으로 출력하세요.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
5
```
## 출력 예시 1
```
후위: 5
이후: 6
전위: 7
이후: 7
m: 14, n: 6
```

## 입력 예시 2
```
-3
```
## 출력 예시 2
```
후위: -3
이후: -2
전위: -1
이후: -1
m: -2, n: -2
```

## Tips
`n++` 는 현재 값을 쓰고 나서 1 을 올리고, `++n` 은 1 을 올리고 나서 그 값을 씁니다. 한 식 안에서 같은 변수를 여러 번 바꾸면 결과가 정해져 있지 않으니 피하세요.

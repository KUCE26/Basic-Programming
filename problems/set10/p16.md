# 주차 요금 영수증

토끼 주차장은 30분까지 무료이고, 그 뒤로는 10분 단위로 요금을 받습니다. 이용 시간과 회원 여부를 입력받아 영수증을 출력해 주세요.

## 지시사항
1. 이용 시간(분, 1 이상 1000 이하 정수)과 회원 여부(`Y` 또는 `N` 한 글자)를 한 줄에 공백으로 구분해 입력받아 `int minutes`, `char member` 에 저장하세요.
2. 30분 이하는 요금이 0원입니다. 30분을 넘으면 넘은 시간을 10분 단위로 올림하여 단위마다 500원입니다. 단, 요금은 최대 15000원입니다.
3. `member` 가 `Y` 이면 요금의 20%를 할인한 금액을, `N` 이면 요금 그대로를 결제 금액(`double`)으로 합니다.
4. 세 줄을 출력하세요. `이용 시간: [○○○○○]분`(폭 5), `주차 요금: [○○○○○○○○]원`(폭 8, 정수), `결제 금액: [○○○○○○○○○○]원`(폭 10, 소수점 첫째 자리까지). 모두 오른쪽 정렬입니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
90 Y
```
## 출력 예시 1
```
이용 시간: [   90]분
주차 요금: [    3000]원
결제 금액: [    2400.0]원
```

## 입력 예시 2
```
45 N
```
## 출력 예시 2
```
이용 시간: [   45]분
주차 요금: [    1000]원
결제 금액: [    1000.0]원
```

## Tips
정수 나눗셈은 소수점 아래를 버리므로, 10분 단위 올림은 나누기 전에 적당한 값을 더하면 만들 수 있습니다. 공백으로 구분된 문자는 `"%d %c"` 로 읽을 수 있습니다.

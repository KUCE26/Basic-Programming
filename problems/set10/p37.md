# 버블 정렬 회차별 기록

토끼 서기는 버블 정렬이 한 회차를 마칠 때마다 카드가 어떻게 놓였는지 장부에 적고, 카드를 몇 번 맞바꿨는지도 센다고 합니다.

## 지시사항
1. 정수 `n` 을 입력받으세요. n 은 2 이상 8 이하입니다. 이어서 n 개의 정수(-100 이상 100 이하)를 입력받아 크기 8 의 배열에 저장하세요.
2. 버블 정렬(오름차순)을 직접 구현하세요. 바깥 반복 `i` 는 0 부터 n-2 까지, 안쪽 반복 `j` 는 0 부터 n-2-i 까지이며, 안쪽에서는 `arr[j]` 가 `arr[j+1]` 보다 **클 때만**(같으면 바꾸지 않음) 두 값을 맞바꿉니다. 이미 정렬되어 있어도 중간에 멈추지 말고 바깥 반복을 끝까지 수행합니다.
3. 바깥 반복이 한 번 끝날 때마다(회차가 끝날 때마다) `○회차: ` 다음에 현재 배열 전체를 공백 한 칸으로 구분해 한 줄로 출력하세요. 회차 번호는 1 부터 시작하며 총 n-1 줄이 나옵니다.
4. 모든 회차를 마친 뒤 `교환 횟수: ○` 를 출력하세요. 실제로 두 값을 맞바꾼 횟수의 합계입니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
5
5 1 4 2 8
```
## 출력 예시 1
```
1회차: 1 4 2 5 8
2회차: 1 2 4 5 8
3회차: 1 2 4 5 8
4회차: 1 2 4 5 8
교환 횟수: 4
```

## 입력 예시 2
```
4
3 3 3 3
```
## 출력 예시 2
```
1회차: 3 3 3 3
2회차: 3 3 3 3
3회차: 3 3 3 3
교환 횟수: 0
```

## Tips
교환 횟수는 `if` 안에서 값을 바꿀 때만 1 씩 늘립니다. 회차 출력은 안쪽 반복이 끝난 직후, 바깥 반복 안에 둡니다.

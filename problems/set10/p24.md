# 알파벳 지그재그 탑

토끼가 알파벳 블록으로 탑을 쌓습니다. 줄마다 블록 수가 하나씩 늘고, 홀수 번째 줄은 올라가며, 짝수 번째 줄은 내려가며 쌓습니다.

## 지시사항
1. 시작 대문자 `char c` 와 줄 수 `int n` 을 한 줄에 공백으로 구분해 입력받으세요. n 은 1 이상 8 이하이고, 쓰이는 모든 문자는 `Z` 를 넘지 않습니다.
2. i 번째 줄(1 부터)에는 i 개의 문자를 출력합니다. i 가 홀수이면 c 부터 한 글자씩 뒤로 가며 i 개를, 짝수이면 (c + i - 1) 에 해당하는 문자부터 한 글자씩 앞으로 가며 c 까지 출력합니다.
3. 한 줄 안의 문자들은 하이픈(`-`) 하나로 구분하고, 줄 끝에는 하이픈을 붙이지 않습니다.
4. 모든 줄을 출력한 뒤 마지막 줄에 `아스키 합: ○` 를 출력하세요. 탑에 출력된 모든 문자의 아스키 코드 합입니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
C 4
```
## 출력 예시 1
```
C
D-C
C-D-E
F-E-D-C
아스키 합: 680
```

## 입력 예시 2
```
A 5
```
## 출력 예시 2
```
A
B-A
A-B-C
D-C-B-A
A-B-C-D-E
아스키 합: 995
```

## Tips
문자는 정수처럼 더하고 뺄 수 있습니다. 문자 입력은 앞 공백을 무시하도록 `" %c"` 로 받으세요. 하이픈은 '첫 글자가 아닐 때 글자 앞에' 출력하면 줄 끝에 남지 않습니다.

# 이름은 다섯 글자까지

엘리스 토끼의 명찰에는 이름을 최대 5글자만 새길 수 있습니다. `fgets` 로 이름을 읽으면 어떤 일이 생기는지 확인해 보세요.

## 지시사항
1. `char name[6];` 을 선언하고, `fgets(name, 6, stdin);` 로 한 줄을 입력받으세요. `fgets` 는 최대 5글자까지만 읽고 끝에 널 문자(`\0`)를 붙입니다.
2. `puts(name);` 으로 저장된 문자열을 출력하세요. `puts` 는 출력 뒤에 줄바꿈을 하나 더 붙입니다.
3. 그 다음 줄에 `끝` 을 출력하세요. (`printf("끝\n");`)
4. 동작에 주의하세요. 입력이 5글자를 넘으면 앞 5글자만 저장됩니다. 입력이 4글자 이하면 줄바꿈 문자(`\n`)까지 `name` 에 저장되므로, `puts` 가 줄바꿈을 한 번 더 해서 빈 줄이 생깁니다. 이 빈 줄도 출력의 일부입니다. 입력이 정확히 5글자면 줄바꿈은 저장되지 않아 빈 줄이 생기지 않습니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    char name[6];
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
Bob
```
## 출력 예시 1
```
Bob

끝
```

## 입력 예시 2
```
Elizabeth
```
## 출력 예시 2
```
Eliza
끝
```

## Tips
`fgets(name, 6, stdin)` 의 6은 널 문자 자리까지 센 크기라서 실제로는 5글자만 읽힙니다. 짧은 입력은 `\n` 이 함께 저장되고, 긴 입력은 남은 글자가 입력 버퍼에 그대로 남습니다.

# 거꾸로 읽어도 같은 말

체셔 고양이는 거꾸로 읽어도 똑같은 말을 좋아합니다. 단, 대문자와 소문자는 같은 글자로 봅니다.

## 지시사항
1. 공백 없는 영문·숫자 단어 하나를 입력받아 크기 101 인 전역 `char` 배열 `a` 에 저장하세요. 길이는 1 이상 100 이하입니다. 같은 크기의 전역 배열 `b` 도 하나 더 선언합니다.
2. 함수 `void lower(void)` 를 만들어 `a` 의 영문 대문자를 모두 소문자로 바꾸세요. 함수 `void reverse(void)` 를 만들어 `a` 를 거꾸로 뒤집은 문자열을 `b` 에 만드세요(끝에 널 문자를 잊지 마세요). 배열은 전역이므로 함수의 매개변수로 넘기지 않습니다.
3. `lower` 와 `reverse` 를 차례로 부른 뒤, 첫 줄에 소문자로 바꾼 `a` 를, 둘째 줄에 뒤집은 `b` 를 출력하세요.
4. 셋째 줄에 `strcmp` 로 `a` 와 `b` 를 비교해서 같으면 `회문입니다`, 다르면 `회문이 아닙니다` 를 출력하세요.

## 시작 코드
```c
#include <stdio.h>
#include <string.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
Level
```
## 출력 예시 1
```
level
level
회문입니다
```

## 입력 예시 2
```
Alice
```
## 출력 예시 2
```
alice
ecila
회문이 아닙니다
```

## Tips
뒤집은 문자열 `b` 의 `i` 번째 글자는 `a` 의 `n - 1 - i` 번째 글자입니다. 대소문자를 맞추지 않으면 `Level` 과 `leveL` 이 다르게 비교됩니다.

# 달력 한 줄 요약

토끼 달력 앱이 월을 입력하면 그 달의 일수와 계절을 알려 주려 합니다. 평년(2월 28일) 기준으로 만들어 보세요.

## 지시사항
1. 월(1 이상 12 이하의 정수)을 입력받아 `int month` 에 저장하세요.
2. `switch` 로 일수를 구해 `int days` 에 저장하세요. 31일: 1, 3, 5, 7, 8, 10, 12월 / 30일: 4, 6, 9, 11월 / 28일: 2월. 같은 결과를 내는 `case` 는 `break` 없이 이어서 쓰세요.
3. 또 다른 `switch` 안에서 계절 이름을 바로 `printf` 로 출력합니다. 봄은 3~5월, 여름은 6~8월, 가을은 9~11월, 겨울은 12, 1, 2월입니다.
4. 첫째 줄에 `○월: ○○일`, 둘째 줄에 `계절: ○` 를 출력하세요. 계절 자리에는 `봄`, `여름`, `가을`, `겨울` 중 하나가 들어갑니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
5
```
## 출력 예시 1
```
5월: 31일
계절: 봄
```

## 입력 예시 2
```
2
```
## 출력 예시 2
```
2월: 28일
계절: 겨울
```

## Tips
`case` 라벨을 여러 개 연달아 쓰고 마지막에만 문장과 `break` 를 두면 여러 값이 같은 처리를 공유합니다. 입력이 항상 1~12 이므로 남은 값들을 `default` 로 처리해도 됩니다.

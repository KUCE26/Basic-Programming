# 체셔의 체스 방석

체셔 고양이가 n × n 칸짜리 체스 무늬 방석을 짜고 있습니다. 칸 위치에 따라 두 가지 무늬가 번갈아 나옵니다.

## 지시사항
1. 방석 한 변의 칸 수 `int n` 을 입력받으세요. n 은 1 이상 9 이하입니다.
2. 행 번호 i 와 열 번호 j 를 각각 1 부터 n 까지 중첩 `for` 문으로 돌며, i + j 가 짝수인 칸은 `#`, 홀수인 칸은 `.` 으로 나타내세요. 삼항 연산자나 `if` 를 사용하세요.
3. 각 줄은 맨 앞에 행 번호를 폭 2 로 오른쪽 정렬해 쓰고 콜론(`:`)을 붙인 뒤, 이어서 칸마다 공백 한 칸과 무늬 문자 하나를 차례로 출력합니다. 줄이 끝나면 줄을 바꿉니다.
4. 모든 줄을 출력한 뒤 마지막 줄에 `# 개수: ○` 를 출력하세요. `#` 칸의 총 개수입니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
4
```
## 출력 예시 1
```
 1: # . # .
 2: . # . #
 3: # . # .
 4: . # . #
# 개수: 8
```

## 입력 예시 2
```
5
```
## 출력 예시 2
```
 1: # . # . #
 2: . # . # .
 3: # . # . #
 4: . # . # .
 5: # . # . #
# 개수: 13
```

## Tips
행 번호 부분이 한 자리 수여도 폭이 2 이므로 앞에 공백이 하나 붙습니다. `#` 의 개수는 무늬를 정하는 자리에서 세면 편합니다.

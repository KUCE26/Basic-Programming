# 토끼굴 지도 검색

토끼굴 지도에는 방마다 번호가 적혀 있습니다. 찾는 번호가 몇 번째 방들에 있는지 포인터 범위 검색으로 모두 찾아 주세요.

## 지시사항
1. `int *findFirst(int *begin, int *end, int target)` 을 작성하세요. 반열린 구간 `[begin, end)` 를 앞에서부터 보며 `target` 과 같은 첫 원소의 주소를 반환하고, 없으면 `NULL` 을 반환합니다. `end` 가 가리키는 곳은 읽지 않습니다.
2. 정수 `n`(1 이상 30 이하)을 입력받고, 다음 줄에서 n 개의 정수(-100 이상 100 이하)를 크기 30 의 배열에 저장하세요. 마지막 줄에서 찾을 정수 `target` 을 입력받으세요.
3. `findFirst` 를 반복 호출해 `target` 이 나오는 모든 원소를 찾으세요. 다음 검색은 방금 찾은 원소의 바로 다음 칸부터 시작합니다.
4. 첫 줄에 `발견 횟수: ○` 를 출력하세요. 한 번도 없으면 이 한 줄로 끝납니다.
5. 한 번이라도 있으면 둘째 줄에 `위치: ` 다음에 찾은 인덱스들(0 부터)을 공백 한 칸으로 구분해 앞에서부터 출력하고, 셋째 줄에 `첫 위치와 마지막 위치의 차이: ○` 를 출력하세요. ○ 는 처음 찾은 원소와 마지막으로 찾은 원소를 가리키는 두 포인터를 빼서 구합니다. 한 번만 발견되면 0 입니다.

## 시작 코드
```c
#include <stdio.h>

int *findFirst(int *begin, int *end, int target) {
    // 지시사항을 참고하여 완성하세요.
    return NULL;
}

int main(void) {
    int arr[30];
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
8
3 7 3 1 3 9 7 3
3
```
## 출력 예시 1
```
발견 횟수: 4
위치: 0 2 4 7
첫 위치와 마지막 위치의 차이: 7
```

## 입력 예시 2
```
5
1 2 3 4 5
9
```
## 출력 예시 2
```
발견 횟수: 0
```

## Tips
다음 검색 시작점 `q + 1` 이 `arr + n` 과 같아져도 괜찮습니다. 그때는 빈 구간이라 바로 `NULL` 이 반환되어야 합니다. 인덱스는 `q - arr` 입니다.

# 선택 정렬 단계별 기록

체셔 고양이는 선택 정렬로 카드를 정리하면서, 매 단계마다 카드를 실제로 맞바꿨는지 장부에 기록합니다.

## 지시사항
1. 정수 `n` 을 입력받으세요. n 은 2 이상 8 이하입니다. 이어서 n 개의 정수(-100 이상 100 이하)를 입력받아 크기 8 의 배열에 저장하세요.
2. 선택 정렬(오름차순)을 직접 구현하세요. 단계 `i` 는 0 부터 n-2 까지입니다. 각 단계에서 `arr[i]` 부터 `arr[n-1]` 까지 중 가장 작은 값의 위치 `m` 을 찾되, 값이 같은 원소가 여럿이면 **가장 먼저 나오는 위치**를 택합니다(더 작은 값이 나올 때만 위치를 바꿈).
3. `m` 이 `i` 와 다르면 `arr[i]` 와 `arr[m]` 을 맞바꾸고 교환 횟수를 1 늘립니다. `m` 이 `i` 와 같으면 아무것도 바꾸지 않고 교환 횟수에 넣지도 않습니다.
4. 매 단계가 끝날 때마다 `○단계: ` 다음에 현재 배열 전체를 공백 한 칸으로 구분해 출력하고, 이어서 공백 한 칸과 함께 맞바꿨으면 `(교환)`, 바꾸지 않았으면 `(유지)` 를 붙여 한 줄로 출력하세요. 단계 번호는 1 부터 시작합니다.
5. 모든 단계가 끝난 뒤 `교환 횟수: ○` 를 출력하세요.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
5
64 25 12 22 11
```
## 출력 예시 1
```
1단계: 11 25 12 22 64 (교환)
2단계: 11 12 25 22 64 (교환)
3단계: 11 12 22 25 64 (교환)
4단계: 11 12 22 25 64 (유지)
교환 횟수: 3
```

## 입력 예시 2
```
4
1 2 3 4
```
## 출력 예시 2
```
1단계: 1 2 3 4 (유지)
2단계: 1 2 3 4 (유지)
3단계: 1 2 3 4 (유지)
교환 횟수: 0
```

## Tips
안쪽 반복의 조건을 `arr[j] < arr[m]` 으로 두면 같은 값 중 가장 앞의 위치가 유지됩니다. `<=` 로 쓰면 뒤쪽 위치로 갱신되니 주의하세요.

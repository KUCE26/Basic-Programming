# 티파티 성적표

티파티 학교에서 시험을 본 손님들의 점수를 모아 합격 인원, 최고점, 평균을 성적표로 만들려 합니다.

## 지시사항
1. 손님 수 `int n` (1 이상 7 이하)을 입력받고, 이어서 점수 n 개(0 이상 100 이하 정수, 공백이나 줄바꿈으로 구분)를 반복문으로 입력받으세요.
2. 60점 이상이면 합격입니다. 합격한 손님 수를 세고, 최고점과 점수의 합을 구하세요.
3. 첫째 줄에 `합격: ○명`, 둘째 줄에 `최고점: ○` 를 출력하세요.
4. 셋째 줄에는 평균을 실수로 구해 `평균: [○○○○○○○]` 형식으로 출력하세요. 대괄호 안은 폭 7 으로 오른쪽 정렬하고 소수점 둘째 자리까지 나타냅니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
5
85 59 60 100 72
```
## 출력 예시 1
```
합격: 4명
최고점: 100
평균: [  75.20]
```

## 입력 예시 2
```
1
0
```
## 출력 예시 2
```
합격: 0명
최고점: 0
평균: [   0.00]
```

## Tips
정수끼리 나누면 소수점 아래가 버려집니다. 합을 `double` 로 바꿔서 나누세요. 최고점의 초기값은 어떤 점수보다 작거나 같아야 합니다.

# 쉼표로 나뉜 신체 정보

엘리스 토끼는 건강검진 결과를 `나이,키,혈액형` 순서로 쉼표를 넣어 한 줄로 받았습니다. 이를 읽어 보기 좋게 정리해 보세요.

## 지시사항
1. 입력은 `20,175.5,A` 꼴의 한 줄입니다. 나이(`int age`), 키(`double height`), 혈액형(`char blood`)을 `scanf("%d,%lf,%c", ...)` 로 한 번에 읽으세요. 형식 문자열의 쉼표가 입력의 쉼표와 짝을 이룹니다.
2. 아래 형식으로 세 줄을 출력하세요. 키는 소수점 첫째 자리까지 출력합니다.
   - `나이: ○○살`
   - `키: ○○○.○cm`
   - `혈액형: ○형`
3. 혈액형은 항상 대문자 알파벳 한 글자이고, 입력에 공백은 없습니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
20,175.5,A
```
## 출력 예시 1
```
나이: 20살
키: 175.5cm
혈액형: A형
```

## 입력 예시 2
```
31,162.8,O
```
## 출력 예시 2
```
나이: 31살
키: 162.8cm
혈액형: O형
```

## Tips
`%d` 와 `%lf` 는 숫자가 끝나는 곳에서 멈추므로 뒤의 `,` 는 형식 문자열에 적어 두면 건너뜁니다. `%c` 앞에는 공백이 없으니 따로 신경 쓸 것이 없습니다.

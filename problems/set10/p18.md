# 문자 열차

체셔 고양이의 문자 열차는 알파벳 대문자를 차례로 태우고 달립니다. Z 다음 역은 다시 A 입니다. 출발 문자와 칸 수를 입력받아 열차를 그려 주세요.

## 지시사항
1. 출발 문자 `char c` (대문자 `A`~`Z`)와 칸 수 `int n` (1 이상 30 이하)을 공백으로 구분해 입력받으세요.
2. `for` 문으로 출발 문자부터 알파벳 순서대로 n 개의 문자를 한 줄에 공백으로 구분해 출력하세요. 문자는 `Z` 다음에 `A` 로 돌아갑니다. 마지막 문자 뒤에는 공백을 두지 말고 줄을 바꾸세요.
3. 둘째 줄에 출력한 문자 중 모음(`A`, `E`, `I`, `O`, `U`)의 개수를 `모음 개수: ○` 로 출력하세요.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
A 5
```
## 출력 예시 1
```
A B C D E
모음 개수: 2
```

## 입력 예시 2
```
X 5
```
## 출력 예시 2
```
X Y Z A B
모음 개수: 1
```

## Tips
문자도 정수처럼 1 을 더해 다음 문자로 넘어갈 수 있습니다. 문자를 한 개 입력받을 때는 `" %c"` 처럼 앞에 공백을 두면 앞선 공백·개행을 건너뜁니다. 첫 문자 앞에는 공백이 없어야 하니 반복 횟수를 이용해 구분하세요.

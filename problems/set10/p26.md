# 최대공약수 · 최소공배수 계산기

체셔 고양이가 두 수의 최대공약수와 최소공배수를 척척 알려 줍니다. 유클리드 호제법을 재귀 함수로 구현해 보세요.

## 지시사항
1. 두 정수의 최대공약수를 구하는 `int gcd(int a, int b)` 를 **재귀 함수**로 정의하세요. 유클리드 호제법을 재귀 호출로 구현하세요.
2. 최소공배수를 반환하는 `int lcm(int a, int b)` 를 정의하세요. 반드시 `gcd()` 를 호출해서 구합니다. 두 함수의 원형은 `main()` 위에 선언하세요.
3. `main()` 에서 먼저 쌍의 개수 `n` 을 입력받고(1 ≤ n ≤ 5), 이어서 n 개의 쌍 `a b` 를 입력받으세요(1 ≤ a, b ≤ 100). 입력은 공백이나 줄바꿈으로 구분됩니다.
4. 각 쌍마다 한 줄씩 `[번호] ○와 ○: 최대공약수 ○, 최소공배수 ○` 를 출력하세요. 번호는 1 부터이며 대괄호 안에 붙여 씁니다. 최대공약수는 폭 3칸, 최소공배수는 폭 5칸으로 오른쪽 정렬합니다. 두 입력 수 자리는 폭 지정 없이 그대로 출력합니다.
5. 모든 쌍을 처리한 뒤 마지막 줄에 `최대공약수의 합: ○` 를 출력하세요.

## 시작 코드
```c
#include <stdio.h>

int gcd(int a, int b);
int lcm(int a, int b);

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}

// gcd(), lcm() 을 여기에 정의하세요.
```

## 입력 예시 1
```
2
12 18
7 5
```
## 출력 예시 1
```
[1] 12와 18: 최대공약수   6, 최소공배수    36
[2] 7와 5: 최대공약수   1, 최소공배수    35
최대공약수의 합: 7
```

## 입력 예시 2
```
3
100 100
1 99
8 20
```
## 출력 예시 2
```
[1] 100와 100: 최대공약수 100, 최소공배수   100
[2] 1와 99: 최대공약수   1, 최소공배수    99
[3] 8와 20: 최대공약수   4, 최소공배수    40
최대공약수의 합: 105
```

## Tips
재귀 함수는 같은 일을 더 작은 입력으로 반복합니다. 재귀 함수에는 반드시 멈추는 조건이 있어야 합니다. 최소공배수는 최대공약수를 이용해 구할 수 있습니다.

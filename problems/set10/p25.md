# 소수 정원사

하트 여왕의 정원사가 번호표가 소수인 장미만 골라 물을 줍니다. 소수 판별 함수를 만들어 구간 안의 소수를 찾아 주세요.

## 지시사항
1. 정수 `n` 이 소수이면 1, 아니면 0 을 반환하는 `int is_prime(int n)` 을 정의하세요. 2 미만의 수는 소수가 아닙니다. 원형은 `main()` 위에 선언합니다.
2. 두 정수 `a`, `b` 를 한 줄에 공백으로 구분해 입력받으세요(1 ≤ a ≤ b ≤ 100).
3. 첫 줄에 a 이상 b 이하의 소수를 작은 수부터 공백 한 칸으로 구분해 출력하세요. 줄 끝에는 공백이 없습니다. 소수가 하나도 없으면 `없음` 을 출력합니다.
4. 둘째 줄에 `개수: ○` 를 출력하세요. 두 줄 모두 줄바꿈으로 끝납니다.

## 시작 코드
```c
#include <stdio.h>

int is_prime(int n);

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}

// is_prime() 을 여기에 정의하세요.
```

## 입력 예시 1
```
1 20
```
## 출력 예시 1
```
2 3 5 7 11 13 17 19
개수: 8
```

## 입력 예시 2
```
24 28
```
## 출력 예시 2
```
없음
개수: 0
```

## Tips
`return` 을 만나면 함수가 즉시 끝나므로, 약수를 찾는 순간 `return 0;` 으로 빠져나올 수 있습니다. 공백은 '이미 하나 이상 출력했을 때 앞에' 출력하면 줄 끝에 남지 않습니다.

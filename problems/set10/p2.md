# 온도 변환표

엘리스 토끼는 여행 준비를 하며 기온을 화씨와 켈빈으로 바꿔 보려 합니다. 섭씨 온도를 입력받아 형식에 맞게 출력해 보세요.

## 지시사항
1. 섭씨 온도를 실수로 한 줄 입력받아 `double celsius` 에 저장하세요. (`%lf` 사용)
2. 화씨 온도는 `celsius * 9.0 / 5 + 32` 로 계산하고, 소수점 첫째 자리까지 `화씨: ○○` 형식으로 출력하세요. (`%.1f`)
3. 켈빈 온도는 `celsius + 273.15` 로 계산하고, 폭 8, 소수점 둘째 자리로 `켈빈: ` 뒤에 이어서 출력하세요. 즉 형식은 `켈빈: %8.2f` 이며 숫자가 짧으면 앞에 공백이 채워집니다.
4. 각 줄은 줄바꿈으로 끝냅니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
25
```
## 출력 예시 1
```
화씨: 77.0
켈빈:   298.15
```

## 입력 예시 2
```
36.6
```
## 출력 예시 2
```
화씨: 97.9
켈빈:   309.75
```

## Tips
`double` 을 입력받을 때는 `scanf` 에 `%lf` 를, 출력할 때는 `%f` 계열을 씁니다. `9 / 5` 처럼 정수끼리 나누면 1이 되니 `9.0` 을 쓰세요.

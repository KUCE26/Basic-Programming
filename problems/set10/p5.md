# 대문자로 바꾸기

엘리스 토끼는 알파벳 한 글자를 대문자로 바꾸는 방법을 아스키 코드로 알아보려 합니다.

## 지시사항
1. 소문자 알파벳 한 글자를 입력받아 `char lower` 에 저장하세요. (`%c` 사용, 입력은 항상 소문자 하나입니다.)
2. 대문자로 바꾼 값을 `char upper` 에 저장하세요.
3. 첫째 줄에 `대문자: ○` 형식으로 `upper` 를 문자(`%c`)로 출력하세요.
4. 둘째 줄에 `대문자의 아스키 코드: ○○` 형식으로 `upper` 를 정수(`%d`)로 출력하세요.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
a
```
## 출력 예시 1
```
대문자: A
대문자의 아스키 코드: 65
```

## 입력 예시 2
```
q
```
## 출력 예시 2
```
대문자: Q
대문자의 아스키 코드: 81
```

## Tips
`char` 는 작은 정수이기도 합니다. 대문자와 소문자의 아스키 코드 차이를 이용해 보세요. 같은 값을 `%c` 로 찍으면 문자, `%d` 로 찍으면 아스키 코드입니다.

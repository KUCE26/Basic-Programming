# 복합 대입 영수증

엘리스 토끼 문구점의 계산대 프로그램을 만듭니다. 금액은 변수 하나를 계속 고쳐 가며 계산하고, 영수증은 금액이 오른쪽으로 정렬되도록 폭을 맞춰 출력합니다.

## 지시사항
1. 단가 `unit`, 수량 `qty`, 쿠폰 할인액 `coupon` 을 각각 한 줄씩 순서대로 `int` 로 입력받으세요. (단가 100 이상 50000 이하, 수량 1 이상 7 이하, 쿠폰은 0 이상이며 단가*수량 이하)
2. `int pay` 를 `unit` 으로 시작해, 복합 대입 연산자만 써서 수량을 곱하고 쿠폰 할인액을 빼서 상품 합계를 만드세요. 이 값을 `상품 합계: ○원` 형식으로 출력하되, 숫자 부분(`○`)만 폭 8 로 오른쪽 정렬하세요. (아래 폭 지정도 모두 숫자 부분에만 적용합니다.)
3. `쿠폰 할인: -○원` 을 폭 7 오른쪽 정렬로 출력하세요(`-` 는 숫자 앞에 고정으로 붙입니다).
4. 상품 합계가 30000 원 이상이면 배송비가 0 원, 아니면 3000 원입니다. 삼항 연산자로 정해 `배송비: ○원` 을 폭 8 오른쪽 정렬로 출력하세요.
5. `pay` 에 배송비를 복합 대입으로 더한 뒤 `결제 금액: ○원` 을 폭 8 오른쪽 정렬로 출력하세요.
6. 결제 금액의 1% 를 정수로(소수점 이하 버림) `적립 포인트: ○점` 으로 출력하세요. 별도 변수에 결제 금액을 복사한 뒤 복합 대입 연산자로 계산하세요.
7. 결제 금액을 천 원으로 나눈 나머지를 별도 변수에 복합 대입으로 구해 `천원 미만: ○○○원` 으로 출력하세요. 항상 세 자리가 되게 빈자리는 0 으로 채웁니다.
8. 수량 한 개당 평균 결제 금액을 소수점 둘째 자리까지 `개당 평균: ○○.○○원` 으로 출력하세요. 정수 나눗셈이 되지 않게 하세요.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
12000
3
2000
```
## 출력 예시 1
```
상품 합계:    34000원
쿠폰 할인: -   2000원
배송비:        0원
결제 금액:    34000원
적립 포인트: 340점
천원 미만: 000원
개당 평균: 11333.33원
```

## Tips
`x *= 3` 은 `x = x * 3` 과 같습니다. 폭 지정은 `%8d`(폭 8, 오른쪽 정렬), 0 채우기는 `%03d` 입니다. 실수로 나누려면 피연산자 중 하나를 `(double)` 로 바꾸세요.

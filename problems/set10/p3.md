# 초를 시계로

엘리스 토끼는 마라톤 기록을 초 단위로 적어 두었습니다. 이를 시계처럼 보기 좋게 바꿔 보세요.

## 지시사항
1. 초 단위 시간 `seconds` 를 정수 하나로 입력받으세요. (0 이상 359999 이하)
2. `seconds` 를 시(`hour`), 분(`minute`), 초(`second`)로 나누어 각각 `int` 변수에 저장하세요.
3. `HH:MM:SS` 형식으로, 각 부분을 `%02d` 로 출력하세요. 24시간을 넘어도 날짜로 넘기지 않고 시만 계속 커집니다. (예: 90061초는 `25:01:01`)

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
3725
```
## 출력 예시 1
```
01:02:05
```

## 입력 예시 2
```
90061
```
## 출력 예시 2
```
25:01:01
```

## Tips
`%02d` 는 두 자리로 맞추고 빈 곳을 0으로 채웁니다. 세 자리 이상이면 그대로 다 출력됩니다.

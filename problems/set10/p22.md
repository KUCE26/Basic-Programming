# 미소 온도계

체셔 고양이의 미소를 재는 온도계가 n 번 측정했습니다. 센서가 고장 난 측정값은 -1 로 기록되어 있어 건너뛰어야 합니다.

## 지시사항
1. 측정 횟수 `int n` (1 이상 10 이하)을 입력받은 뒤, n 개의 측정값을 `double` 로 입력받으세요. 정상 측정값은 0 이상 100 이하이고, 고장 난 값은 `-1` 입니다. 정상 측정값은 적어도 하나 있습니다.
2. `for` 문으로 n 번 반복하며, 고장 난 값(음수)은 `continue` 로 건너뛰세요.
3. 정상 측정값은 한 줄에 하나씩 `○번: [○○○○○○]` 형식으로 출력하세요. 번호는 입력된 순서(1 부터)이며 고장 난 측정은 번호만 비어 갑니다. 대괄호 안의 값은 폭 6, 소수점 아래 한 자리로 오른쪽 정렬합니다.
4. 마지막 줄에 `유효 ○개, 평균 ○` 를 출력하세요. 평균은 정상 측정값만으로 구하고 소수점 둘째 자리까지 나타냅니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
5
85.5 -1 90.0 72.3 -1
```
## 출력 예시 1
```
1번: [  85.5]
3번: [  90.0]
4번: [  72.3]
유효 3개, 평균 82.60
```

## 입력 예시 2
```
3
100.0 100.0 99.5
```
## 출력 예시 2
```
1번: [ 100.0]
2번: [ 100.0]
3번: [  99.5]
유효 3개, 평균 99.83
```

## Tips
평균을 구할 때 나누는 수는 n 이 아니라 정상 측정값의 개수입니다. 실수 입력에는 `%lf` 를 사용합니다.

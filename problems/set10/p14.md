# 정수 분류기

엘리스 토끼가 정수 카드를 한 장 뽑았습니다. 카드의 절댓값과 부호, 홀짝을 알려 주는 프로그램을 만들어 주세요.

## 지시사항
1. 정수를 입력받아 `int x` 에 저장하세요. 입력은 -1000 이상 1000 이하입니다.
2. 첫째 줄에 `입력한 수: ○` 를 출력하세요.
3. 둘째 줄에 `절댓값: ○` 를 출력하세요. 절댓값은 삼항 연산자로 구하세요.
4. 셋째 줄에는 `분류: ○○` 를 출력하세요. 0 이면 `영`, 0 보다 크면 `양의 짝수` 또는 `양의 홀수`, 0 보다 작으면 `음의 짝수` 또는 `음의 홀수` 입니다. 홀짝은 2로 나눈 나머지가 0 인지로 구분합니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
7
```
## 출력 예시 1
```
입력한 수: 7
절댓값: 7
분류: 양의 홀수
```

## 입력 예시 2
```
-4
```
## 출력 예시 2
```
입력한 수: -4
절댓값: 4
분류: 음의 짝수
```

## Tips
삼항 연산자 `조건 ? 값1 : 값2` 는 `printf` 의 인자 자리에도 쓸 수 있습니다. `%s` 에 `"짝수"` 같은 문자열을 그대로 줄 수 있어요. 음수를 2로 나눈 나머지는 `-1` 일 수 있으니 `== 1` 로 홀수를 판정하지 마세요.

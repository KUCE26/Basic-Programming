# 여왕의 시저 암호

하트 여왕은 편지를 알파벳 몇 칸씩 밀어서 암호로 씁니다. `z` 다음은 다시 `a` 로 돌아옵니다.

## 지시사항
1. 첫 줄에 공백이 섞인 문장을 `fgets` 로 입력받으세요. 영문, 공백, 숫자, 문장부호로 이루어지며 줄바꿈을 제외하고 1 글자 이상 80 글자 이하입니다. 줄 앞뒤의 공백도 문장의 일부이므로 지우지 않고 그대로 처리하며, 암호문 길이에도 포함합니다. 줄 끝의 줄바꿈 문자는 널 문자로 바꿔 지웁니다. 배열 크기는 101 로 하세요.
2. 둘째 줄에서 밀 칸 수 `k` (0 이상 25 이하의 정수)를 입력받으세요. 문장을 먼저 읽은 뒤에 `k` 를 읽어야 합니다.
3. 영문 대문자는 대문자끼리, 소문자는 소문자끼리 알파벳 순서로 `k` 칸 뒤의 글자로 바꾸고, 알파벳 끝을 넘으면 처음으로 돌아가세요(`Z` 다음은 `A`, `z` 다음은 `a`). 영문자가 아닌 글자는 그대로 둡니다.
4. 첫 줄에 암호문을, 둘째 줄에 `암호문 길이: ○` 를 출력하세요. 길이는 공백을 포함한 글자 수입니다.

## 시작 코드
```c
#include <stdio.h>
#include <string.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
Off with her head!
3
```
## 출력 예시 1
```
Rii zlwk khu khdg!
암호문 길이: 18
```

## 입력 예시 2
```
Xyz Abc zZ
25
```
## 출력 예시 2
```
Wxy Zab yY
암호문 길이: 10
```

## Tips
글자에서 `'a'` 를 빼면 0~25 의 번호가 되고, 거기에 `k` 를 더해 26 으로 나눈 나머지에 `'a'` 를 다시 더하면 돌아오는 글자가 됩니다. `scanf("%d")` 보다 `fgets` 를 먼저 쓰세요. 순서가 반대면 남은 줄바꿈 때문에 `fgets` 가 빈 줄을 읽습니다.

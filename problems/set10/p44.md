# 두 바구니 이름표

앨리스에게 당근 바구니 두 개가 있습니다. 바구니 속 당근 수는 그대로 두고, '큰 바구니를 가리키는 이름표'와 '작은 바구니를 가리키는 이름표'만 서로 바꿔 보세요.

## 지시사항
1. `void swap_ptr(int **a, int **b)` 함수를 정의하세요. 두 이중 포인터가 가리키는 포인터 변수의 내용(주소)을 서로 교환하며, 정수 값은 건드리지 않습니다.
2. `main` 에서 정수 `x`, `y` 를 한 줄에 공백으로 구분해 입력받으세요(각각 -1000 이상 1000 이하).
3. `int *p = &x;`, `int *q = &y;` 로 초기화하세요. `*p` 가 `*q` 보다 작을 때만(같으면 해당 안 됨) `swap_ptr(&p, &q)` 를 호출하세요.
4. 첫 줄에 `큰 쪽: ○`, 둘째 줄에 `작은 쪽: ○` 를 각각 `*p`, `*q` 의 값으로 출력하세요.
5. 그다음 `*p` 에 10 을 더하세요. 셋째 줄에 `x=○ y=○` 를 출력하세요(변수 `x`, `y` 의 현재 값).
6. 넷째 줄에 `p` 가 `x` 를 가리키면 `p 는 x 를 가리킵니다.`, `y` 를 가리키면 `p 는 y 를 가리킵니다.` 를 출력하세요.

## 시작 코드
```c
#include <stdio.h>

void swap_ptr(int **a, int **b) {
    // 지시사항을 참고하여 완성하세요.
}

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
3 8
```
## 출력 예시 1
```
큰 쪽: 8
작은 쪽: 3
x=3 y=18
p 는 y 를 가리킵니다.
```

## 입력 예시 2
```
8 3
```
## 출력 예시 2
```
큰 쪽: 8
작은 쪽: 3
x=18 y=3
p 는 x 를 가리킵니다.
```

## Tips
포인터 변수 자체를 바꾸려면 그 포인터의 주소(`&p`)를 넘겨 `int **` 로 받아야 합니다. 값이 아니라 '가리키는 대상'이 바뀐다는 점에 주의하세요.

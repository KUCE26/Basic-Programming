# 나눗셈 안전 검사기

엘리스 토끼가 두 수를 나누는 계산기를 만들었는데, 0 으로 나누면 프로그램이 멈춰 버립니다. 논리 연산자는 앞의 결과만으로 답이 정해지면 뒤를 계산하지 않는다는 성질(단락 평가)이 있습니다. 이 성질로 계산기를 안전하게 만들어 보세요.

## 지시사항
1. 두 정수 `a`, `b` 를 공백으로 구분해 한 줄에 입력받으세요. (둘 다 0 이상 1000 이하, `b` 는 0 일 수 있습니다.) `int cnt` 를 0 으로 선언해 두세요.
2. `r1` : b 가 0 이 아니고 a 를 b 로 나눈 몫이 2 이상이면 1, 아니면 0. b 가 0 일 때 나눗셈이 실행되면 안 됩니다.
3. `r2` : b 가 0 이거나 a 를 b 로 나눈 나머지가 0 이면 1, 아니면 0. 마찬가지로 b 가 0 일 때 나머지 연산이 실행되면 안 됩니다.
4. `r3` : a 가 b 보다 크거나, `cnt` 를 먼저 1 증가시킨(전위) 값이 0 보다 크면 1, 아니면 0.
5. `r4` : a 가 100 이상이고, `cnt` 를 먼저 1 증가시킨(전위) 값이 1 보다 크면 1, 아니면 0. (`r3` 다음에 계산하세요.)
6. `r1: ○`, `r2: ○`, `r3: ○`, `r4: ○`, `cnt: ○` 를 순서대로 한 줄씩 출력하세요.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
150 40
```
## 출력 예시 1
```
r1: 1
r2: 0
r3: 1
r4: 0
cnt: 1
```

## 입력 예시 2
```
130 130
```
## 출력 예시 2
```
r1: 0
r2: 1
r3: 1
r4: 1
cnt: 2
```

## Tips
`A && B` 는 A 가 거짓이면 B 를 계산하지 않고, `A || B` 는 A 가 참이면 B 를 계산하지 않습니다. 그래서 B 안의 `++cnt` 가 실행되지 않을 수도 있어요. 마지막에 찍은 `cnt` 로 확인해 보세요.

# 폭 맞춘 영수증

엘리스 토끼는 문구점 영수증을 예쁘게 뽑는 프로그램을 만들고 있습니다. 상품 하나의 줄을 열에 딱 맞춰 출력해 보세요.

## 지시사항
1. 상품명(공백 없는 단어, 10자 이내), 단가, 수량을 공백으로 구분해 한 줄로 입력받으세요. 상품명은 `char name[11];` 에 `%s` 로 읽고, 단가와 수량은 `int` 로 저장하세요.
2. 금액(단가 * 수량)을 `int` 변수 `total` 에 저장하세요.
3. 첫 줄에 `%-10s|%6d|%3d|%8d` 형식으로 상품명, 단가, 수량, 금액을 출력하세요. 상품명은 폭 10 왼쪽 정렬, 나머지는 각각 폭 6, 3, 8 오른쪽 정렬입니다.
4. 둘째 줄에는 `-` 문자 30개를 출력하세요.
5. 단가는 99999 이하, 수량은 99 이하로 입력됩니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    char name[11];
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
Pencil 500 12
```
## 출력 예시 1
```
Pencil    |   500| 12|    6000
------------------------------
```

## 입력 예시 2
```
Notebook 2800 5
```
## 출력 예시 2
```
Notebook  |  2800|  5|   14000
------------------------------
```

## Tips
`%-10s` 는 왼쪽 정렬, `%6d` 는 오른쪽 정렬입니다. 폭이 하나라도 틀리면 열이 어긋나 오답이 됩니다. `%s` 는 공백 전까지만 읽습니다.

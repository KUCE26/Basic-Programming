# 세 자리 수 해부

엘리스 토끼는 세 자리 비밀번호의 각 자리를 따로 보고 싶습니다. 숫자를 자리별로 나눠 보세요.

## 지시사항
1. 100 이상 999 이하의 정수 하나를 입력받아 `int n` 에 저장하세요.
2. 백의 자리, 십의 자리, 일의 자리 숫자를 각각 구해 `int` 변수에 저장하세요.
3. 아래 형식으로 네 줄을 출력하세요.
   - `백의 자리: ○`
   - `십의 자리: ○`
   - `일의 자리: ○`
   - `자릿수 합: ○○`

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
482
```
## 출력 예시 1
```
백의 자리: 4
십의 자리: 8
일의 자리: 2
자릿수 합: 14
```

## 입력 예시 2
```
907
```
## 출력 예시 2
```
백의 자리: 9
십의 자리: 0
일의 자리: 7
자릿수 합: 16
```

## Tips
정수끼리의 `/` 는 소수점 아래를 버리고, `%` 는 나머지를 구합니다. 두 연산을 조합해 보세요.

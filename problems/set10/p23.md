# 빌의 무게 컨베이어

도마뱀 빌의 컨베이어에 상자 무게가 차례로 도착합니다. 0 이 오면 작업이 정상 종료되고, 999 가 오면 기계 이상으로 긴급 정지합니다.

## 지시사항
1. 무게(정수)를 `while` 문으로 계속 입력받으세요. 무게는 1 이상 998 이하이고, 입력의 끝은 `0`(정상 종료) 또는 `999`(긴급 정지) 중 하나이며 반드시 둘 중 하나가 나옵니다. 종료를 알리는 값은 기록에 포함하지 않으며, 긴급 정지 뒤에 남은 입력은 읽지 않습니다.
2. 첫째 줄에 종료 사유를 `종료: 정상` 또는 `종료: 긴급 정지` 로 출력하세요.
3. 기록된 상자가 하나도 없으면 둘째 줄에 `기록 없음` 만 출력하고 끝냅니다.
4. 기록이 있으면 둘째 줄부터 `개수: ○`, `최대: [○○○○] (○번)`, `짝수: ○` 를 한 줄씩 출력하세요. 최대는 가장 무거운 무게(대괄호 안은 폭 4 오른쪽 정렬)와 그 무게가 나온 횟수, 짝수는 짝수 무게의 개수입니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
3 8 8 2 0
```
## 출력 예시 1
```
종료: 정상
개수: 4
최대: [   8] (2번)
짝수: 3
```

## 입력 예시 2
```
10 999 20 0
```
## 출력 예시 2
```
종료: 긴급 정지
개수: 1
최대: [  10] (1번)
짝수: 1
```

## Tips
종료값이 두 종류이므로 어느 쪽으로 `break` 했는지 변수에 기록해 두세요. 최댓값은 첫 값으로 초기화하거나, 상자가 1 개 이상일 때만 비교하세요.

# 작은 수와 큰 수 찾기

체셔 고양이가 숫자 카드 더미에서 가장 작은 카드와 가장 큰 카드를 찾아 달라고 합니다. 같은 값이 여러 장이면 위치 규칙에 주의하세요.

## 지시사항
1. `void minmax(int arr[], int n, int *mn, int *mx, int *imin, int *imax)` 함수를 정의하세요. `arr` 의 앞 n 개 중 최솟값을 `*mn`, 최댓값을 `*mx` 에 저장합니다.
2. `*imin` 에는 최솟값이 처음 나오는 위치(인덱스, 0 부터)를, `*imax` 에는 최댓값이 마지막으로 나오는 위치를 저장하세요.
3. `main` 에서 정수 `n` (1 이상 20 이하)을 입력받고 다음 줄에 n 개의 정수(-1000 이상 1000 이하)를 크기 20 인 배열에 입력받으세요.
4. `minmax` 를 호출한 뒤 `최솟값: ○ (위치 ○)`, `최댓값: ○ (위치 ○)` 를 두 줄에 출력하세요.
5. 셋째 줄에 `차이: ○` 를 출력하세요. 최댓값에서 최솟값을 뺀 값입니다.

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

## 입력 예시 1
```
5
3 9 1 9 1
```
## 출력 예시 1
```
최솟값: 1 (위치 2)
최댓값: 9 (위치 3)
차이: 8
```

## 입력 예시 2
```
1
7
```
## 출력 예시 2
```
최솟값: 7 (위치 0)
최댓값: 7 (위치 0)
차이: 0
```

## Tips
최솟값은 '더 작을 때만' 갱신해야 처음 위치가 유지되고, 최댓값은 '같거나 클 때' 갱신해야 마지막 위치가 남습니다.

# 사과 상자 포장

엘리스 토끼가 사과를 상자에 담아 팔려고 합니다. 한 상자에 같은 개수씩 담고 남는 사과는 낱개로 둡니다. 개수가 1 개일 때와 그 외일 때 단어가 다르게(단수/복수) 나와야 합니다.

## 지시사항
1. 전체 사과 수 `total` 과 한 상자에 담는 수 `per` 를 공백으로 구분해 한 줄에 입력받아 `int` 에 저장하세요. (`total` 은 0 이상 1000 이하, `per` 는 1 이상 50 이하)
2. 가득 찬 상자 수를 `가득 찬 상자: ○ box` 형식으로 출력하세요. 상자가 1 개가 아니면 `box` 대신 `boxes` 를 출력합니다(0 개도 `boxes`). 삼항 연산자를 쓰세요.
3. 남는 사과 수를 `남은 사과: ○ apple` 형식으로 출력하세요. 1 개가 아니면 `apple` 대신 `apples` 입니다.
4. 남는 사과까지 담으려면 필요한 전체 상자 수를 `필요한 상자 수: ○` 형식으로 출력하세요. 사과가 남으면 상자가 하나 더 필요합니다. 조건문 대신 관계 연산자의 결과(1 또는 0)를 더해서 구하세요.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
25 8
```
## 출력 예시 1
```
가득 찬 상자: 3 boxes
남은 사과: 1 apple
필요한 상자 수: 4
```

## 입력 예시 2
```
7 7
```
## 출력 예시 2
```
가득 찬 상자: 1 box
남은 사과: 0 apples
필요한 상자 수: 1
```

## Tips
`/` 는 몫, `%` 는 나머지입니다. `조건 ? 값1 : 값2` 는 조건이 참이면 값1, 거짓이면 값2 가 됩니다. 문자열 `%s` 자리에 삼항 연산자의 결과를 그대로 넣을 수 있어요.

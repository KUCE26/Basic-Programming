# 숫자 뒤집기 마법

하트 여왕의 마법 거울은 숫자를 비추면 자릿수의 합을 알려 주고 거꾸로 뒤집어 보여 줍니다. -1 이 입력될 때까지 거울에 숫자를 비춰 보세요. 0 도 정상적인 입력이니 다른 수와 똑같이 처리합니다.

## 지시사항
1. 정수 `n` 의 각 자릿수의 합을 반환하는 `int digit_sum(int n)` 을 **재귀 함수**로 정의하세요(n ≥ 0).
2. 정수 `n` 의 자릿수를 일의 자리부터 거꾸로 출력하는 `void print_reverse(int n)` 을 **재귀 함수**로 정의하세요. 반환값은 없고, 함수 안에서 직접 출력합니다. 줄바꿈은 출력하지 않으며 `n` 이 0 이면 `0` 하나만 출력합니다. 10 으로 끝나는 수의 끝자리 0 은 앞자리 0 이 되어 그대로 출력됩니다(예: 1200 은 `0021`). 두 함수의 원형은 `main()` 위에 선언하세요.
3. `main()` 에서 0 이상의 정수를 계속 입력받다가 -1 이 입력되면 멈추세요. 0 도 처리 대상인 정상 입력입니다. 입력은 공백이나 줄바꿈으로 구분되며, 각 수는 1000000000 이하입니다.
4. 입력된 수마다 한 줄씩 `○: 자릿수 합 ○, 뒤집기 ○` 를 출력하세요(첫 ○ 는 입력한 수). -1 은 처리하지 않습니다.
5. 입력이 끝나면 마지막 줄에 `총 ○개` 를 출력하세요(처리한 수의 개수).

## 시작 코드
```c
#include <stdio.h>

int digit_sum(int n);
void print_reverse(int n);

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}

// digit_sum(), print_reverse() 를 여기에 정의하세요.
```

## 입력 예시 1
```
123 4050 -1
```
## 출력 예시 1
```
123: 자릿수 합 6, 뒤집기 321
4050: 자릿수 합 9, 뒤집기 0504
총 2개
```

## 입력 예시 2
```
7 100 -1
```
## 출력 예시 2
```
7: 자릿수 합 7, 뒤집기 7
100: 자릿수 합 1, 뒤집기 001
총 2개
```

## Tips
`n % 10` 은 마지막 자릿수, `n / 10` 은 마지막 자릿수를 뺀 수입니다. 재귀 호출 앞에 출력하느냐 뒤에 출력하느냐에 따라 순서가 달라집니다. 이 문제는 앞에서 먼저 출력한 뒤 재귀 호출해야 거꾸로 나옵니다.

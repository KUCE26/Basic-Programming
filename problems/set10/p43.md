# 거품 정리 교환 기록

붉은 여왕의 카드를 이웃한 두 장씩 비교해 작은 순서로 정렬합니다. 두 장의 자리를 바꿀 때마다 `swap` 으로 기록을 남겨 교환 횟수와 정렬 과정을 보고하세요.

## 지시사항
1. `void swap(int *a, int *b)` 함수를 정의해 두 정수 값을 교환하세요.
2. 정수 `n` (1 이상 8 이하)을 입력받고 다음 줄에 n 개의 정수(-100 이상 100 이하)를 배열에 입력받으세요.
3. `i` 를 0 부터 n-2 까지 늘려 가며 한 패스를 진행합니다. 한 패스에서는 `j` 를 0 부터 n-2-i 까지 늘리며 `arr[j]` 가 `arr[j+1]` 보다 크면(같으면 교환하지 않음) `swap(&arr[j], &arr[j+1])` 으로 교환하고 교환 횟수를 1 늘립니다.
4. 한 패스가 끝났을 때 그 패스에서 교환이 한 번이라도 있었다면 `패스 ○: ` 뒤에 배열 전체를 공백 한 칸으로 구분해 출력하세요(○ 는 i+1, 줄 끝 공백 없음).
5. 한 패스에서 교환이 한 번도 없었다면 아무것도 출력하지 말고 즉시 반복을 끝내세요.
6. 마지막 줄에 `교환 횟수: ○` 를 출력하세요(총 교환 횟수).

#include <stdio.h>

void swap(int *a, int *b) {

}

    // 지시사항을 참고하여 코드를 작성하세요.

## 입력 예시 1
```
5
5 1 4 2 8
```
## 출력 예시 1
```
패스 1: 1 4 2 5 8
패스 2: 1 2 4 5 8
교환 횟수: 4
```

## 입력 예시 2
```
4
1 2 3 4
```
## 출력 예시 2
```
교환 횟수: 0
```

## Tips
`&arr[j]` 는 배열 원소의 주소이므로 `swap` 에 그대로 넘길 수 있습니다. 출력 형식에서 `패스 ○:` 뒤의 첫 값 앞에만 공백이 하나 있음에 유의하세요.

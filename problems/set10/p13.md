# 캠핑 날씨 점검

엘리스 토끼가 주말 캠핑을 가기 전에 기온, 습도, 풍속을 보고 가도 되는지 판단하려 합니다. 세 값을 한 줄에 입력받아 요약표와 판정을 출력하세요.

## 지시사항
1. 기온, 습도, 풍속을 공백으로 구분해 한 줄로 입력받아 각각 `double` 변수에 저장하세요. (`scanf` 한 번. 모든 입력은 소수점 첫째 자리까지 주어지며 기온은 -30.0 ~ 50.0, 습도는 0.0 ~ 100.0, 풍속은 0.0 ~ 50.0 입니다.)
2. 첫 세 줄에 값을 각각 폭 6칸, 소수점 첫째 자리까지 오른쪽 정렬로 출력하세요. 형식: `기온: [○○○○○○]도`, `습도: [○○○○○○]%`, `풍속: [○○○○○○]m/s`
3. 다음 세 조건을 **모두** 만족하면 마지막 줄에 `판정: 캠핑하기 좋은 날!` 을 출력하세요.
   - 조건 A: 기온이 15.0 이상 28.0 이하
   - 조건 B: 풍속이 5.0 미만
   - 조건 C: 습도가 80.0 미만이거나, 또는 기온이 20.0 미만 (둘 중 하나만 맞아도 조건 C 는 만족)
4. 하나라도 만족하지 않으면 `판정: 캠핑은 다음에...` 를 출력하세요.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
22.5 60.0 3.0
```
## 출력 예시 1
```
기온: [  22.5]도
습도: [  60.0]%
풍속: [   3.0]m/s
판정: 캠핑하기 좋은 날!
```

## 입력 예시 2
```
30.0 40.0 2.0
```
## 출력 예시 2
```
기온: [  30.0]도
습도: [  40.0]%
풍속: [   2.0]m/s
판정: 캠핑은 다음에...
```

## Tips
`&&` 가 `||` 보다 먼저 계산되므로 섞어 쓸 때는 괄호로 묶는 것이 안전합니다. `printf` 에서 `%` 문자 자체를 출력하려면 `%%` 를 씁니다. `%6.1f` 는 폭 6, 소수점 아래 1자리입니다.

# 점수 평균의 함정

엘리스 토끼는 세 과목 시험 점수의 평균을 구하려 합니다. 정수 평균과 실수 평균을 모두 구해 비교해 보세요.

## 지시사항
1. 세 과목 점수를 공백으로 구분해 한 줄로 입력받아 `int a, b, c` 에 저장하세요. (0 이상 100 이하)
2. 합계를 `int sum` 에 저장하고 `합계: ○○` 형식으로 출력하세요.
3. 정수 평균(`sum / 3`, 소수점 아래 버림)을 `int avg_int` 에 저장하고 `정수 평균: ○○` 형식으로 출력하세요.
4. 실수 평균은 `(double)sum / 3` 으로 계산해 `double avg_real` 에 저장하고, `실수 평균: ○○.○○` 형식(`%.2f`)으로 출력하세요.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
90 85 88
```
## 출력 예시 1
```
합계: 263
정수 평균: 87
실수 평균: 87.67
```

## 입력 예시 2
```
100 100 99
```
## 출력 예시 2
```
합계: 299
정수 평균: 99
실수 평균: 99.67
```

## Tips
`sum / 3` 은 정수끼리의 나눗셈이라 소수점이 사라집니다. 나눗셈 전에 `(double)` 로 형 변환을 해야 합니다. `(double)(sum / 3)` 처럼 나눈 뒤에 변환하면 이미 늦습니다.

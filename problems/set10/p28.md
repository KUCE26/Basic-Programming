# 달력 한 달 계산기

체셔 고양이의 달력에는 해마다 달의 날수가 바뀝니다. 윤년 판별 함수와 달의 날수 함수를 만들어 누적 일수를 구해 보세요.

## 지시사항
1. 연도 `y` 가 윤년이면 1, 아니면 0 을 반환하는 `int is_leap(int y)` 를 정의하세요. 4 의 배수이면서 100 의 배수가 아니거나, 400 의 배수이면 윤년입니다.
2. 연도 `y` 와 월 `m` 을 받아 그 달의 날수를 반환하는 `int days_in_month(int y, int m)` 을 정의하세요. 달의 날수는 `switch` 문으로 고르고, 2 월은 `is_leap()` 을 호출해 28 일 또는 29 일로 처리합니다. 두 함수의 원형은 `main()` 위에 선언하세요.
3. `main()` 에서 연도 `y` 와 월 `m` 을 한 줄에 공백으로 구분해 입력받으세요(1900 ≤ y ≤ 2100, 1 ≤ m ≤ 12).
4. 아래 세 줄을 출력하세요. 각 줄은 줄바꿈으로 끝납니다.
   - `○년 ○월: ○일` (입력한 연도, 월, 그 달의 날수)
   - 윤년이면 `윤년입니다.`, 아니면 `평년입니다.`
   - `1월부터 ○월까지 누적: ○일` (그 해 1 월 1 일부터 입력한 월의 마지막 날까지의 일수. 반복문과 `days_in_month()` 로 구합니다.)

## 시작 코드
```c
#include <stdio.h>

int is_leap(int y);
int days_in_month(int y, int m);

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}

// is_leap(), days_in_month() 를 여기에 정의하세요.
```

## 입력 예시 1
```
2024 2
```
## 출력 예시 1
```
2024년 2월: 29일
윤년입니다.
1월부터 2월까지 누적: 60일
```

## 입력 예시 2
```
2023 12
```
## 출력 예시 2
```
2023년 12월: 31일
평년입니다.
1월부터 12월까지 누적: 365일
```

## Tips
윤년 조건에서 `&&` 와 `||` 의 묶음을 괄호로 분명히 하세요. `switch` 안에서 `return` 을 쓰면 `break` 가 없어도 함수가 끝납니다. 같은 값을 내는 `case` 는 붙여서 쓸 수 있습니다.

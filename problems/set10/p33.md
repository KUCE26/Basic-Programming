# 뒤집힌 티파티 간판

모자 장수의 티파티 간판은 대문자와 소문자가 모두 거꾸로 적혀 있습니다. 간판 문구를 바로잡고 글자 수도 세어 봅시다.

## 지시사항
1. 공백이 섞인 한 줄을 `fgets` 로 입력받으세요. 줄은 1 글자 이상이며 영문, 숫자, 공백, 문장부호로 이루어지며 줄바꿈을 제외하고 80 글자 이하입니다. 저장할 `char` 배열은 크기 100 으로 선언하세요.
2. `fgets` 는 줄 끝의 줄바꿈 문자까지 배열에 저장합니다. 이 줄바꿈 문자를 널 문자로 바꿔 지운 뒤 처리하세요. 줄 앞뒤의 공백은 문구의 일부이므로 지우지 말고 그대로 출력합니다.
3. 첫 줄에 문구의 영문 대문자는 소문자로, 영문 소문자는 대문자로 바꿔 출력하세요. 영문자가 아닌 글자(공백, 숫자, 문장부호)는 그대로 둡니다. `ctype.h` 의 함수는 쓰지 말고 문자의 아스키 코드 차이를 이용하세요.
4. 둘째 줄에 `대문자 ○개, 소문자 ○개` 를 출력하세요. 바꾸기 전 원래 문구에 들어 있던 영문 대문자와 소문자의 개수입니다.

## 시작 코드
```c
#include <stdio.h>
#include <string.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
Hello Alice!
```
## 출력 예시 1
```
hELLO aLICE!
대문자 2개, 소문자 8개
```

## 입력 예시 2
```
tEA tIME at 6 O'clock
```
## 출력 예시 2
```
Tea Time AT 6 o'CLOCK
대문자 6개, 소문자 9개
```

## Tips
대문자와 소문자의 아스키 코드 차이는 `'a' - 'A'` 로 얻을 수 있습니다. 문자가 `'A'` 이상 `'Z'` 이하인지 먼저 검사한 뒤 바꾸세요. 줄바꿈 문자는 `'\n'` 입니다.

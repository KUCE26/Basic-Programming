## [과제1] 단위 바꾸기 (lecturepages/55663054)

지시사항: 엘리스가 확인한 집의 넓이가 m^2 단위의 정수로 입력됩니다. 입력된 넓이를 평으로 변환해서 소수점 한 자리까지 출력해 주세요.
입력 예시: `25` → 출력 예시: `7.5`

## [과제2] 엘리스 토끼의 장보기 (55663055)
요즘 들어 한창 C언어 공부에 열심인 엘리스 토끼는 집에 들어가며 어머니에게 전화를 받았습니다.
"들어오는 길에 마트에서 당근 우유를 2개 사오렴, 아 당근 케이크랑 당근 스프가 있는지도 보고, 있으면 10개 사오렴"
잠시 후, 마트에 들렀다 집에 돌아온 엘리스 토끼는 당근 우유를 왜 10개나 사왔냐며 어머니에게 한 소리를 들었습니다. 왜그럴까요? if문을 사용해서 이유를 알아보세요!
지시사항: 4, 8, 11 번의 주석을 참고하여 코드를 작성해보세요.
Tips: 당근 케이크와 당근 스프가 마트에 있는지에 대한 조건을 어떻게 작성해야 할까요?
에디터 코드(주석은 원본 시작 코드의 것):
```c
#include <stdio.h>
int main(void) {
    // 마트에는 당근 케이크와 당근 스프가 있습니다.
    int c_cake = 1;
    int c_soup = 1;
    // 엘리스 토끼가 사야 할 물건인 당근 우유의 구매 개수를 저장할 정수형 변수 c_milk를 선언합니다.
    int c_milk;
    // 만약 당근 케이크와 당근 스프가 있다면 당근 우유를 10개 사야합니다.
    if (c_cake==1 && c_soup==1) { c_milk = 10; }
    // 엘리스 토끼는 과연 당근 우유를 몇 개를 샀을까요?
    printf("당근 우유를 %d개 샀습니다.\n", c_milk);
    return 0;
}
```
(입력 없음. 기대 출력 `당근 우유를 10개 샀습니다.`)

## [과제1] 함수 (lecturepages/55663140)
엘리스 토끼는 친구들의 평균점수를 계산하려 합니다. 친구들이 점수를 4.0, 3.0 같은 수가 아니라 A, B 같은 알파벳으로 알려주었습니다. 알파벳으로 된 점수를 실수로 된 점수로 바꾸는 함수를 작성해 봅시다!
지시사항: char2num 함수를 작성해 출력 예시대로 출력하도록 해봅시다.
시작 코드:
```c
#include <stdio.h>
//여기에 char2num함수를 작성해 주세요.
int main(void)
{
    // 아래는 수정하지 마세요.
    printf("A grade : %.1f\n", char2num('A'));
    printf("B grade : %.1f\n", char2num('B'));
    printf("C grade : %.1f\n", char2num('C'));
    printf("D grade : %.1f\n", char2num('D'));
    printf("F grade : %.1f\n", char2num('F'));
    return 0;
}
```
출력 예시: `A grade : 4.0` / `B grade : 3.0` / `C grade : 2.0` / `D grade : 1.0` / `F grade : 0.0` (입력 없음)

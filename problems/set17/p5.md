# 당근밭 수확량 점검

토끼가 당근밭 한 줄에 심은 당근의 수확량을 기록했습니다. 배열 이름을 포인터에 대입하고, 포인터에 정수를 더해 가며 밭을 훑어 봅시다.

## 지시사항
1. 정수 `n` 을 입력받으세요. n 은 1 이상 20 이하입니다.
2. 크기 20 의 정수 배열 `arr` 와, `arr` 의 시작 주소를 가리키는 포인터 `p` 를 선언하세요. 이후 배열 원소에는 `arr[i]` 대신 `*(p + i)` 형태로만 접근하세요. (입력 때는 `p + i` 가 곧 i 번째 원소의 주소입니다.)
3. n 개의 수확량(-1000 이상 1000 이하의 정수)을 공백으로 구분해 입력받아 저장하세요.
4. 첫 줄에 `총 수확량: ○` 를 출력하세요. ○ 는 모든 수확량의 합입니다.
5. 수확량이 가장 큰 원소를 가리키는 포인터 `maxp` 를 구하세요. 최댓값이 여러 개이면 가장 앞의 원소를 가리킵니다.
6. 둘째 줄에 `최대 수확량: ○ (처음부터 △칸)` 을 출력하세요. ○ 는 최댓값, △ 는 `maxp` 와 `p` 의 두 포인터를 빼서 얻은 원소 개수 차이(0 부터)입니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    int arr[20];
    int *p = arr;
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
5
3 8 2 8 1
```
## 출력 예시 1
```
총 수확량: 22
최대 수확량: 8 (처음부터 1칸)
```

## 입력 예시 2
```
4
-5 -2 -9 -2
```
## 출력 예시 2
```
총 수확량: -18
최대 수확량: -2 (처음부터 1칸)
```

## Tips
두 포인터를 빼면 주소의 차이가 아니라 두 포인터 사이의 원소 개수가 나옵니다. 포인터 차이의 결과를 정수형으로 바꿔 출력하면 안전합니다.

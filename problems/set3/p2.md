# 성적표 만들기

엘리스 토끼가 세 과목 시험을 치렀습니다. 점수의 합계와 평균을 한 줄로 알려 주는 성적표를 만들어 보세요.

## 지시사항
1. 세 과목의 점수를 한 줄에 하나씩 정수로 입력받으세요.
2. 세 점수의 합계와 평균을 구하세요.
3. `합계: 255, 평균: 85.00` 형식으로 한 줄에 출력하세요. 평균은 소수점 둘째 자리까지 출력합니다.

## 입력 예시 1
```
90
80
85
```
## 출력 예시 1
```
합계: 255, 평균: 85.00
```
## 입력 예시 2
```
70
85
92
```
## 출력 예시 2
```
합계: 247, 평균: 82.33
```

## Tips
f-string에서 `{값:.2f}`를 쓰면 소수점 둘째 자리까지 출력할 수 있습니다.

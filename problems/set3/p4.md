# 합격자 명단

엘리스 학원에서 학생들의 이름과 점수를 입력받아 합격자 명단을 만들려고 합니다. 점수가 80점 이상이면 합격입니다.

## 지시사항
1. 첫째 줄에 학생 수 `N`을 입력받으세요.
2. 다음 `N`줄에 걸쳐 `이름 점수` 형식으로 입력받아 이름을 키, 점수(정수)를 값으로 하는 딕셔너리를 만드세요. 이름은 서로 다릅니다.
3. 점수가 80 이상인 학생의 이름을 입력된 순서대로 한 줄에 공백으로 구분하여 출력하세요.
4. 합격자가 한 명도 없으면 `없음`을 출력하세요.

## 입력 예시 1
```
4
철수 85
영희 70
민수 80
지수 92
```
## 출력 예시 1
```
철수 민수 지수
```
## 입력 예시 2
```
3
하나 60
둘이 79
셋이 50
```
## 출력 예시 2
```
없음
```

## Tips
`for 이름, 점수 in 딕셔너리.items():` 로 키와 값을 함께 꺼낼 수 있습니다.

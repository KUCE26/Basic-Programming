# 프로필 카드 만들기

엘리스 토끼가 친구들의 프로필 카드를 만들고 있습니다. 이름과 나이는 꼭 필요하지만, 취미나 도시 같은 추가 정보는 사람마다 개수가 다릅니다. `**extra`를 이용해 추가 정보를 몇 개든 받을 수 있는 함수를 완성해 보세요.

## 지시사항
1. `make_profile(name, age, **extra)` 함수를 완성하세요.
2. 먼저 `이름: name, 나이: age` 형식으로 한 줄을 출력하세요.
3. 이어서 `extra`에 담긴 항목을 입력된 순서대로 한 줄에 하나씩 `키 = 값` 형식으로 출력하세요.
4. 메인 코드는 첫 줄에서 `이름 나이`를, 둘째 줄에서 `키=값` 쌍들을 공백으로 구분해 입력받아 딕셔너리를 만든 뒤 `make_profile(name, age, **extra)`로 함수를 호출합니다. 메인 코드는 수정하지 마세요.

## 시작 코드
```python
def make_profile(name, age, **extra):
    pass


# 아래 코드는 수정하지 마세요.
name, age = input().split()
age = int(age)
extra = {}
for pair in input().split():
    key, value = pair.split("=")
    extra[key] = value
make_profile(name, age, **extra)
```

## 입력 예시 1
```
엘리스 20
취미=독서 도시=서울
```
## 출력 예시 1
```
이름: 엘리스, 나이: 20
취미 = 독서
도시 = 서울
```
## 입력 예시 2
```
토끼 3
색=흰색
```
## 출력 예시 2
```
이름: 토끼, 나이: 3
색 = 흰색
```

## Tips
`**extra`로 받은 값은 딕셔너리이므로 `extra.items()`로 키와 값을 꺼낼 수 있습니다.

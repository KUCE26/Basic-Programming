# 창고 재고 정리

엘리스 토끼의 창고에는 품목별 재고 수량이 적힌 목록이 있습니다. 재고가 0인 품목은 목록에서 빼고, 남은 재고를 정리해 보려 합니다.

## 지시사항
1. 공백으로 구분된 정수들을 한 줄로 입력받아 리스트로 만드세요. 0이 아닌 값이 하나 이상 있습니다.
2. 리스트에서 값이 0인 원소를 모두 제거하세요.
3. 첫째 줄에 0을 제거한 리스트를 그대로 출력하세요.
4. 둘째 줄에 `개수: ` 뒤에 남은 원소의 개수를 출력하세요.
5. 셋째 줄에 `최솟값: ○, 최댓값: ○` 형식으로 최솟값과 최댓값을 출력하세요. (쉼표 뒤에 공백이 하나 있습니다.)

## 입력 예시 1
```
3 0 5 0 2
```
## 출력 예시 1
```
[3, 5, 2]
개수: 3
최솟값: 2, 최댓값: 5
```
## 입력 예시 2
```
10 20 0 0 0 30
```
## 출력 예시 2
```
[10, 20, 30]
개수: 3
최솟값: 10, 최댓값: 30
```

## Tips
`while 0 in 리스트:` 로 0이 남아 있는 동안 `remove(0)`을 반복할 수 있습니다.

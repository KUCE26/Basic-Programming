# 토끼네 직사각형 밭

엘리스 토끼는 직사각형 모양의 당근밭을 가지고 있습니다. 밭의 가로와 세로 길이를 알면 울타리 길이와 밭의 넓이를 구할 수 있습니다.

## 지시사항
1. 가로 길이 `a`와 세로 길이 `b`를 각각 한 줄씩 정수로 입력받으세요.
2. 첫째 줄에 `둘레: ` 뒤에 직사각형의 둘레를 출력하세요.
3. 둘째 줄에 `넓이: ` 뒤에 직사각형의 넓이를 출력하세요.
4. 셋째 줄에 `대각선 제곱: ` 뒤에 `a`의 제곱과 `b`의 제곱의 합(`a ** 2 + b ** 2`)을 출력하세요.

## 입력 예시 1
```
3
4
```
## 출력 예시 1
```
둘레: 14
넓이: 12
대각선 제곱: 25
```
## 입력 예시 2
```
10
7
```
## 출력 예시 2
```
둘레: 34
넓이: 70
대각선 제곱: 149
```

## Tips
`input()`으로 받은 값은 문자열이므로 `int()`로 바꿔 계산하세요.

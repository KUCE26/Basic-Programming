# 학점 계산 함수

엘리스 선생님이 여러 학생의 점수를 학점으로 바꿔 주려고 합니다. 점수를 받아 학점을 돌려주는 함수 `grade(score)`를 완성해 보세요.

## 지시사항
1. `grade(score)` 함수를 완성하세요. 점수에 따라 아래 학점 문자열을 **return** 해야 합니다.
   - 90 이상: `"A"`
   - 80 이상 90 미만: `"B"`
   - 70 이상 80 미만: `"C"`
   - 그 외: `"F"`
2. 메인 코드는 점수들을 공백으로 구분해 한 줄로 입력받고, 각 점수에 대해 `점수 -> 학점` 형식으로 한 줄씩 출력합니다. 메인 코드는 수정하지 마세요.

## 시작 코드
```python
def grade(score):
    pass


# 아래 코드는 수정하지 마세요.
scores = list(map(int, input().split()))
```

## 입력 예시 1
```
95 83 70 41
```
## 출력 예시 1
```
95 -> A
83 -> B
70 -> C
41 -> F
```
## 입력 예시 2
```
100 90 89 80 79
```
## 출력 예시 2
```
100 -> A
90 -> A
89 -> B
80 -> B
79 -> C
```

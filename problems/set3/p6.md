# 윤년 판별기

엘리스 토끼의 달력에는 2월이 29일까지 있는 해가 있습니다. 입력받은 연도가 윤년인지 평년인지 알려 주는 프로그램을 만들어 보세요.

## 지시사항
1. 연도를 정수로 입력받으세요.
2. 연도가 **4의 배수이면서 100의 배수가 아니거나**, **400의 배수**이면 `윤년`을 출력하세요.
3. 그렇지 않으면 `평년`을 출력하세요.

## 입력 예시 1
```
2024
```
## 출력 예시 1
```
윤년
```
## 입력 예시 2
```
1900
```
## 출력 예시 2
```
평년
```

## Tips
`and`, `or`를 함께 쓸 때는 괄호로 묶어 우선순위를 분명히 하세요.

# 별 계단 쌓기

엘리스 토끼가 별로 계단을 쌓고 있습니다. 먼저 한 칸씩 올라가는 계단을 쌓고, 이어서 한 칸씩 내려오는 계단을 쌓아 보세요.

## 지시사항
1. 정수 `N`을 입력받으세요.
2. 먼저 `i`번째 줄에 별(`*`) `i`개를 출력하는 직각삼각형을 `N`줄 출력하세요. (1개, 2개, ..., `N`개)
3. 이어서 별이 `N`개인 줄부터 1개인 줄까지 거꾸로 `N`줄을 더 출력하세요. 총 `2N`줄이 출력됩니다.

## 입력 예시 1
```
3
```
## 출력 예시 1
```
*
**
***
***
**
*
```
## 입력 예시 2
```
1
```
## 출력 예시 2
```
*
*
```

## Tips
`print("*", end="")`는 줄바꿈 없이 별을 이어 붙입니다. 한 줄을 다 찍은 뒤 `print()`로 줄을 바꾸세요.

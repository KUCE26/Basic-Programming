# 전화번호 가리기

엘리스 토끼는 개인정보를 지키기 위해 전화번호의 가운데 부분을 가리려고 합니다. 전화번호는 항상 `XXX-XXXX-XXXX` 형태로 입력됩니다.

## 지시사항
1. 전화번호를 한 줄로 입력받으세요.
2. 첫째 줄에 `-`를 모두 제거한 숫자열을 출력하세요. (`replace` 사용)
3. 둘째 줄에 전화번호의 뒤 4자리를 출력하세요. (슬라이싱 사용)
4. 셋째 줄에 가운데 4자리를 `****`로 바꾼 번호를 출력하세요. 예: `010-****-5678`

## 입력 예시 1
```
010-1234-5678
```
## 출력 예시 1
```
01012345678
5678
010-****-5678
```
## 입력 예시 2
```
010-9876-0001
```
## 출력 예시 2
```
01098760001
0001
010-****-0001
```

## Tips
`"문자열"[:4]`는 앞 4글자, `"문자열"[-4:]`는 뒤 4글자입니다.

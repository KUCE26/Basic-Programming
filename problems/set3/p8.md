# 숫자 맞히기 게임

엘리스 토끼와 친구가 숫자 맞히기 게임을 합니다. 정답이 정해져 있고, 친구는 정답을 맞힐 때까지 계속 숫자를 말합니다.

## 지시사항
1. 첫째 줄에 정답(정수)을 입력받으세요.
2. 이후 추측값(정수)을 한 줄에 하나씩 계속 입력받으세요. (`while True` 사용)
3. 추측값이 정답보다 작으면 `UP`, 크면 `DOWN`을 출력하세요.
4. 추측값이 정답과 같으면 `정답! N번 만에 맞혔습니다`를 출력하고 반복을 끝내세요. `N`은 지금까지 추측한 횟수(정답을 맞힌 입력 포함)입니다.
5. 정답을 맞힌 뒤의 입력은 읽지 않습니다.

## 입력 예시 1
```
37
50
25
37
```
## 출력 예시 1
```
DOWN
UP
정답! 3번 만에 맞혔습니다
```
## 입력 예시 2
```
7
1
2
3
4
5
6
7
```
## 출력 예시 2
```
UP
UP
UP
UP
UP
UP
정답! 7번 만에 맞혔습니다
```

## Tips
`break`를 만나면 가장 가까운 반복문이 바로 끝납니다.

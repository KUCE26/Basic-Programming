# 토끼 자기소개 카드

엘리스 토끼가 동아리 가입 신청서에 쓸 자기소개 카드를 만들려고 합니다. 나이, 키, 등급을 입력받아 카드 모양으로 출력해 보세요.

## 지시사항
1. 나이(정수), 키(실수), 등급(문자 하나)을 각각 한 줄씩 순서대로 입력받아 `int`, `double`, `char` 변수에 저장하세요.
2. 첫 줄에 `=== 토끼 카드 ===` 를 출력하세요.
3. 나이를 `나이: ○○세` 형식으로 출력하세요.
4. 키를 소수점 첫째 자리까지 `키: ○○.○cm` 형식으로 출력하세요.
5. 등급을 `등급: ○` 형식으로 출력하세요.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
20
170.5
A
```
## 출력 예시 1
```
=== 토끼 카드 ===
나이: 20세
키: 170.5cm
등급: A
```

## 입력 예시 2
```
7
45.25
b
```
## 출력 예시 2
```
=== 토끼 카드 ===
나이: 7세
키: 45.2cm
등급: b
```

## Tips
`double` 은 `scanf` 에서 `%lf`, `printf` 에서도 `%f`/`%.1f` 로 씁니다. 문자 `%c` 는 앞의 줄바꿈까지 읽어 버리므로 `" %c"` 처럼 앞에 공백을 넣으면 안전합니다.

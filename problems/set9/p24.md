# 구구단 특강

하트 여왕이 구구단을 틀린 병사들에게 특강을 열었습니다. 시작 단부터 끝 단까지, 각 단을 지정한 곱셈 횟수만큼만 외우게 합니다.

## 지시사항
1. 세 정수 `a`, `b`, `c` 를 한 줄에 공백으로 구분해 입력받으세요. a 단부터 b 단까지 외우며(2 ≤ a ≤ b ≤ 9), 각 단은 1 부터 c 까지 곱합니다(1 ≤ c ≤ 9).
2. `for` 문을 중첩해서 각 단의 식을 `단 x 곱하는수 = 결과` 형식(곱셈 기호는 소문자 x, 양옆 공백 한 칸)으로 한 줄에 하나씩 출력하세요.
3. 단과 단 사이에는 빈 줄을 한 줄 출력하세요. 마지막 단 뒤에는 빈 줄을 출력하지 않습니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
2 3 5
```
## 출력 예시 1
```
2 x 1 = 2
2 x 2 = 4
2 x 3 = 6
2 x 4 = 8
2 x 5 = 10

3 x 1 = 3
3 x 2 = 6
3 x 3 = 9
3 x 4 = 12
3 x 5 = 15
```

## 입력 예시 2
```
7 7 9
```
## 출력 예시 2
```
7 x 1 = 7
7 x 2 = 14
7 x 3 = 21
7 x 4 = 28
7 x 5 = 35
7 x 6 = 42
7 x 7 = 49
7 x 8 = 56
7 x 9 = 63
```

## Tips
바깥 반복은 단, 안쪽 반복은 곱하는 수를 맡습니다. 빈 줄은 '첫 단이 아닐 때, 단을 시작하기 전에' 출력하면 마지막 단 뒤에 남지 않습니다.

# 비밀 문구 확인

체셔 고양이네 문 앞에는 비밀 문구를 말해야 열리는 자물쇠가 있습니다. 비밀 문구는 `carrot` 입니다. 입력한 문구가 맞는지 확인해 주세요.

## 지시사항
1. 공백 없는 영문 소문자·대문자로 이루어진 단어(최대 15글자)를 입력받아 `char word[20]` 에 저장하세요. (`%s` 사용)
2. `strcmp` 로 입력한 단어가 `carrot` 과 완전히 같은지 비교하세요.
3. 같으면 `문이 열립니다!` 를, 다르면 `문이 열리지 않아요.` 를 출력하세요. (`if`-`else` 사용)

## 시작 코드
```c
#include <stdio.h>
#include <string.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
carrot
```
## 출력 예시 1
```
문이 열립니다!
```

## 입력 예시 2
```
cabbage
```
## 출력 예시 2
```
문이 열리지 않아요.
```

## Tips
`strcmp(a, b)` 는 두 문자열이 같을 때 `0` 을 돌려줍니다. 대문자와 소문자는 서로 다른 글자로 취급되고, 문자열 비교에 `==` 를 쓰면 안 됩니다. `string.h` 를 포함하세요.

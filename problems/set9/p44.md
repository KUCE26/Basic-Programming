# 모자 바꿔 쓰기

앨리스와 미친 모자 장수가 쓴 모자의 크기가 뒤바뀌었습니다. 함수로 두 모자를 서로 바꿔 주고, 큰 모자가 1번에 오도록 정리하세요.

## 지시사항
1. `void swap(int *a, int *b)` 함수를 정의하세요. 두 포인터가 가리키는 정수 값을 서로 교환하며 반환값은 없습니다.
2. `main` 에서 정수 `hat1`, `hat2` 를 한 줄에 공백으로 구분해 입력받으세요(각각 -1000 이상 1000 이하).
3. `swap(&hat1, &hat2)` 로 먼저 한 번 교환한 뒤 `1번 모자 : ○` 와 `2번 모자 : ○` 를 두 줄에 출력하세요.
4. 이때 `hat1` 이 `hat2` 보다 작으면(같을 때는 해당 안 됨) `다시 바꿉니다.` 를 한 줄 출력하고 `swap` 으로 한 번 더 교환하세요.
5. 마지막에 `큰 모자 : ○` 와 `작은 모자 : ○` 를 두 줄에 출력하세요. 두 값이 같으면 둘 다 같은 값을 출력합니다.

## 시작 코드
```c
#include <stdio.h>

void swap(int *a, int *b) {
    // 지시사항을 참고하여 완성하세요.
}

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
8 10
```
## 출력 예시 1
```
1번 모자 : 10
2번 모자 : 8
큰 모자 : 10
작은 모자 : 8
```

## 입력 예시 2
```
10 8
```
## 출력 예시 2
```
1번 모자 : 8
2번 모자 : 10
다시 바꿉니다.
큰 모자 : 10
작은 모자 : 8
```

## Tips
`swap` 안에서는 임시 변수 하나를 두고 `*a`, `*b` 값을 옮깁니다. 호출할 때는 변수 앞에 `&` 를 붙여 주소를 넘겨야 원래 변수가 바뀝니다.

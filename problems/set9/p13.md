# 놀이기구 키 제한

엘리스 토끼가 롤러코스터 앞에 줄을 섰습니다. 키 제한을 넘는지 확인해 안내 문구를 출력해 주세요.

## 지시사항
1. 키를 실수로 입력받아 `double height` 에 저장하세요. 키는 0 보다 크고 250 이하입니다.
2. `if` 문을 사용해 키가 120.0 이상이면 `탑승할 수 있어요!` 를 출력하세요.
3. `if` 문을 한 번 더 사용해 키가 120.0 보다 작으면 `키가 조금 더 커야 해요.` 를 출력하세요.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
150.5
```
## 출력 예시 1
```
탑승할 수 있어요!
```

## 입력 예시 2
```
110.2
```
## 출력 예시 2
```
키가 조금 더 커야 해요.
```

## Tips
`double` 을 `scanf` 로 읽을 때는 `%lf` 를 씁니다. 두 조건은 서로 반대이므로 어느 입력이든 문장은 정확히 하나만 출력되어야 합니다. 경계값 120.0 이 어느 쪽인지 주의하세요.

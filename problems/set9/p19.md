# 약수 도감

체셔 고양이는 숫자를 하나 받으면 그 수를 나누어떨어지게 하는 수를 모두 도감에 적습니다. `while` 문으로 도감을 완성해 주세요.

## 지시사항
1. 양의 정수 `int num` (1 이상 100 이하)을 입력받으세요.
2. `while` 문을 사용해 1 부터 `num` 까지 확인하면서 `num` 의 약수를 작은 수부터 한 줄에 하나씩 출력하세요.
3. 약수를 모두 출력한 뒤 `개수: ○` 를, 이어서 `합: ○` (약수들의 합)를 각각 한 줄에 출력하세요.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
6
```
## 출력 예시 1
```
1
2
3
6
개수: 4
합: 12
```

## 입력 예시 2
```
16
```
## 출력 예시 2
```
1
2
4
8
16
개수: 5
합: 31
```

## Tips
반복 변수를 올리는 문장(`i++`)을 빠뜨리면 반복문이 끝나지 않습니다. 개수와 합을 세는 변수는 반복 전에 0 으로 두세요.

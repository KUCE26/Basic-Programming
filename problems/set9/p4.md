# 비밀 암호 한 칸 밀기

엘리스 토끼는 친구에게 보내는 쪽지를 알파벳 한 칸씩 밀어서 암호로 만듭니다. 문자 하나를 입력받아 아스키 코드와 다음 문자를 알려 주세요.

## 지시사항
1. 영문자 하나를 입력받아 `char` 변수에 저장하세요. 입력은 `A`~`Y` 또는 `a`~`y` 중 하나입니다.
2. 그 문자의 아스키 코드를 `아스키: ○○` 형식으로 출력하세요. (`%d`)
3. 문자에 1을 더한 다음 문자를 `다음 문자: ○` 형식으로 출력하세요. (`%c`)

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
A
```
## 출력 예시 1
```
아스키: 65
다음 문자: B
```

## 입력 예시 2
```
k
```
## 출력 예시 2
```
아스키: 107
다음 문자: l
```

## Tips
같은 `char` 값이라도 `%d` 로 출력하면 아스키 코드 번호, `%c` 로 출력하면 문자가 됩니다. `'A' + 1` 은 `'B'` 입니다.

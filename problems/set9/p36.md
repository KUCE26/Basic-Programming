# 체셔 고양이의 미소 세기

체셔 고양이는 단어 속에서 자기가 좋아하는 글자가 몇 번 나오는지 세는 놀이를 합니다.

## 지시사항
1. 공백 없는 영문·숫자 단어와 글자 하나를 한 줄에 공백으로 구분해 입력받으세요. 단어 길이는 1 이상 100 이하이며, 글자는 `scanf(" %c")` 로 받습니다.
2. 단어를 한 글자씩 훑으며 입력받은 글자와 같은 글자(대소문자를 구분합니다)가 몇 개인지 세세요. 널 문자 `'\0'` 를 만나면 반복을 끝냅니다.
3. 첫 줄에 `개수: ○` 를 출력하세요.
4. 둘째 줄에 `처음 위치: ○` 를 출력하세요. 처음 나타난 글자의 인덱스(첫 글자는 0)이며, 단어에 그 글자가 없으면 -1 을 출력합니다.

## 시작 코드
```c
#include <stdio.h>
#include <string.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
Wonderland d
```
## 출력 예시 1
```
개수: 2
처음 위치: 3
```

## 입력 예시 2
```
Cheshire h
```
## 출력 예시 2
```
개수: 2
처음 위치: 1
```

## Tips
단어의 길이를 따로 구하지 않아도 `s[i] != '\0'` 를 반복 조건으로 쓸 수 있습니다. 글자 입력 앞에 공백을 둔 `" %c"` 는 앞쪽 공백을 건너뜁니다. 대문자 `A` 와 소문자 `a` 는 서로 다른 글자입니다.

# 장부에 적는 숫자들

도마뱀 빌이 장부에 숫자를 적다가 0 을 적으면 하루 장부를 마칩니다. 마감 때 적은 숫자의 개수와 총합을 알려 주세요.

## 지시사항
1. `do-while` 문을 사용해 정수를 한 개씩 `int x` 에 입력받으세요. 입력은 절댓값이 1000 이하인 정수들이며, 0 이 입력되면 입력이 끝납니다. 입력 개수는 100개 이하입니다.
2. 0 을 제외한 숫자만 개수에 세고 총합에 더하세요. (0 이 맨 처음에 입력될 수도 있습니다.)
3. 입력이 끝나면 첫째 줄에 `개수: ○`, 둘째 줄에 `총합: ○` 를 출력하세요.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
1
2
3
0
```
## 출력 예시 1
```
개수: 3
총합: 6
```

## 입력 예시 2
```
2
5
1
7
0
```
## 출력 예시 2
```
개수: 4
총합: 15
```

## Tips
`do-while` 은 조건을 검사하기 전에 몸통을 먼저 한 번 실행합니다. 입력받은 직후 값이 0 인지 아닌지 `if` 로 구분해서 처리하세요.

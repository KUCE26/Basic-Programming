# 놀이기구 대기 시간

토끼 놀이공원 전광판은 놀이기구 약어 한 글자를 입력하면 대기 시간을 알려 줍니다. 약어에 맞는 안내 문장을 출력해 보세요.

## 지시사항
1. 놀이기구 약어를 `char ride` 에 입력받으세요. (`" %c"` 사용)
2. `switch` 문을 사용해 약어에 맞는 문장을 출력하세요. `r` 롤러코스터 `40분`, `c` 회전목마 `10분`, `f` 관람차 `25분`, `b` 범퍼카 `15분` 입니다.
3. 문장 형식은 `롤러코스터 대기 시간은 40분입니다.` 처럼 놀이기구 이름과 시간만 바뀝니다.
4. 표에 없는 약어(대문자 포함)는 `그런 놀이기구는 없습니다.` 를 출력하세요.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
r
```
## 출력 예시 1
```
롤러코스터 대기 시간은 40분입니다.
```

## 입력 예시 2
```
x
```
## 출력 예시 2
```
그런 놀이기구는 없습니다.
```

## Tips
`case` 끝마다 `break` 를 써야 아래 `case` 로 흘러가지 않습니다. 어떤 `case` 에도 맞지 않을 때의 처리는 `default` 에 씁니다.

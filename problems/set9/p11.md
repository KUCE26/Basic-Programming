# 자전거 평균 속도

엘리스 토끼가 자전거로 달린 거리(미터)와 걸린 시간(초)을 기록했습니다. 시속(km/h)으로 바꿔서 평균 속도를 알아보세요.

## 지시사항
1. 달린 거리(m)와 걸린 시간(초)을 이 순서대로 공백으로 구분해 한 줄에 입력받아 `double` 변수 두 개에 저장하세요. (거리 1 이상 100000 이하, 시간 1 이상 36000 이하, 둘 다 양수)
2. 먼저 거리를 시간으로 나눠 초속(m/s)을 구한 뒤, 1초에 1미터가 시속 3.6킬로미터이므로 그 값에 3.6 을 곱해 시속(km/h)을 구하세요. (계산 순서를 지키세요.)
3. 평균 속도를 소수점 둘째 자리까지 `평균 속도: ○○.○○km/h` 형식으로 출력하세요.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
1500 240
```
## 출력 예시 1
```
평균 속도: 22.50km/h
```

## 입력 예시 2
```
100 12
```
## 출력 예시 2
```
평균 속도: 30.00km/h
```

## Tips
거리와 시간을 `double` 로 받으면 나눗셈이 정수 나눗셈이 되는 걱정이 없습니다. `scanf` 에서 `double` 은 `%lf` 입니다.

# 시계 토끼의 시계

흰 토끼의 시계는 늘 15분씩 느립니다. 시계의 시와 분을 포인터로 접근해 15분을 더해 시각을 고쳐 주세요.

## 지시사항
1. 정수 `hour` 와 `minute` 을 한 줄에 공백으로 구분해 입력받으세요. hour 는 0 이상 23 이하, minute 은 0 이상 59 이하입니다.
2. `hour` 를 가리키는 포인터 `ph`, `minute` 을 가리키는 포인터 `pm` 을 선언하고 각각의 주소로 초기화하세요.
3. `hour` 와 `minute` 이라는 변수 이름을 직접 쓰지 말고 `ph`, `pm` 만 사용해 시각에 15분을 더하세요. 분이 60 이상이 되면 60 을 빼고 시를 1 올리며, 시가 24 가 되면 0 으로 만듭니다.
4. `시각 ○:○` 형태로 한 줄 출력하세요. 시와 분은 각각 항상 두 자리로 출력하고 한 자리 수는 앞에 0 을 붙입니다(예: `시각 09:05`). 출력은 `hour`, `minute` 변수 값으로 하세요.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
9 30
```
## 출력 예시 1
```
시각 09:45
```

## 입력 예시 2
```
23 50
```
## 출력 예시 2
```
시각 00:05
```

## Tips
한 자리 수 앞에 0 을 붙여 두 자리로 맞추는 출력 서식을 찾아보세요. 분이 정확히 60 이 되는 경우(45 분 입력)도 확인해 보세요.

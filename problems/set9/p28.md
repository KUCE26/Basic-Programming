# 짝수 탑 쌓기

토끼가 2, 4, 6, ... 번 블록만 골라 탑을 쌓습니다. 블록 번호의 합을 재귀 함수로 구해 보세요.

## 지시사항
1. 정수 `n` 을 매개변수로 받아 2 부터 n 까지 짝수의 합을 반환하는 `int even_sum(int n)` 을 **재귀 함수**로 정의하세요. n 이 2 보다 작으면 0 을 반환합니다. 반복문은 쓰지 않습니다.
2. 함수 원형은 `main()` 위에 선언하세요.
3. `main()` 에서 정수 `n` 을 입력받으세요(-100 이상 100 이하).
4. n 이 0 보다 작으면 `0 이상의 수를 입력하세요.` 를 출력합니다. 아니면 `2부터 ○까지 짝수의 합: ○` 를 출력합니다(처음 ○ 는 입력한 n 입니다). 출력 뒤에는 줄을 바꿉니다.

## 시작 코드
```c
#include <stdio.h>

int even_sum(int n);

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}

// even_sum() 을 여기에 정의하세요.
```

## 입력 예시 1
```
10
```
## 출력 예시 1
```
2부터 10까지 짝수의 합: 30
```

## 입력 예시 2
```
7
```
## 출력 예시 2
```
2부터 7까지 짝수의 합: 12
```

## Tips
n 이 짝수이면 `n + even_sum(n - 2)`, 홀수이면 `even_sum(n - 1)` 로 문제를 줄입니다. 더 이상 줄일 수 없는 경우(종료 조건)를 먼저 쓰세요.

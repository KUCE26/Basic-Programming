# 재채점 가산점

하트 여왕이 재시험 점수를 모두 올려 주기로 했습니다. 토끼 조교는 학생들의 점수를 받아 적은 뒤 전원에게 가산점을 줍니다.

## 지시사항
1. 학생 수 `n` 을 입력받으세요. n 은 1 이상 20 이하입니다. 점수를 저장할 배열은 크기 20 으로 선언하세요.
2. n 개의 점수(0 이상 100 이하 정수)를 공백이나 줄바꿈으로 구분해 입력받아 배열에 저장하세요.
3. 반복문으로 모든 점수에 5점을 더하세요. 단, 100점을 넘으면 100점으로 맞춥니다.
4. 보정된 점수를 첫 줄에 공백 한 칸으로 구분해 출력하세요(마지막 점수 뒤에는 공백 없이 줄바꿈).
5. 둘째 줄에 `만점자: ○명` 을 출력하세요. 보정 후 100점인 학생 수입니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
5
10 20 30 40 50
```
## 출력 예시 1
```
15 25 35 45 55
만점자: 0명
```

## 입력 예시 2
```
6
95 96 100 94 99 0
```
## 출력 예시 2
```
100 100 100 99 100 5
만점자: 4명
```

## Tips
반복문의 범위는 `i < n` 입니다. 100 을 넘는지 검사하는 `if` 는 5점을 더한 뒤에 둡니다.

# 달리기 메달 판정

토끼 마을 달리기 대회의 기록 점수에 따라 메달을 나눠 주려 합니다. 점수를 입력받아 어떤 메달을 받는지 알려 주세요.

## 지시사항
1. 점수(0 이상 100 이하의 정수)를 입력받아 `int score` 에 저장하세요.
2. 점수가 90점 이상이면 금메달, 75점 이상이면 은메달, 60점 이상이면 동메달, 그보다 낮으면 메달 없음입니다. `if`-`else if`-`else` 로 나누세요.
3. `○○점: ○○○` 형식으로 한 줄 출력하세요. 뒤쪽에는 `금메달`, `은메달`, `동메달`, `메달 없음` 중 하나를 씁니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
95
```
## 출력 예시 1
```
95점: 금메달
```

## 입력 예시 2
```
62
```
## 출력 예시 2
```
62점: 동메달
```

## Tips
`else if` 는 앞의 조건이 거짓일 때만 검사되므로 위에서부터 큰 기준을 먼저 씁니다. 정확히 90, 75, 60 일 때 어느 메달인지 확인해 보세요.

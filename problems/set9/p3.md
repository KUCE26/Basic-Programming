# 간식 나눠 주기

엘리스 토끼에게 당근 쿠키가 있습니다. 친구들에게 똑같이 나누어 주면 몇 개씩 돌아가고 몇 개가 남는지, 그리고 정확히 나누면 몇 개씩인지 알아보려고 해요.

## 지시사항
1. 쿠키 수 `a` 와 친구 수 `b` 를 공백으로 구분해 한 줄에 정수로 입력받으세요. (`a` 는 0 이상, `b` 는 1 이상)
2. 정수 나눗셈의 몫을 `몫: ○○` 형식으로 출력하세요.
3. 나머지를 `나머지: ○○` 형식으로 출력하세요.
4. `(double)` 로 형 변환하여 나눈 값을 소수점 셋째 자리까지 `실수 나눗셈: ○.○○○` 형식으로 출력하세요.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
17 5
```
## 출력 예시 1
```
몫: 3
나머지: 2
실수 나눗셈: 3.400
```

## 입력 예시 2
```
7 2
```
## 출력 예시 2
```
몫: 3
나머지: 1
실수 나눗셈: 3.500
```

## Tips
`a / b` 는 둘 다 정수라 소수점이 버려집니다. `(double)a / b` 처럼 한쪽을 먼저 `double` 로 바꿔야 실수 나눗셈이 됩니다. `(double)(a / b)` 는 이미 버려진 뒤라 소용없어요.

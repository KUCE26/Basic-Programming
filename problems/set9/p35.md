# 토끼굴 비밀번호

토끼굴 문 앞에서 앨리스는 비밀번호를 최대 세 번까지 말해 볼 수 있습니다. 비밀번호는 `wonderland` 이며 대소문자를 구분합니다.

## 지시사항
1. 공백 없는 영문·숫자 단어 세 개를 입력받으세요(공백이나 줄바꿈으로 구분, 각 길이 1 이상 50 이하). 앨리스가 차례대로 말한 시도입니다.
2. `strcmp` 로 각 시도를 비밀번호 `wonderland` 와 비교하세요. 시도를 앞에서부터 차례로 검사하며 `○번째 시도: 실패` 또는 `○번째 시도: 성공` 을 한 줄씩 출력합니다(번호는 1 부터).
3. 성공한 시도가 나오면 그 뒤의 시도는 검사하지 않고 반복을 끝냅니다.
4. 세 번 모두 실패하면 마지막에 `문이 영원히 잠겼습니다` 를 한 줄 더 출력하세요.

## 시작 코드
```c
#include <stdio.h>
#include <string.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
rabbit Wonderland wonderland
```
## 출력 예시 1
```
1번째 시도: 실패
2번째 시도: 실패
3번째 시도: 성공
```

## 입력 예시 2
```
wonderland a b
```
## 출력 예시 2
```
1번째 시도: 성공
```

## Tips
`strcmp(a, b)` 는 두 문자열이 같을 때 0 을 돌려줍니다. 문자열을 `==` 로 비교하면 안 됩니다. 입력 세 개가 모두 주어지므로, 성공 뒤에 남은 입력은 읽지 않아도 상관없습니다.

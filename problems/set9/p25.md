# 당근 창고 재고

토끼의 당근 창고 재고는 어느 함수에서든 확인하고 바꿀 수 있어야 합니다. 재고를 전역 변수로 두고, 수확과 사용을 함수로 나눠 관리해 보세요.

## 지시사항
1. 정수형 전역 변수 `stock` 을 함수들 바깥에 선언하세요.
2. 반환값이 없고 정수 `n` 을 매개변수로 받는 `void harvest(int n)` 을 정의하세요. `stock` 에 n 을 더한 뒤 `수확 후: ○개` 를 출력합니다.
3. 반환값이 없고 정수 `n` 을 매개변수로 받는 `void use(int n)` 을 정의하세요. `stock` 이 n 이상이면 n 을 빼고 `사용 후: ○개` 를 출력하고, 부족하면 재고는 그대로 두고 `재고가 부족합니다.` 를 출력합니다.
4. `main()` 에서 정수 세 개 `a`, `b`, `c` 를 한 줄에 공백으로 구분해 입력받으세요(모두 0 이상 100 이하). `stock` 을 a 로 정하고 `처음 재고: ○개` 를 출력한 다음, `harvest(b)`, `use(c)` 순서로 호출하세요.
5. 마지막 줄에 `남은 재고: ○개` 를 출력하세요. 출력은 모두 한 줄에 하나씩입니다.

## 시작 코드
```c
#include <stdio.h>

int stock;

void harvest(int n);
void use(int n);

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}

// harvest(), use() 를 여기에 정의하세요.
```

## 입력 예시 1
```
10 5 8
```
## 출력 예시 1
```
처음 재고: 10개
수확 후: 15개
사용 후: 7개
남은 재고: 7개
```

## 입력 예시 2
```
3 2 9
```
## 출력 예시 2
```
처음 재고: 3개
수확 후: 5개
재고가 부족합니다.
남은 재고: 5개
```

## Tips
전역 변수는 모든 함수에서 같은 변수를 공유합니다. 함수 안에서 `stock` 을 다시 선언하지 말고 그대로 쓰세요. 사용 가능 여부는 `stock >= n` 으로 비교합니다.

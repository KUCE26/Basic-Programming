# 야옹 간판 그리기

엘리스 토끼가 고양이 가게의 간판을 아스키 아트로 만들려고 합니다. 입력은 없고, 아래 예시와 똑같은 그림을 출력하면 됩니다.

## 지시사항
1. 입력은 없습니다. 아래 출력 예시와 글자 하나까지 똑같이 출력하세요.
2. 각 줄은 맨 앞에 탭(`\t`) 한 개로 들여쓰기합니다. 첫째 줄(귀)과 셋째 줄(입) 은 탭 뒤에 공백 1개가 더 있고, 나머지 세 줄은 탭 바로 뒤에 글자가 옵니다.
3. 백슬래시는 `\\`, 큰따옴표는 `\"`, 작은따옴표는 `\'`, 물음표는 `\?` 로 쓸 수 있습니다.
4. 그림은 총 5줄입니다: 귀와 얼굴 두 줄, 몸 한 줄, 대사 두 줄.

## 시작 코드

#include <stdio.h>

    // 지시사항을 참고하여 코드를 작성하세요.

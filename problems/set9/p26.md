# 모래시계 정원

하트 여왕의 정원에 별 모양 모래시계 화단을 만들려고 합니다. 한 줄을 그리는 함수를 만들어 여러 번 호출해 보세요.

## 지시사항
1. 정수 `space` 와 `star` 를 매개변수로 받는 `void print_line(int space, int star)` 를 정의하세요. 공백 space 개, 별(`*`) star 개를 차례로 출력하고 줄을 바꿉니다.
2. `main()` 에서 정수 `n` 을 입력받으세요(1 이상 6 이하).
3. 위쪽 절반은 별 개수가 (2 × n - 1) 개인 줄에서 시작해 2 개씩 줄어들어 1 개가 될 때까지, 아래쪽 절반은 별 3 개 줄에서 시작해 2 개씩 늘어나 (2 × n - 1) 개가 될 때까지 그립니다. 가운데 별 1 개 줄은 한 번만 출력하세요.
4. 모든 줄은 별이 가운데 정렬되도록 앞에 공백을 두며, 가장 긴 줄(별 (2 × n - 1) 개)은 앞 공백이 없습니다. 줄 끝에는 공백을 출력하지 않습니다.
5. 모든 줄은 반드시 `print_line()` 을 호출해서 출력하세요.

## 시작 코드
```c
#include <stdio.h>

void print_line(int space, int star);

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}

// print_line() 을 여기에 정의하세요.
```

## 입력 예시 1
```
4
```
## 출력 예시 1
```
*******
 *****
  ***
   *
  ***
 *****
*******
```

## 입력 예시 2
```
1
```
## 출력 예시 2
```
*
```

## Tips
같은 모양의 한 줄을 여러 번 그릴 때는 함수로 묶어 두면 편합니다. 줄 번호 i 에 따라 공백 수와 별 수가 어떻게 변하는지 먼저 표로 적어 보세요.

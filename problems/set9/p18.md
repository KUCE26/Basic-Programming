# 도마뱀 빌의 구구단 노트

도마뱀 빌은 구구단을 한 단 전체가 아니라 원하는 곳까지만 외우고 싶어 합니다. 단과 끝 번호를 입력받아 식을 적어 주고 결과의 합도 알려 주세요.

## 지시사항
1. 단 `int dan` (2 이상 9 이하)과 곱하는 수의 끝 `int last` (1 이상 9 이하)를 공백으로 구분해 입력받으세요.
2. `for` 문으로 1 부터 `last` 까지 `○ x ○ = ○` 형식(공백 포함)으로 한 줄씩 출력하세요. 예: `3 x 4 = 12`
3. 마지막 줄에 지금까지 출력한 결괏값을 모두 더해 `합계: ○` 로 출력하세요.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
3 4
```
## 출력 예시 1
```
3 x 1 = 3
3 x 2 = 6
3 x 3 = 9
3 x 4 = 12
합계: 30
```

## 입력 예시 2
```
9 1
```
## 출력 예시 2
```
9 x 1 = 9
합계: 9
```

## Tips
합계를 저장할 변수는 반복문 앞에서 0 으로 초기화해 두어야 합니다.

# 거꾸로 읽는 일기

체셔 고양이는 일기를 거꾸로 읽는 것을 좋아합니다. 하루하루 적은 숫자들을 뒤에서부터 읽어 주세요.

## 지시사항
1. 정수 개수 `n` 을 입력받으세요. n 은 1 이상 30 이하입니다. 배열은 크기 30 으로 선언하세요.
2. n 개의 정수(-100 이상 100 이하)를 입력받아 배열에 저장하세요.
3. 첫 줄에 저장한 정수들을 마지막 것부터 첫 번째 것까지 공백 한 칸으로 구분해 출력하세요(마지막 수 뒤에는 공백 없음).
4. 둘째 줄에 `합계: ○` 를 출력하세요. 모든 정수의 합입니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
5
3 -1 4 1 -5
```
## 출력 예시 1
```
-5 1 4 -1 3
합계: 2
```

## 입력 예시 2
```
1
7
```
## 출력 예시 2
```
7
합계: 7
```

## Tips
거꾸로 출력하려면 인덱스를 `n - 1` 에서 시작해 0 까지 줄여 가면 됩니다. 공백은 '마지막 원소를 출력한 뒤에는 붙이지 않는다'는 조건으로 정리하세요.

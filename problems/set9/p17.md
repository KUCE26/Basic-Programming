# 토끼 로켓 카운트다운

엘리스 토끼의 로켓은 연료를 아끼려고 숫자를 하나 건너뛰며 카운트다운을 합니다. 발사 전 전광판에 나올 숫자를 출력해 주세요.

## 지시사항
1. 시작 숫자를 `int n` 에 입력받으세요. n 은 1 이상 30 이하의 정수입니다.
2. `for` 문을 사용해 n 부터 시작해 2씩 줄여 가며, 값이 1 이상인 동안 `현재 숫자: ○` 를 한 줄씩 출력하세요.
3. 반복이 끝나면 마지막 줄에 `발사!` 를 출력하세요.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    int n;
    scanf("%d", &n);

    for ( ; ; ) {
        // 지시사항을 참고하여 코드를 작성하세요.
    }

    return 0;
}
```

## 입력 예시 1
```
9
```
## 출력 예시 1
```
현재 숫자: 9
현재 숫자: 7
현재 숫자: 5
현재 숫자: 3
현재 숫자: 1
발사!
```

## 입력 예시 2
```
10
```
## 출력 예시 2
```
현재 숫자: 10
현재 숫자: 8
현재 숫자: 6
현재 숫자: 4
현재 숫자: 2
발사!
```

## Tips
`for (초기식; 조건식; 증감식)` 의 세 칸을 각각 채우세요. 증감식에는 `n--` 대신 2씩 줄이는 식이 들어갑니다. 시작 숫자가 짝수인지 홀수인지에 따라 마지막 숫자가 2 또는 1 이 됩니다.

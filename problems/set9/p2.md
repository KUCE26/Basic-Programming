# 원형 화단 울타리

엘리스 토끼는 원형 화단을 만들려고 합니다. 반지름을 알면 울타리 길이(둘레)와 흙을 깔 면적(넓이)을 구할 수 있어요.

## 지시사항
1. `#define` 으로 `PI` 를 `3.14159` 로 정의하세요.
2. `const int TWO = 2;` 처럼 `const` 로 상수 `TWO` 를 만드세요(둘레 계산에 사용).
3. 반지름을 실수(`double`)로 입력받으세요.
4. 둘레(`TWO * PI * 반지름`)를 `둘레: ○○.○○` 형식으로, 넓이(`PI * 반지름 * 반지름`)를 `넓이: ○○.○○` 형식으로 각각 한 줄에 출력하세요. 소수점 둘째 자리까지 출력합니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
5.0
```
## 출력 예시 1
```
둘레: 31.42
넓이: 78.54
```

## 입력 예시 2
```
1.5
```
## 출력 예시 2
```
둘레: 9.42
넓이: 7.07
```

## Tips
`#define` 줄 끝에는 세미콜론을 붙이지 않습니다. `const` 변수는 선언할 때 값을 정하면 이후 바꿀 수 없습니다.

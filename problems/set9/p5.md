# 고장난 캘린더

엘리스 토끼의 전자 캘린더가 고장 나서 날짜와 시간이 `2026-10-26T01:08:05` 처럼 붙어서 나옵니다. 이 문자열을 읽어 우리말로 읽기 좋게 바꿔 주세요.

## 지시사항
1. 입력은 `연-월-일T시:분:초` 꼴 한 줄입니다. `scanf` 의 형식 문자열에 `-`, `T`, `:` 를 그대로 넣어 여섯 개의 정수로 한 번에 입력받으세요.
2. `○○○○년 ○○월 ○○일 ○○시 ○○분 ○○초` 형식으로 출력하세요.
3. 연도는 그대로, 월·일·시·분·초는 항상 두 자리로 맞추어(한 자리면 앞에 0) 출력합니다. (`%02d`)

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
2026-10-26T01:08:05
```
## 출력 예시 1
```
2026년 10월 26일 01시 08분 05초
```

## 입력 예시 2
```
2024-02-29T23:59:00
```
## 출력 예시 2
```
2024년 02월 29일 23시 59분 00초
```

## Tips
형식 문자열의 공백이 아닌 문자는 입력에서 그대로 일치해야 읽힙니다. `%02d` 는 폭 2, 빈 자리를 0으로 채웁니다.

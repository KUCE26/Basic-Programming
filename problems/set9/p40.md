# 초대장 사전순 정렬

하트 여왕이 초대할 손님의 이름 목록을 받았습니다. 시종이 qsort 로 이름을 사전 순으로 정렬해 초대장을 한 줄씩 적습니다.

## 지시사항
1. 정수 `n` 을 입력받으세요. n 은 1 이상 10 이하입니다.
2. 영문 소문자로만 이루어진 이름 n 개를 `scanf("%s", ...)` 로 입력받아 `char names[10][20]` 에 저장하세요. 이름의 길이는 1 이상 19 이하이고, 같은 이름이 여러 번 나올 수 있습니다.
3. `qsort` 와 `strcmp` 를 이용해 이름을 사전 순(오름차순)으로 정렬하세요. 비교 함수는 시작 코드의 `cmp` 를 사용합니다.
4. 정렬된 이름을 한 줄에 하나씩 출력하세요.
5. 마지막 줄에 `가장 앞선 이름: ○` 를 출력하세요.

## 시작 코드
```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int cmp(const void *a, const void *b) {
    return strcmp((const char *)a, (const char *)b);
}

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
4
alice rabbit cat queen
```
## 출력 예시 1
```
alice
cat
queen
rabbit
가장 앞선 이름: alice
```

## 입력 예시 2
```
3
bob bob alice
```
## 출력 예시 2
```
alice
bob
bob
가장 앞선 이름: alice
```

## Tips
`qsort(names, n, sizeof(names[0]), cmp);` 처럼 배열 이름, 원소 개수, 원소 하나의 크기, 비교 함수를 순서대로 넘깁니다.

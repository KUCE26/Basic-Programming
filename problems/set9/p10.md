# 체셔의 두 번째 수수께끼

체셔 고양이가 새 수수께끼를 냈습니다. "나는 어떤 수에 3917 을 더하고, 1500 을 뺀 다음, 12 를 곱하고 80 으로 나눴어. 그랬더니 y 가 나오더라구!" 체셔가 처음 생각한 수를 거꾸로 계산해서 알아맞혀 보세요.

## 지시사항
1. 체셔가 말해 준 최종 수 `y` 를 `int` 로 입력받으세요. (400 이상 1000 이하)
2. 체셔가 한 계산을 반대로 되돌리세요. 나누기는 곱하기로, 곱하기는 나누기로, 더하기는 빼기로, 빼기는 더하기로 바꾸고 순서도 거꾸로 합니다.
3. 나눗셈은 정수 나눗셈이 되지 않도록 실수(`double`)로 계산하세요. 필요하면 `(double)` 로 형 변환을 하세요.
4. 체셔가 처음 생각한 수를 소수점 둘째 자리까지 `체셔가 생각한 수는 ○○.○○입니다.` 형식으로 출력하세요.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
513
```
## 출력 예시 1
```
체셔가 생각한 수는 1003.00입니다.
```

## 입력 예시 2
```
400
```
## 출력 예시 2
```
체셔가 생각한 수는 249.67입니다.
```

## Tips
정수끼리 나누면 소수 부분이 버려집니다. 둘 중 하나만 `double` 이어도 나눗셈은 실수로 계산됩니다. 거꾸로 계산할 때는 순서를 헷갈리지 않게 한 단계마다 변수를 하나씩 쓰세요.

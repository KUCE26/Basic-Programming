# 한 줄 메아리

엘리스 토끼가 산에서 한 줄 외치면 메아리가 되돌아옵니다. 한 줄을 입력받아 `fputs` 와 `puts` 로 각각 출력해 보세요.

## 지시사항
1. `char str[10];` 배열을 선언하고 `fgets(str, 10, stdin)` 으로 한 줄을 입력받으세요. 입력은 공백을 포함할 수 있고 길이는 1자 이상 8자 이하입니다.
2. `fputs(str, stdout)` 으로 한 번 출력하세요.
3. `puts(str)` 로 한 번 출력하세요.
4. 마지막으로 `끝` 을 한 줄 출력하세요.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    char str[10];

    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
hello
```
## 출력 예시 1
```
hello
hello

끝
```

## 입력 예시 2
```
a b c
```
## 출력 예시 2
```
a b c
a b c

끝
```

## Tips
`fgets` 는 입력의 줄바꿈 문자까지 배열에 저장합니다. `fputs` 는 문자열을 그대로 출력하고, `puts` 는 문자열 뒤에 줄바꿈을 하나 더 붙이므로 두 번째 출력 뒤에는 빈 줄이 생깁니다. 9자 이상이면 줄바꿈이 배열에 들어가지 못해 결과가 달라지므로 입력은 8자 이하로 합니다.

# 오 단위 건너뛰기 합산

도마뱀 빌이 1 번부터 차례로 번호표를 모아 합계를 냅니다. 5 의 배수 번호표는 불길하다며 빼고, 합계가 목표를 넘으면 그 즉시 멈춥니다.

## 지시사항
1. 목표 값 `int n` 을 입력받으세요. n 은 1 이상 500 이하의 정수입니다.
2. 1 부터 1 씩 늘려 가며 번호를 합계에 더하세요. 단, 5 의 배수인 번호는 `continue` 로 건너뛰어 더하지 않습니다.
3. 번호를 더한 직후 합계가 n 보다 커졌으면 `break` 로 반복을 끝내세요. 합계가 n 과 같은 경우는 계속 진행합니다.
4. 첫째 줄에 `마지막 번호: ○`, 둘째 줄에 `합계: ○` 를 출력하세요. 마지막 번호는 합계에 마지막으로 더한 번호입니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
100
```
## 출력 예시 1
```
마지막 번호: 16
합계: 106
```

## 입력 예시 2
```
1
```
## 출력 예시 2
```
마지막 번호: 2
합계: 3
```

## Tips
반복 횟수가 정해져 있지 않으니 `for (i = 1; ; i++)` 처럼 조건식을 비워 두거나 `while (1)` 을 써도 됩니다. `while` 을 쓴다면 `continue` 전에 번호를 증가시켜야 무한 루프에 빠지지 않습니다.

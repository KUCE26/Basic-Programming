# 당근 수확 장부

엘리스 토끼네 텃밭에서 친구들이 한 명씩 수확한 당근 개수를 말해 줍니다. 더 이상 말할 친구가 없으면 음수를 외쳐 끝을 알립니다.

## 지시사항
1. 친구가 수확한 당근 개수를 `int carrot` 에 입력받는 일을 무한 루프 `while (1)` 안에서 반복하세요. 당근 개수는 0 이상 1000 이하이고, 끝을 알리는 값은 음수(-1 이상 -100 이하)입니다.
2. 입력받은 값이 음수이면 `break` 로 반복문을 빠져나오세요. 이 음수는 합계나 인원수에 포함하지 않습니다.
3. 음수가 아닐 때는 당근 개수를 합계에 더하고, 인원수를 1 늘리세요.
4. 반복이 끝나면 첫째 줄에 `참가한 친구: ○명`, 둘째 줄에 `당근 총합: ○개` 를 출력하세요.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    int carrot, sum = 0, count = 0;

    while (1) {
        // 지시사항을 참고하여 코드를 작성하세요.
    }

    return 0;
}
```

## 입력 예시 1
```
3
5
2
-1
```
## 출력 예시 1
```
참가한 친구: 3명
당근 총합: 10개
```

## 입력 예시 2
```
10
-4
```
## 출력 예시 2
```
참가한 친구: 1명
당근 총합: 10개
```

## Tips
음수가 맨 처음에 입력되면 인원수와 합계는 모두 0 이 됩니다. `break` 는 가장 안쪽 반복문 하나만 빠져나옵니다.

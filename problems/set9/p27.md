# 가장 큰 당근, 가장 작은 당근

당근 세 개의 무게를 비교해 가장 큰 것과 가장 작은 것을 찾으려 합니다. 함수의 원형을 먼저 선언하고 정의는 main 아래에 두세요.

## 지시사항
1. 정수 세 개를 매개변수로 받아 가장 큰 값을 반환하는 `int max3(int a, int b, int c)` 와 가장 작은 값을 반환하는 `int min3(int a, int b, int c)` 를 정의하세요. 두 함수의 원형은 `main()` 위에 선언하고, 정의는 `main()` 아래에 작성합니다.
2. `main()` 에서 정수 세 개를 한 줄에 공백으로 구분해 입력받으세요(음수도 가능, 절댓값 1000 이하).
3. 아래 세 줄을 출력하세요. 각 줄은 줄바꿈으로 끝납니다. `차이` 는 최댓값에서 최솟값을 뺀 값이며, 반드시 두 함수의 반환값으로 계산하세요.
   - `최대: ○`
   - `최소: ○`
   - `차이: ○`

## 시작 코드
```c
#include <stdio.h>

int max3(int a, int b, int c);
int min3(int a, int b, int c);

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}

// max3(), min3() 을 여기에 정의하세요.
```

## 입력 예시 1
```
5 9 2
```
## 출력 예시 1
```
최대: 9
최소: 2
차이: 7
```

## 입력 예시 2
```
-3 -8 -1
```
## 출력 예시 2
```
최대: -1
최소: -8
차이: 7
```

## Tips
`return` 은 값을 호출한 곳으로 돌려줍니다. 반환된 값은 `printf` 안에서 바로 출력하거나 다른 식에 쓸 수 있습니다.

# void 상자 속 선물

체셔 고양이는 어떤 선물이든 담을 수 있는 void 상자를 가지고 있습니다. 상자에 정수 선물과 실수 선물을 번갈아 담았다가 꺼내 봅시다.

## 지시사항
1. 정수 `a` 와 실수 `b`(double) 를 한 줄에 공백으로 구분해 입력받으세요. a 는 -1000 이상 1000 이하, b 는 -1000.0 이상 1000.0 이하이며 소수점 아래 둘째 자리 이하로 주어집니다.
2. `void *vp` 를 선언하고 `a` 의 주소를 저장하세요. 형 변환(`int *`)을 거쳐 `a` 의 값을 두 배로 만든 뒤, 같은 방법으로 읽은 값을 `a : ○` 형식으로 출력하세요.
3. `vp` 에 `b` 의 주소를 저장하세요. 형 변환(`double *`)을 거쳐 `b` 의 값에 0.5 를 더한 뒤, 읽은 값을 `b : ○` 형식으로 출력하세요. 실수는 소수점 아래 둘째 자리까지 출력합니다.
4. 출력은 두 줄이며, 값 변경과 읽기는 반드시 `vp` 를 통해 하세요.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    int a;
    double b;
    void *vp;
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
10 3.5
```
## 출력 예시 1
```
a : 20
b : 4.00
```

## 입력 예시 2
```
-7 -0.25
```
## 출력 예시 2
```
a : -14
b : 0.25
```

## Tips
`void *` 는 그대로 `*` 연산을 할 수 없습니다. `*(int *)vp` 처럼 먼저 가리키는 대상의 자료형으로 형 변환한 뒤 간접 참조하세요. `double` 입력에 맞는 서식 지정자도 확인하세요.

# 모자 장수의 모자 값

모자 장수는 두 모자의 가격표를 비교하며 차를 마십니다. 한 모자는 포인터로 가리켜서 값을 확인하려 합니다.

## 지시사항
1. 정수 `a` 와 `b` 를 한 줄에 공백으로 구분해 입력받으세요. 두 값은 -1000 이상 1000 이하입니다.
2. 포인터 변수 `ptr` 을 선언하고 `a` 의 주소로 초기화하세요.
3. 첫 줄에 `ptr` 이 가리키는 값과 `b` 를 공백 한 칸으로 구분해 출력하세요.
4. 둘째 줄에는 두 값이 같으면 `값이 같아요.`, 다르면 `값이 달라요.` 를 출력하세요.
5. 그다음 `ptr` 을 통해서만 `a` 의 값을 `b` 의 값으로 바꾸세요(`a` 에 직접 대입하지 않습니다).
6. 셋째 줄에 `a: ○` 형태로 바뀐 `a` 의 값을 출력하세요.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
30 30
```
## 출력 예시 1
```
30 30
값이 같아요.
a: 30
```

## 입력 예시 2
```
12 -7
```
## 출력 예시 2
```
12 -7
값이 달라요.
a: -7
```

## Tips
포인터는 `int *ptr = &a;` 처럼 선언하며 초기화합니다. `*ptr` 에 값을 대입하면 `ptr` 이 가리키는 변수 `a` 가 바뀝니다.

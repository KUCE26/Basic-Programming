# 도도새의 끝말 잇기

도도새는 단어를 뒤에서부터 말하는 버릇이 있습니다. 'Elice' 를 말할 때 e, ce, ice, lice, Elice 순서로 말합니다.

## 지시사항
1. 공백 없는 영문 단어 하나를 `scanf("%s", ...)` 로 입력받으세요. 길이는 1 이상 100 이하입니다. 문자열을 저장할 `char` 배열은 널 문자까지 들어가도록 크기 101 로 선언하세요.
2. 단어의 마지막 글자 하나부터 시작해서, 한 글자씩 앞으로 늘려 가며 단어의 끝부분(접미사)을 한 줄에 하나씩 출력하세요. 마지막 줄은 단어 전체입니다.
3. 각 접미사는 `%c` 로 한 글자씩 출력하는 반복문으로 만드세요. 줄마다 출력이 끝나면 줄을 바꿉니다.

## 시작 코드
```c
#include <stdio.h>
#include <string.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
ABC
```
## 출력 예시 1
```
C
BC
ABC
```

## 입력 예시 2
```
Elice
```
## 출력 예시 2
```
e
ce
ice
lice
Elice
```

## Tips
문자열의 길이는 `strlen` 으로 구합니다(`string.h`). 가장 안쪽 반복문은 시작 인덱스 `i` 부터 마지막 글자(`n - 1`)까지 돕니다. 바깥 반복은 `i` 를 끝에서 앞으로 줄여 가며 돕니다.

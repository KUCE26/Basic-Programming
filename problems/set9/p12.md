# 숫자 두 개 비교표

엘리스 토끼가 숫자 카드 두 장을 뽑았습니다. 두 수의 관계를 1(참)과 0(거짓)으로 표시한 비교표를 만들어 보세요.

## 지시사항
1. 정수 두 개를 공백으로 구분해 한 줄에 입력받아 `int a`, `int b` 에 저장하세요. (-100 이상 100 이하)
2. `a > b: ○` 형식으로 a 가 b 보다 큰지 출력하세요. 참이면 1, 거짓이면 0 입니다.
3. `a == b: ○` 형식으로 두 수가 같은지, `a != b: ○` 형식으로 두 수가 다른지 출력하세요.
4. `둘 다 양수: ○` 형식으로 a 와 b 가 모두 0 보다 크면 1, 아니면 0 을 출력하세요.
5. `하나라도 짝수: ○` 형식으로 a 와 b 중 짝수가 하나라도 있으면 1, 아니면 0 을 출력하세요. (0 은 짝수입니다.)
6. `a가 짝수가 아님: ○` 형식으로 a 가 짝수가 아니면 1, 짝수이면 0 을 출력하세요. 논리 부정 연산자를 써 보세요.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
5 3
```
## 출력 예시 1
```
a > b: 1
a == b: 0
a != b: 1
둘 다 양수: 1
하나라도 짝수: 0
a가 짝수가 아님: 1
```

## 입력 예시 2
```
4 4
```
## 출력 예시 2
```
a > b: 0
a == b: 1
a != b: 0
둘 다 양수: 1
하나라도 짝수: 1
a가 짝수가 아님: 0
```

## Tips
관계·논리 연산의 결과는 정수 1 또는 0 이라서 `%d` 로 바로 출력할 수 있습니다. 음수를 2 로 나눈 나머지는 0 이거나 음수이니, 짝수는 "나머지가 0 인지" 로 판단하세요.

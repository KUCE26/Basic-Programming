# 거꾸로 읽는 암호

엘리스 토끼의 비밀 번호는 문자 3개입니다. 친구에게는 이것을 거꾸로 읽어서 알려 주려고 해요.

## 지시사항
1. 공백 없이 붙어 있는 문자 3개를 `getchar()` 로 3번 호출하여 읽고 `char` 변수에 저장하세요.
2. `putchar()` 를 3번 호출하여 읽은 순서의 반대로 출력하세요.
3. 마지막에 `putchar('\n')` 으로 줄바꿈을 출력하세요.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
abc
```
## 출력 예시 1
```
cba
```

## 입력 예시 2
```
XYZ
```
## 출력 예시 2
```
ZYX
```

## Tips
`getchar()` 는 한 글자를 읽고, `putchar(c)` 는 한 글자를 출력합니다. `printf` 와 달리 형식 지정자가 필요 없어요.

# 카드 병정의 삼중 포인터

카드 병정들은 명령을 한 단계씩 전달합니다. 숫자 하나를 포인터, 포인터의 포인터, 포인터의 포인터의 포인터로 차례로 가리키게 해 값을 읽고 고쳐 보세요.

## 지시사항
1. 정수 `num` 을 입력받으세요. `num` 은 -1000 이상 1000 이하입니다.
2. `ptr1` 은 `num` 을, `ptr2` 는 `ptr1` 을, `ptr3` 은 `ptr2` 를 가리키도록 선언하고 초기화하세요.
3. 첫 줄에 `ptr3`, `ptr2`, `ptr1` 을 통해 읽은 `num` 의 값을 이 순서대로 공백 한 칸으로 구분해 출력하세요.
4. `ptr3` 을 통해서만 `num` 에 저장된 값에서 7 을 뺀 값을 `num` 에 다시 저장하세요.
5. 둘째 줄에 이번에는 `ptr1`, `ptr2`, `ptr3` 순서로 읽은 값을 공백으로 구분해 출력하세요.
6. 셋째 줄에 `num: ○` 형태로 `num` 의 값을 출력하세요.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
100
```
## 출력 예시 1
```
100 100 100
93 93 93
num: 93
```

## 입력 예시 2
```
-3
```
## 출력 예시 2
```
-3 -3 -3
-10 -10 -10
num: -10
```

## Tips
`int ***ptr3` 는 세 번 `*` 를 붙여야 `num` 값에 닿습니다. 한 번만 붙이면 주소 값이 나오니 주의하세요.

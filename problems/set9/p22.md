# 체셔의 공배수 찻잔

체셔 고양이는 1부터 차례로 번호가 붙은 찻잔 중에서 두 가지 무늬가 동시에 새겨진 잔만 골라 쓰려고 합니다. 무늬 A 는 a 의 배수, 무늬 B 는 b 의 배수 번호에 새겨져 있습니다.

## 지시사항
1. 세 정수 `a`, `b`, `n` 을 한 줄에 공백으로 구분해 입력받으세요. a 와 b 는 2 이상 9 이하, n 은 1 이상 100 이하입니다.
2. `for` 문으로 1 부터 n 까지 번호를 살펴보면서, a 의 배수이면서 동시에 b 의 배수인 번호만 한 줄에 하나씩 출력하세요.
3. 조건에 맞지 않는 번호는 `continue` 로 건너뛰세요.
4. 번호 출력이 끝나면 마지막 줄에 `공배수: ○개` 를 출력하세요. 공배수가 하나도 없으면 `공배수: 0개` 입니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
2 3 20
```
## 출력 예시 1
```
6
12
18
공배수: 3개
```

## 입력 예시 2
```
4 6 50
```
## 출력 예시 2
```
12
24
36
48
공배수: 4개
```

## Tips
'둘 다 만족하지 않으면 건너뛴다' 는 조건을 만들 때 `&&` 와 `||` 의 차이에 주의하세요. 입력은 한 줄에 `%d %d %d` 로 받을 수 있습니다.

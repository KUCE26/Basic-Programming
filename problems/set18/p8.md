# 함수 자판기 연속 주문

엘리스 자판기에는 다섯 가지 계산 버튼이 있습니다. 손님이 0 번을 누를 때까지 계속 주문을 받으세요. 버튼마다 하는 일은 다르지만, 두 수를 받아 한 수를 돌려준다는 형태는 같으므로 함수 포인터 배열로 관리합니다.

## 지시사항
1. 시작 코드의 `add`(합), `sub`(앞의 수에서 뒤의 수를 뺀 값), `mul`(곱), `maxOf`(큰 값), `minOf`(작은 값)를 완성하세요.
2. `void run(int (*fp)(int, int))` 를 작성하세요. 두 정수를 입력받아 `fp` 로 계산한 뒤 `결괏값은 : ○` 를 한 줄에 출력합니다. 두 정수는 -10000 이상 10000 이하입니다.
3. 함수 포인터 배열 `int (*ops[5])(int, int)` 에 위 다섯 함수를 순서대로 넣으세요.
4. 메뉴 번호를 반복해서 입력받으세요. 1~5 이면 `ops[번호 - 1]` 을 `run` 에 넘겨 실행합니다. 1 은 합, 2 는 뺄셈, 3 은 곱, 4 는 큰 값, 5 는 작은 값입니다.
5. 0 이 입력되면 반복을 끝냅니다. 입력의 마지막에는 항상 0 이 있습니다.
6. 0 과 1~5 가 아닌 번호가 입력되면 `없는 메뉴입니다.` 를 출력하고, 두 정수는 입력받지 않은 채 다음 번호를 읽으세요.
7. 끝날 때 `처리한 연산: ○개` 를 출력하세요. 없는 메뉴는 세지 않습니다.

## Tips
배열 칸에 들어 있는 함수 포인터는 `ops[i](a, b)` 로 바로 호출할 수 있고, `run(ops[i])` 처럼 다른 함수에 인자로 넘길 수도 있습니다. 번호 범위 검사를 하지 않고 배열에 접근하지 않도록 주의하세요.

# 시간 쪼개기

하얀 토끼는 초 단위로 적힌 지각 시간을 시, 분, 초로 나누어 여왕에게 보고해야 합니다. 한 번에 결과 세 개를 돌려주는 함수를 만들어 주세요.

## 지시사항
1. `int hms(int total, int *h, int *m, int *s)` 함수를 정의하세요. 총 초 `total` 을 시간(`*h`), 남은 분(`*m`), 남은 초(`*s`) 로 나누어 포인터로 저장하고, 시간이 1 이상이면 1 을, 아니면 0 을 반환합니다.
2. `main` 에서 정수 `n` 을 입력받으세요. n 은 1 이상 10 이하입니다.
3. 다음 줄에 n 개의 정수를 입력받으세요. 각 값은 0 이상 359999 이하이며 총 초를 뜻합니다.
4. 각 값마다 한 줄씩 `○시간 ○분 ○초` 형태로 출력하세요. 분과 초는 각각 0 이상 59 이하입니다.
5. `hms` 의 반환값이 1 이면 같은 줄 끝에 공백 한 칸과 `(장시간)` 을 붙이세요.

## 시작 코드
```c
#include <stdio.h>

int hms(int total, int *h, int *m, int *s) {
    // 지시사항을 참고하여 완성하세요.
    return 0;
}

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
3
3725 59 0
```
## 출력 예시 1
```
1시간 2분 5초 (장시간)
0시간 0분 59초
0시간 0분 0초
```

## 입력 예시 2
```
4
60 3599 3600 359999
```
## 출력 예시 2
```
0시간 1분 0초
0시간 59분 59초
1시간 0분 0초 (장시간)
99시간 59분 59초 (장시간)
```

## Tips
나눗셈의 몫과 나머지를 이용하세요. 반환값은 하나뿐이지만 포인터 매개변수를 쓰면 호출한 쪽 변수 여러 개를 한꺼번에 바꿀 수 있습니다.

# 거북이의 가장 긴 단어

가짜 거북이가 한 줄짜리 노래 가사를 읊었습니다. 가사에서 단어가 몇 개인지, 가장 긴 단어는 무엇인지 문자 포인터로 찾아 주세요.

## 지시사항
1. `fgets` 로 한 줄(개행 제외 200 자 이하, 영문·숫자·공백·기호로만 구성)을 입력받으세요.
2. 여기서 '단어'는 영문 알파벳(대소문자)이 연속된 가장 긴 덩어리입니다. 알파벳이 아닌 문자(공백, 숫자, 기호)는 모두 단어를 끊습니다. 예를 들어 `don't` 는 `don` 과 `t` 두 단어입니다.
3. `int wordCount(const char *s)` 는 단어의 개수를 반환합니다.
4. `const char *longestWord(const char *s, int *len)` 는 가장 긴 단어의 첫 글자를 가리키는 포인터를 반환하고, `len` 이 가리키는 곳에 그 길이를 저장합니다. 길이가 같은 단어가 여럿이면 가장 앞의 단어를 고릅니다. 단어가 없으면 `NULL` 을 반환하고 길이는 0 으로 저장합니다.
5. 단어가 없으면 `단어 없음` 한 줄만 출력하세요.
6. 단어가 있으면 첫 줄에 `단어 수: ○`, 둘째 줄에 `가장 긴 단어: ○ (길이 △, 위치 □)` 를 출력하세요. ○ 는 단어 자체, △ 는 길이, □ 는 입력한 줄의 맨 앞 글자에서 그 단어 첫 글자까지의 거리(0 부터)이며 두 포인터를 빼서 구하세요.

## Tips
단어 시작 위치를 `start` 에 저장해 두고 알파벳이 이어지는 동안 포인터를 이동하면, 끝난 뒤 `s - start` 가 단어의 길이입니다. 단어를 출력할 때는 `start` 에서 길이만큼 `putchar` 하면 됩니다.

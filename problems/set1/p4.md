# 과일 가게 가격표

엘리스 토끼네 과일 가게에서 가격표를 만들려고 합니다. 입력받은 과일 이름과 가격으로 딕셔너리를 만들고 가격을 조회해 보세요.

## 지시사항
1. 첫 줄에 과일의 개수 N을 입력받으세요.
2. 다음 N줄에 걸쳐 `과일이름 가격` 을 입력받아, 이름을 키, 가격(정수)을 값으로 하는 딕셔너리에 저장하세요. 같은 이름이 또 입력되면 가격을 새 값으로 바꿉니다.
3. 마지막 줄에 조회할 과일 이름을 입력받으세요.
4. 딕셔너리에 있으면 그 가격(숫자만)을, 없으면 `없음` 을 출력하세요.

## 입력 예시 1
```
3
사과 1500
바나나 3000
포도 5000
바나나
```
## 출력 예시 1
```
3000
```

## 입력 예시 2
```
3
사과 1500
바나나 3000
포도 5000
수박
```
## 출력 예시 2
```
없음
```

# 체온 측정기

엘리스 토끼는 학교 정문에서 체온을 재는 일을 맡았습니다. 체온을 입력받아 상태를 알려 주세요.

## 지시사항
1. 체온을 실수로 입력받으세요.
2. 체온이 37.5 이상이면 `고열` 을 출력하세요.
3. 37.5 미만이면서 37.0 이상이면 `미열` 을 출력하세요.
4. 36.0 미만이면 `저체온` 을 출력하세요.
5. 위에 해당하지 않으면 `정상` 을 출력하세요. (36.0 이상 37.0 미만)

## 입력 예시 1
```
38.2
```
## 출력 예시 1
```
고열
```

## 입력 예시 2
```
36.5
```
## 출력 예시 2
```
정상
```

## Tips
경계값에 주의하세요. 37.5는 고열, 37.0은 미열, 36.0은 정상입니다.

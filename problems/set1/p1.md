# 편의점 영수증

엘리스 토끼는 편의점에서 간식을 샀습니다. 물건의 단가와 수량, 낸 돈을 입력받아 영수증을 출력해 보세요.

## 지시사항
1. 단가, 수량, 낸 돈을 각각 한 줄씩 입력받아 정수로 저장해 보세요.
2. 합계(단가 * 수량)를 계산해 `합계: ○○원` 형식으로 출력하세요.
3. 거스름돈(낸 돈 - 합계)을 계산해 `거스름돈: ○○원` 형식으로 출력하세요.
4. 낸 돈은 항상 합계 이상으로 입력됩니다.

## 입력 예시 1
```
1200
3
5000
```
## 출력 예시 1
```
합계: 3600원
거스름돈: 1400원
```

## 입력 예시 2
```
850
4
10000
```
## 출력 예시 2
```
합계: 3400원
거스름돈: 6600원
```

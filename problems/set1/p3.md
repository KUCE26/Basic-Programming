# 심사위원 점수 계산

엘리스 토끼의 발표에 심사위원 5명이 점수를 매겼습니다. 가장 높은 점수와 가장 낮은 점수를 하나씩 제외하고 남은 점수를 확인해 보세요.

## 지시사항
1. 공백으로 구분된 점수 5개를 한 줄로 입력받아 정수 리스트로 만드세요.
2. 리스트를 오름차순으로 정렬하세요.
3. 가장 낮은 점수 하나와 가장 높은 점수 하나를 리스트에서 제거하세요. 같은 점수가 여러 개여도 각각 하나만 제거합니다.
4. 남은 점수 리스트를 그대로 출력하세요.
5. 남은 점수의 합을 `합계: ○○` 형식으로 출력하세요.

## 입력 예시 1
```
8 6 9 7 10
```
## 출력 예시 1
```
[7, 8, 9]
합계: 24
```

## 입력 예시 2
```
50 90 70 90 60
```
## 출력 예시 2
```
[60, 70, 90]
합계: 220
```

## Tips
`map(int, input().split())` 으로 입력을 정수로 바꿀 수 있습니다.

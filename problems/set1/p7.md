# 홀수만 골라 말하기

엘리스 토끼는 1부터 숫자를 세다가 홀수만 말하는 놀이를 하고 있습니다.

## 지시사항
1. 자연수 N을 입력받으세요.
2. 1부터 N까지의 수 중 홀수만 한 줄에 공백으로 구분해 출력하세요. 줄 끝에 공백이 남지 않게 하세요.
3. 다음 줄에 홀수들의 합을 `홀수의 합: ○○` 형식으로 출력하세요.

## 입력 예시 1
```
10
```
## 출력 예시 1
```
1 3 5 7 9
홀수의 합: 25
```

## 입력 예시 2
```
7
```
## 출력 예시 2
```
1 3 5 7
홀수의 합: 16
```

## Tips
`print(*리스트)` 는 리스트의 원소를 공백으로 구분해 한 줄에 출력합니다.

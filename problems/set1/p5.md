# 이메일 주소 살펴보기

엘리스 토끼는 친구에게 받은 이메일 주소를 정리하려고 합니다. 이메일 주소를 입력받아 여러 가지 정보를 출력해 보세요.

## 지시사항
1. 이메일 주소를 한 줄 입력받으세요. `@` 는 항상 정확히 하나 들어 있습니다.
2. `@` 를 기준으로 나누어 아이디와 도메인을 구하고, 각각 `아이디: ○○`, `도메인: ○○` 형식으로 출력하세요.
3. 도메인에 들어 있는 `.` 의 개수를 `점 개수: ○` 형식으로 출력하세요.
4. 이메일 주소 전체를 대문자로 바꾸어 `대문자: ○○` 형식으로 출력하세요.

## 입력 예시 1
```
elice@korea.ac.kr
```
## 출력 예시 1
```
아이디: elice
도메인: korea.ac.kr
점 개수: 2
대문자: ELICE@KOREA.AC.KR
```

## 입력 예시 2
```
rabbit01@naver.com
```
## 출력 예시 2
```
아이디: rabbit01
도메인: naver.com
점 개수: 1
대문자: RABBIT01@NAVER.COM
```

## Tips
`split('@')` 는 `@` 를 기준으로 문자열을 나눈 리스트를 돌려줍니다.

# 단어 끝말 세기

엘리스 토끼가 단어를 계속 말하다가 `end` 라고 말하면 멈춥니다. 말한 단어의 개수와 가장 긴 단어를 알아봅시다.

## 지시사항
1. 단어를 한 줄에 하나씩 입력받는 것을 반복하세요. `end` 가 입력되면 반복을 멈춥니다. `end` 는 단어 개수에 포함하지 않습니다.
2. 입력된 단어의 개수를 `단어 개수: ○` 형식으로 출력하세요.
3. 가장 긴 단어를 `가장 긴 단어: ○○` 형식으로 출력하세요. 길이가 같은 단어가 여럿이면 먼저 입력된 단어를 출력합니다.
4. `max()` 함수는 사용하지 말고, 직접 길이를 비교하세요.
5. `end` 앞에는 최소 한 개의 단어가 입력됩니다. `end` 뒤에 줄이 더 있어도 읽지 않습니다(첫 `end`에서 멈추면 됩니다).

## 입력 예시 1
```
apple
banana
kiwi
end
```
## 출력 예시 1
```
단어 개수: 3
가장 긴 단어: banana
```

## 입력 예시 2
```
cat
dog
rat
end
```
## 출력 예시 2
```
단어 개수: 3
가장 긴 단어: cat
```

# 나의 BMI 구하기

엘리스 토끼는 건강검진에서 키와 몸무게를 측정했습니다. BMI 수치를 계산해서 출력해 보세요.

## 지시사항
1. 키(cm)와 몸무게(kg)를 각각 한 줄씩 실수로 입력받으세요.
2. BMI를 `몸무게 / (키(m)) ** 2` 로 계산하세요. 키는 cm 단위로 입력되므로 100으로 나누어 m로 바꿉니다.
3. BMI를 소수점 둘째 자리까지 f-string을 사용해 `BMI: ○○.○○` 형식으로 출력하세요.

## 입력 예시 1
```
175
74
```
## 출력 예시 1
```
BMI: 24.16
```

## 입력 예시 2
```
160.5
52.3
```
## 출력 예시 2
```
BMI: 20.30
```

## Tips
`f"{x:.2f}"` 는 x를 소수점 둘째 자리까지 나타냅니다.

# 여왕의 정렬 규칙

하트 여왕은 매번 다른 규칙으로 병사들의 번호표를 세우라고 명령합니다. 정렬 함수는 하나만 두고, 규칙은 비교 함수를 함수 포인터로 넘겨 바꾸세요. 규칙마다 순서가 완전히 정해지도록 동점 처리도 지켜야 합니다.

## 지시사항
1. 시작 코드의 비교 함수는 모두 `int cmp(int a, int b)` 형태이며, `a` 가 `b` 보다 뒤에 와야 하면 양수, 앞에 와야 하면 음수, 순서가 같으면 0 을 반환해야 합니다.
2. `byValue`: 값이 작은 쪽이 앞에 옵니다(오름차순).
3. `byAbsDesc`: 절댓값이 큰 쪽이 앞에 옵니다. 절댓값이 같으면 값이 작은 쪽이 앞에 옵니다(예: -5 가 5 보다 앞).
4. `byDigitSum`: 절댓값의 각 자리 숫자를 모두 더한 값(예: -123 은 6)이 작은 쪽이 앞에 옵니다. 그 합이 같으면 값이 작은 쪽이 앞에 옵니다.
5. `void sortBy(int *arr, int n, int (*cmp)(int, int))` 를 작성하세요. 원소는 `*(arr + j)` 형태로 접근하고, 인접한 두 원소에 `cmp` 를 적용하여 `cmp` 의 결과가 양수이면 둘을 맞바꾸는 방식(버블 정렬)으로 정렬합니다. `qsort` 는 쓰지 않습니다.
6. 규칙 번호를 먼저 입력받으세요. 1 은 `byValue`, 2 는 `byAbsDesc`, 3 은 `byDigitSum` 입니다. 1~3 이 아니면 `잘못된 선택입니다.` 한 줄만 출력하고, 뒤의 입력은 읽지 않고 끝냅니다.
7. 올바른 번호이면 정수 `n`(1 이상 15 이하)과 n 개의 정수(-1000000 이상 1000000 이하)를 입력받아 정렬하고, 첫 줄에 결과를 공백 한 칸으로 구분해 출력하세요(마지막 값 뒤 공백 없음).
8. 둘째 줄에 `끝과 처음의 차: ○` 를 출력하세요. 정렬된 배열의 마지막 원소 값에서 첫 원소 값을 뺀 값입니다.

## Tips
비교 함수는 대소를 비교해 -1, 0, 1 중 하나를 돌려주면 안전합니다. 자릿수 합은 `abs` 로 부호를 없앤 뒤 `% 10` 과 `/ 10` 을 반복해 구합니다. 동점이면 `byValue` 를 다시 불러 쓰면 편합니다.

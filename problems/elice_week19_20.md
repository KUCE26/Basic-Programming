## 19차시 [실습1] 거꾸로 숫자세기! (lectures/6781518/lecturepages/55663018, 9/16)

로켓 발사를 위해 거꾸로 숫자를 카운트다운하는 코드를 작성해 보세요. for문을 활용하여 10부터 1까지 거꾸로 숫자를 세야 합니다.

지시사항: count는 10부터 시작하세요. 1까지 출력할 수 있도록 조건을 작성하세요. count를 -1 감소시키세요.

출력 예시:
```
현재 숫자: 10
현재 숫자: 9
...
현재 숫자: 2
현재 숫자: 1
```
Tips: 마지막 줄에 개행이 출력되는 것에 유의하세요.

시작 코드:
```c
#include <stdio.h>
int main(void)
{
    int count;
    
    for( ; ; )
    {
        printf("현재 숫자: %d\n", count);
    }
    
    return 0;
}
```

## 20차시 [실습6] 소수 판별 프로그램 (55663046, 14/15)

사용자로부터 입력받은 양의 정수가 소수인지 판별하는 프로그램을 작성해보세요. 소수는 1과 자기 자신만을 약수로 가지는 수입니다. 사용자가 0을 입력할 때까지 입력을 받도록 합니다.

지시사항: 사용자로부터 정수를 입력받고, 입력이 0인 경우 반복문을 종료합니다. 만약, 음수가 입력될 경우 소수 판별 대상이 아니기 때문에 다음 입력으로 건너뛰어야 합니다. 소수일 경우 "입력받은 수은(는) 소수입니다." 를, 소수가 아닐 경우 "입력받은 수은(는) 소수가 아닙니다."를 출력합니다. 해당 문장 뒤 개행을 함께 출력합니다.

입력 예시 1: `2 / 0` → 출력 예시 1: `2은(는) 소수입니다.`
입력 예시 2: `4 / 3 / 2 / 1 / 0` → 출력 예시 2:
```
4은(는) 소수가 아닙니다.
3은(는) 소수입니다.
2은(는) 소수입니다.
1은(는) 소수가 아닙니다.
```

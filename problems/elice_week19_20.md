## 19차시 [실습1] 거꾸로 숫자세기! (lectures/6781518/lecturepages/55663018, 9/16)

로켓 발사를 위해 거꾸로 숫자를 카운트다운하는 코드를 작성해 보세요. for문을 활용하여 10부터 1까지 거꾸로 숫자를 세야 합니다.

지시사항: count는 10부터 시작하세요. 1까지 출력할 수 있도록 조건을 작성하세요. count를 -1 감소시키세요.

출력 예시:
```
현재 숫자: 10
현재 숫자: 9
...
현재 숫자: 2
현재 숫자: 1
```
Tips: 마지막 줄에 개행이 출력되는 것에 유의하세요.

시작 코드:
```c
#include <stdio.h>
int main(void)
{
    int count;
    
    for( ; ; )
    {
        printf("현재 숫자: %d\n", count);
    }
    
    return 0;
}
```

## 19차시 [실습7] 다이아몬드 광산 (55663024, 15/16)

땅을 계속 파면서 사용자로부터 땅을 파내고 얻은 물건을 입력 받다가 다이아몬드(diamond)를 파내면 땅 파기를 종료하면서 지금까지 땅을 몇번 팠는지 출력하는 프로그램을 작성하세요. 예를 들어 `soil / trash / glasses / vinyl / diamond` 가 순차적으로 들어오면 diamond에서 멈추고 땅을 판 총 횟수인 5를 출력합니다. (마지막 diamond를 얻기 위해서도 땅을 파야 하므로 4가 아닌 5.)

지시사항: 땅을 파는 횟수를 저장할 정수형 변수와 땅을 파고 얻은 물건을 저장할 문자열 변수(입력되는 문자열의 최대 길이는 20)를 정의합니다. do-while 문을 활용하여 사용자에게 땅을 파고 얻은 물건을 입력받고, 땅을 파는 횟수를 증가시키는 반복문을 구현합니다. 만약, 사용자에게 입력받은 물건이 diamond 일 경우, 해당 반복문을 빠져나가고, 지금까지 땅을 파낸 횟수를 출력합니다.

입력 예시 1: `ruby / stone / diamond` → 출력 예시 1: `3`
입력 예시 2: `diamond` → 출력 예시 2: `1`
Tips: 문자열이 동일한지 여부를 확인하기 위해선 string.h의 strcmp 함수를 사용할 수 있습니다.

시작 코드: `#include <stdio.h>` `#include <string.h>` 빈 main
(※ 이 실습만 문자열 변수(char 배열)+strcmp 를 씀. 배열 자체는 아직 정식 차시가 아니므로 변형 문제에서는 문자열 입력을 쓰지 않거나 극히 제한적으로만 사용.)

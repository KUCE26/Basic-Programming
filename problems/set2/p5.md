# 단어 분석기

엘리스 토끼는 영어 문장을 받아 단어를 분석하는 프로그램을 만들고 있습니다. 문장 속의 단어를 세고, 이어 붙이고, 찾아 보세요.

## 지시사항
1. 첫째 줄에 문장이, 둘째 줄에 찾을 단어가 주어집니다. 문장은 공백으로 단어가 구분됩니다.
2. `split()`으로 문장을 단어 리스트로 나누세요.
3. 첫째 줄에 단어의 개수를 출력하세요.
4. 둘째 줄에 단어들을 `-`로 이어 붙여(`join`) 출력하세요.
5. 셋째 줄에 찾을 단어가 단어 리스트에 들어 있는지 `True` 또는 `False`로 출력하세요.

## 입력 예시 1
```
i love python
love
```
## 출력 예시 1
```
3
i-love-python
True
```

## 입력 예시 2
```
hello world again and again
bye
```
## 출력 예시 2
```
5
hello-world-again-and-again
False
```

## Tips
`target in words`는 `True` 또는 `False` 값이 됩니다.

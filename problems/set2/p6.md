# 요일 알림이

엘리스 토끼는 요일 번호를 보고 오늘이 무슨 요일인지 알려 주는 알림이를 만들고 있습니다. 월요일은 1, 일요일은 7입니다.

## 지시사항
1. 요일 번호(정수)가 하나 주어집니다.
2. `match-case`를 사용하여 1부터 7까지 `월요일`, `화요일`, `수요일`, `목요일`, `금요일`, `토요일`, `일요일`을 출력하세요.
3. 6이나 7이면 요일 이름을 출력한 다음 줄에 `주말`도 출력하세요.
4. 1~7 범위 밖의 값이면 `잘못된 입력`만 출력하세요.

## 입력 예시 1
```
3
```
## 출력 예시 1
```
수요일
```

## 입력 예시 2
```
6
```
## 출력 예시 2
```
토요일
주말
```

## Tips
`case _:`는 어떤 case에도 해당하지 않을 때 실행됩니다.

# 엘리스 토끼의 지각 시간 계산기

엘리스 토끼는 시계를 보며 지각한 시간을 계산하고 있습니다. 시계는 초 단위로만 알려 주기 때문에, 시간을 "시간, 분, 초"로 바꿔야 합니다.

## 지시사항
1. 입력으로 정수 하나가 주어집니다. 이 값은 흘러간 시간(초)입니다.
2. `//` 연산자와 `%` 연산자를 사용하여 시간, 분, 초로 변환해 보세요.
3. 변환한 결과를 `H시간 M분 S초` 형식으로 출력하세요. (예: `1시간 2분 5초`)
4. 0인 값도 생략하지 않고 그대로 출력하세요.

## 입력 예시 1
```
3725
```
## 출력 예시 1
```
1시간 2분 5초
```

## 입력 예시 2
```
59
```
## 출력 예시 2
```
0시간 0분 59초
```

## Tips
1시간은 3600초, 1분은 60초입니다. 먼저 시간을 구하고, 남은 초(`%`)에서 분을 구해 보세요.

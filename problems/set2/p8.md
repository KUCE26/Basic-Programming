# 엘리스 은행 시뮬레이터

엘리스 은행의 창구에는 입금과 출금 요청이 계속 들어옵니다. 통장 잔액을 관리하는 프로그램을 만들어 보세요.

## 지시사항
1. 첫째 줄에 처음 잔액(0 이상의 정수)이 주어집니다.
2. 그 다음 줄부터 정수가 한 줄에 하나씩 계속 입력됩니다. 양수는 입금, 음수는 출금입니다.
3. `0`이 입력되면 입력을 멈추세요. (`break` 사용)
4. 출금했을 때 잔액이 음수가 되면 `잔액 부족`을 출력하고, 그 요청은 무시한 채 다음 입력으로 넘어가세요. (`continue` 사용)
5. 입력이 끝나면 `최종 잔액: 15000원` 형식으로 최종 잔액을 출력하세요.

## 입력 예시 1
```
10000
5000
-3000
0
```
## 출력 예시 1
```
최종 잔액: 12000원
```

## 입력 예시 2
```
5000
-8000
2000
-7000
-100
0
```
## 출력 예시 2
```
잔액 부족
잔액 부족
최종 잔액: 0원
```

## Tips
잔액 부족 요청은 잔액을 바꾸지 않습니다. 계산하기 전에 먼저 검사해 보세요.

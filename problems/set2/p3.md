# 새치기 손님

엘리스 카페 앞에 손님들이 줄을 서 있습니다. 그런데 새치기하려는 손님이 나타났습니다! 줄의 상태를 기록해 보세요.

## 지시사항
1. 첫째 줄에 줄을 선 사람들의 이름이 공백으로 구분되어 주어집니다. `split()`으로 리스트에 저장하세요.
2. 둘째 줄에 새치기할 사람의 이름, 셋째 줄에 새치기할 위치(인덱스, 정수)가 주어집니다.
3. `insert()`를 사용하여 해당 위치에 이름을 끼워 넣고, 리스트를 출력하세요.
4. 그 다음 줄의 마지막 사람이 집으로 돌아갑니다. `pop()`으로 마지막 사람을 꺼낸 뒤, 리스트를 다시 출력하세요.

## 입력 예시 1
```
앨리스 토끼 모자장수
여왕
1
```
## 출력 예시 1
```
['앨리스', '여왕', '토끼', '모자장수']
['앨리스', '여왕', '토끼']
```

## 입력 예시 2
```
kim lee park choi
jung
0
```
## 출력 예시 2
```
['jung', 'kim', 'lee', 'park', 'choi']
['jung', 'kim', 'lee', 'park']
```

## Tips
리스트를 `print()`하면 `['a', 'b']` 모양으로 출력됩니다.

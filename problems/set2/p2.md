# 엘리스의 환전 계산기

엘리스는 해외여행을 앞두고 원화를 달러로 바꿔 보려고 합니다. 환율과 금액이 주어지면 몇 달러인지 계산해 주는 프로그램을 만들어 보세요.

## 지시사항
1. 첫째 줄에 원화 금액(정수), 둘째 줄에 환율(실수)이 주어집니다. 각각 `int`, `float`로 변환하여 저장하세요.
2. 달러 금액은 `원화 금액 / 환율`로 계산하세요.
3. 출력은 반드시 `%` 포맷팅을 사용하세요. (f-string 사용 금지)
4. 첫째 줄에는 환율을 소수점 첫째 자리까지 `환율: 1350.5원` 형식으로 출력하세요.
5. 둘째 줄에는 `135050원은 100.00달러입니다.` 형식으로, 원화 금액은 정수로, 달러 금액은 소수점 둘째 자리까지 출력하세요.

## 입력 예시 1
```
135050
1350.5
```
## 출력 예시 1
```
환율: 1350.5원
135050원은 100.00달러입니다.
```

## 입력 예시 2
```
200000
1400.0
```
## 출력 예시 2
```
환율: 1400.0원
200000원은 142.86달러입니다.
```

## Tips
`%.2f`는 소수점 둘째 자리까지, `%d`는 정수를 출력합니다. 값이 둘 이상이면 `% (값1, 값2)`처럼 튜플로 묶으세요.

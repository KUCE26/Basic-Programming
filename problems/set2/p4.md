# 출석 체크 장부

엘리스 학교의 출석부에는 학생 이름이 출석할 때마다 한 줄씩 적힙니다. 이름별로 몇 번 출석했는지 딕셔너리로 정리해 보세요.

## 지시사항
1. 이름이 한 줄에 하나씩 입력됩니다. `끝`이 입력되면 입력을 멈추세요.
2. 딕셔너리를 만들어 이름이 처음 나오면 횟수를 1로, 이미 있는 이름이면 횟수를 1 늘리세요. (`in` 사용)
3. 입력이 끝나면 딕셔너리를 그대로 출력하세요. 딕셔너리는 이름이 처음 입력된 순서를 유지합니다.
4. 아무도 입력하지 않고 `끝`만 입력되면 `{}`를 출력하세요.

## 입력 예시 1
```
kim
lee
kim
끝
```
## 출력 예시 1
```
{'kim': 2, 'lee': 1}
```

## 입력 예시 2
```
park
park
park
끝
```
## 출력 예시 2
```
{'park': 3}
```

## Tips
딕셔너리를 `print()`하면 `{'kim': 2, 'lee': 1}` 모양으로 출력됩니다.

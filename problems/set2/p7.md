# 거꾸로 구구단

엘리스 토끼는 구구단을 거꾸로 외우는 놀이를 하고 있습니다. 한 단을 9번째 줄부터 1번째 줄까지 거꾸로 출력해 보세요.

## 지시사항
1. 단을 나타내는 정수 N이 주어집니다.
2. `for`문과 `range()`를 사용하여 곱하는 수를 9부터 1까지 거꾸로 변화시키세요.
3. 각 줄을 `N * 곱하는 수 = 결과` 형식으로 출력하세요. (`*` 앞뒤, `=` 앞뒤에 공백이 하나씩 있습니다.)

## 입력 예시 1
```
3
```
## 출력 예시 1
```
3 * 9 = 27
3 * 8 = 24
3 * 7 = 21
3 * 6 = 18
3 * 5 = 15
3 * 4 = 12
3 * 3 = 9
3 * 2 = 6
3 * 1 = 3
```

## 입력 예시 2
```
19
```
## 출력 예시 2
```
19 * 9 = 171
19 * 8 = 152
19 * 7 = 133
19 * 6 = 114
19 * 5 = 95
19 * 4 = 76
19 * 3 = 57
19 * 2 = 38
19 * 1 = 19
```

## Tips
`range(9, 0, -1)`은 9, 8, ..., 1을 차례로 만듭니다.

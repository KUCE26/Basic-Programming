## [실습1] 너는 어디에 사니? (lecturepages/55663154)
메모리에 할당된 변수들은 주소를 가진다. 선언된 두 변수의 주소를 출력해 형태를 확인.
지시사항: 두 변수(int num = 10; float num2 = 3.14;)의 주소를 각 줄에 출력하는 출력문 작성. 실행 버튼을 한 번 더 눌러 동일한 결괏값이 나오는지 확인.
Tips: 메모리 주소를 출력하기 위한 형식 지정자는 %p.

## [실습2] 변수에 주소를 저장! (55663155)
포인터 변수에 num 변수의 주소를 저장하고 num 의 값과 ptr 이 가리키는 값이 같은지 조건문으로 확인.
지시사항: ptr 포인터 변수를 선언하고 num(=10) 의 주소로 초기화. *ptr 과 num 을 한 줄에 공백으로 출력한 뒤, 같으면 "값이 같아요.", 다르면 "값이 달라요." 출력.
출력 예시: `10 10` / `값이 같아요.`

## [실습3] 간접 접근 (55663156)
간접 접근: 포인터와 메모리 주소로 변수에 접근. * 로 값을 참조하거나 변경.
지시사항: num1(int 200) 을 가리키는 ptr1, num2(float 3.14) 를 가리키는 ptr2 선언. 간접 접근으로 ptr1 이 가리키는 값을 123, ptr2 가 가리키는 값을 -4.23 으로 변경. num1 num2 를 공백으로 출력.
출력 예시: `123 -4.230000`

## [실습4] 포인터의 포인터의 포인터 (55663157)
정수를 입력받아 그 값을 가리키는 포인터, 포인터의 포인터, 포인터의 포인터의 포인터를 만들고 포인터로 값을 출력.
지시사항: ptr1, ptr2, ptr3 선언. ptr1→num, ptr2→ptr1, ptr3→ptr2. ptr3, ptr2, ptr1 을 활용해 num 값을 공백으로 출력.
입력 예시: `100` / 출력 예시: `100 100 100`

## [실습5] 교체 작업 (55663158)
두 컵의 물을 서로 바꿔 주는 함수를 만들기.
지시사항: swap() 정의 — cup1, cup2 두 정수를 포인터 매개변수로 받아 값을 교체, 반환값 없음. main 에서 scanf("%d %d", &cup1, &cup2) 후 swap(&cup1, &cup2) 호출.
입력 예시: `8 10` / 출력 예시: `1번 컵 : 10` / `2번 컵 : 8`

## [실습6] 포인터와 Constant 키워드 (55663159)
Constant 키워드는 값이 프로그램 내에서 변화될 수 없다는 의미. 상수 포인터와 포인터 상수를 올바르게 이해하고 코드를 수정.
지시사항: ptr1 과 ptr2 가 각각 상수 포인터와 포인터 상수로 작동하도록 수정.
시작 코드: int x = 10, y = 20; int *ptr1 = &x; int *ptr2 = &y; printf("ptr1이 가리키는 값: %d\n", *ptr1); printf("ptr2가 가리키는 값: %d\n", *ptr2); *ptr1 = 15; ptr2 = &x; ... (ptr1 은 가리키는 값을 바꾸고 ptr2 는 가리키는 대상을 바꿈 → ptr1 은 int *const, ptr2 는 const int * 로 선언해야 컴파일됨)

## [실습1] 주소 연산 (55663176)
다양한 자료형의 변수를 선언하고 포인터를 초기화. 주소를 출력해 보고 1을 더한 주소가 어떻게 나오는지 관찰.
시작 코드: short num1[2]; int num2[2]; double num3[2]; short *ptr1 = num1; int *ptr2 = num2; double *ptr3 = num3; ...
지시사항: 포인터 변수에 있는 주소와 1을 더한 주소를 공백을 두고 출력. 포인터에 1을 더하면 주솟값이 얼마나 증가하는지 자료형 크기와 비교.

## [실습2] 모음 찾기 (55663177)
사용자가 입력한 문자열에서 모음(a, e, i, o, u)의 개수를 세는 프로그램. 포인터 주소 연산으로 문자열을 순회.
지시사항: 전달받은 문자열을 순회하며 모음 개수를 세어 반환하는 countVowels 함수 작성. 매개변수는 문자열 포인터 str.
입력 예시: `Hello, World! How are you?` / 출력 예시: `모음의 개수: 8`
Tips: ctype.h 의 tolower() 로 소문자로 만들어 모음인지 확인.

## [실습3] void*형 포인터 (55663178)
void 포인터는 어떤 주소든 저장 가능. 사용하려면 원하는 형태로 변환. int a = 10; void *vp = &a; → *(int*)vp. 형 변환을 하면 정수 연산도 가능.
지시사항: void형 포인터 vp 선언. vp 를 a(int 10) 의 주소로 초기화하고 형변환하여 값 출력. vp 를 b(double 3.5) 의 주소로 초기화하고 형변환하여 값 출력.
출력 예시: `a : 10` / `b : 3.5`

## [실습4] 함수 포인터 (55663179)
함수의 주소도 포인터에 저장하면 포인터로 함수 호출 가능. int sum(int, int); → int (*fp)(int, int); 반드시 별표와 변수명을 괄호로 묶는다(없으면 주소를 반환하는 함수 선언). 함수 포인터는 간접 참조 연산자 없이 바로 호출 가능.
지시사항: int 두 개를 받아 int 를 반환하는 함수 포인터 fp 선언, fp 를 sum 으로 초기화, fp(10, 20) 결과를 res 에 저장.
출력 예시: `result : 30`

## [실습5] 함수 자판기 (55663180)
함수 포인터는 형태만 같으면 모든 함수에 사용 가능 → 형태가 같은 다양한 기능의 함수를 선택적으로 호출. func(): 2개의 정수를 키보드로 입력 → 두 정수로 연산 → 결과 출력. 연산 종류를 호출할 때 결정하도록 매개변수에 함수 포인터.
시작 코드 원형: void func(int (*fp)(int, int)); int sum(int a, int b); int mul(int a, int b); int max(int a, int b);
지시사항: 함수 포인터 fp 를 매개변수로 받는 func() 작성(두 수를 입력받아 fp 의 연산을 수행하고 결괏값 출력).
출력 예시:
```
01 두 정수의 합
02 두 정수의 곱
03 두 정수 중에서 큰 값 계산
원하는 연산을 선택하세요 : 2
두 정수의 값을 입력하세요 : 3 7
결괏값은 : 21
```

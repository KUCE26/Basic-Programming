# 동점자 공동 등수표

하트 여왕의 크로켓 대회가 끝났습니다. 선수 번호는 입력된 순서대로 1번, 2번, ... 이고, 점수가 같으면 공동 등수를 줍니다. 순위표를 높은 점수부터 작성해야 합니다.

## 지시사항
1. 정수 `n` 을 입력받으세요. n 은 1 이상 10 이하입니다. 이어서 n 개의 점수(0 이상 100 이하 정수)를 입력받아 크기 10 의 배열 `score` 에 저장하세요. 입력 순서대로 선수 번호는 1 번부터 n 번입니다.
2. 선수 번호를 저장하는 크기 10 의 배열 `id` 를 하나 더 만들어 `id[i] = i + 1` 로 채우세요.
3. 버블 정렬로 점수 내림차순 정렬하세요. 인접한 두 원소를 비교해 왼쪽 점수가 오른쪽 점수보다 **작을 때만** 두 원소를 맞바꿉니다(같으면 바꾸지 않음). 이때 `score` 와 `id` 를 항상 함께 맞바꿔야 합니다. 결과적으로 점수가 같은 선수는 번호가 작은 선수가 앞에 옵니다.
4. 정렬된 순서대로 한 줄에 한 명씩 `○등: ○번 (○점)` 형식으로 출력하세요. 등수는 '자기보다 점수가 높은 선수의 수 + 1' 입니다. 예를 들어 95, 90, 90, 80 점이면 등수는 1, 2, 2, 4 가 됩니다.
5. 마지막 줄에 `공동 순위 선수: ○명` 을 출력하세요. 자신과 점수가 같은 다른 선수가 한 명이라도 있는 선수의 수입니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
5
80 95 90 90 70
```
## 출력 예시 1
```
1등: 2번 (95점)
2등: 3번 (90점)
2등: 4번 (90점)
4등: 1번 (80점)
5등: 5번 (70점)
공동 순위 선수: 2명
```

## 입력 예시 2
```
4
50 50 50 50
```
## 출력 예시 2
```
1등: 1번 (50점)
1등: 2번 (50점)
1등: 3번 (50점)
1등: 4번 (50점)
공동 순위 선수: 4명
```

## Tips
등수는 정렬된 위치(i+1)와 다를 수 있습니다. 앞 선수와 점수가 같으면 앞 선수의 등수를 그대로 쓰고, 다르면 i+1 로 새로 정하면 됩니다.

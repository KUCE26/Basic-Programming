# 지뢰 탐지 정원

가로 C 칸, 세로 R 칸 정원에 하트 병사들이 지뢰를 묻었습니다. 지뢰 위치는 지도 좌표 (x, y) 로 주어집니다. x 는 왼쪽부터 센 열 번호, y 는 위에서부터 센 행 번호이며 둘 다 1 부터 시작합니다. 각 칸 주변의 지뢰 수를 알려 주세요.

## 지시사항
1. `R`, `C`, `K` 를 공백으로 구분해 입력받으세요. R 과 C 는 각각 1 이상 8 이하, K 는 0 이상 20 이하입니다. 이어서 K 줄에 지뢰의 `x y` 를 입력받습니다. 좌표는 정원 안이며 같은 칸이 여러 번 나올 수 있습니다.
2. 지뢰 여부를 저장할 `int mine[8][8]` 을 0 으로 초기화해 선언하고, 지뢰가 있는 칸을 1 로 표시하세요. 행과 열 순서에 주의하세요.
3. R 줄, 줄마다 C 글자를 공백 없이 출력하세요. 지뢰가 있는 칸은 `*`, 아닌 칸은 그 칸을 둘러싼 8방향 칸에 있는 지뢰 수(0 이상 8 이하 숫자 하나)를 씁니다. 정원 밖은 지뢰가 없는 것으로 칩니다.
4. 마지막 줄에 `지뢰: ○개` 를 출력하세요. 지뢰가 묻힌 서로 다른 칸의 수입니다.

## 시작 코드
```c
#include <stdio.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
3 4 2
2 1
4 3
```
## 출력 예시 1
```
1*10
1121
001*
지뢰: 2개
```

## 입력 예시 2
```
2 5 3
1 2
3 2
3 2
```
## 출력 예시 2
```
12110
*2*10
지뢰: 2개
```

## Tips
입력 좌표는 (x, y) 이지만 배열은 `mine[행][열]` 이므로 `mine[y - 1][x - 1]` 에 저장합니다. 주변 8칸을 볼 때는 인덱스가 0 미만이거나 R, C 이상이 되지 않는지 먼저 검사한 뒤 배열에 접근하세요.

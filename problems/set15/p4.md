# 한 줄 읽기의 함정

앨리스가 작은 쪽지 상자에 한 줄짜리 쪽지를 넣습니다. 상자는 널 문자까지 포함해서 8칸뿐이라 긴 쪽지는 전부 들어가지 않습니다.

## 지시사항
1. 크기 8 인 `char` 배열 `buf` 를 선언하고, `fgets(buf, 8, stdin)` 으로 표준 입력에서 한 줄을 읽으세요. 줄에는 공백이 들어 있을 수 있고 길이는 1 이상 40 이하입니다. `fgets` 는 줄바꿈 문자를 만나거나 최대 7 글자를 읽으면 멈추고, 읽은 글자 뒤에 널 문자를 붙입니다. 줄바꿈 문자를 읽었다면 그것도 배열에 저장합니다.
2. 첫 줄에 `읽은 글자 수: ○` 를 출력하세요. 줄바꿈 문자를 지우기 **전** 에 `strlen` 으로 잰 값입니다(줄바꿈 문자가 배열에 있었다면 그것도 한 글자로 셉니다).
3. 둘째 줄에 `개행 포함: 예` 또는 `개행 포함: 아니오` 를 출력하세요. 배열에 줄바꿈 문자 `'\n'` 가 들어 있었는지를 말합니다.
4. 배열에 줄바꿈 문자가 있었다면 그 자리를 널 문자로 바꿔서 지우세요. 그런 다음 셋째 줄에 `내용: [○○]` 형식으로 배열의 문자열을 대괄호로 감싸 출력하세요.

## 시작 코드
```c
#include <stdio.h>
#include <string.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
hello
```
## 출력 예시 1
```
읽은 글자 수: 6
개행 포함: 예
내용: [hello]
```

## 입력 예시 2
```
Alice in Wonderland
```
## 출력 예시 2
```
읽은 글자 수: 7
개행 포함: 아니오
내용: [Alice i]
```

## Tips
줄바꿈 문자를 지우지 않으면 `내용: [hello` 다음에 줄이 바뀌어 `]` 가 다음 줄에 찍힙니다. `fgets(buf, 8, stdin)` 은 최대 7 글자만 읽으므로 입력이 6 글자 이하일 때만 줄바꿈 문자가 배열에 들어옵니다. 정확히 7 글자인 줄은 줄바꿈 문자가 입력에 남아 있고 배열에는 없습니다.

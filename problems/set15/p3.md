# 사전 맨 앞의 단어

도서관의 사서 토끼는 단어 카드 세 장을 사전순으로 비교합니다. 이 도서관은 컴퓨터의 방식(아스키 코드 순서)을 따라서, 대문자는 모든 소문자보다 앞에 옵니다.

## 지시사항
1. 공백 없는 영문·숫자 단어 세 개를 공백이나 줄바꿈으로 구분해 입력받으세요(각 길이 1 이상 20 이하). 단어 세 개를 저장할 `char` 2차원 배열을 쓰세요.
2. `strcmp` 로 첫째와 둘째, 둘째와 셋째를 차례로 비교해서 `단어 기호 단어` 형식으로 한 줄씩 출력하세요. 앞 단어가 사전순으로 앞서면 `<`, 뒤서면 `>`, 완전히 같으면 `=` 입니다(기호 양옆에 공백 한 칸).
3. `strcmp` 가 돌려주는 값의 크기는 컴파일러마다 다를 수 있습니다. 0 보다 작은지, 같은지, 큰지만 판단하세요.
4. 셋째 줄에 `사전 맨 앞: ○○` 를 출력하세요. 세 단어 중 사전순으로 가장 앞서는 단어이며, 가장 앞서는 단어가 여러 개이면 먼저 입력된 단어입니다. 정렬 알고리즘 없이, 가장 앞선 단어의 번호를 하나 기억해 두고 비교하면 됩니다.

## 시작 코드
```c
#include <stdio.h>
#include <string.h>

int main(void) {
    // 지시사항을 참고하여 코드를 작성하세요.

    return 0;
}
```

## 입력 예시 1
```
apple banana cherry
```
## 출력 예시 1
```
apple < banana
banana < cherry
사전 맨 앞: apple
```

## 입력 예시 2
```
Zebra apple Apple
```
## 출력 예시 2
```
Zebra < apple
apple > Apple
사전 맨 앞: Apple
```

## Tips
문자열 비교는 첫 글자부터 차례로 같은지 보다가 처음으로 다른 글자에서 아스키 코드의 크기로 결정됩니다. 한쪽이 다른 쪽의 앞부분이면 짧은 쪽이 앞섭니다. 숫자 문자열도 글자 단위로 비교하므로 `"10"` 은 `"9"` 보다 앞섭니다.

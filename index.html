세트마다 같은 10슬롯

시험에서 어떤 유형이 나와도 한 번씩은 풀어 본 상태가 되도록, A–E 다섯 세트 모두 아래 순서로 짰어요. 과제 세트는 교수님이 시험 난이도의 기준이라고 한 엘리스 4차시·8차시 과제 15문제 원본, 연습 세트는 12차시 종합 연습 문제 중 시험 범위 안 10문제예요. 범위밖(11차시 과제 등 모듈·클래스·정규식 8문제)은 중간고사엔 안 나오니 시간이 남을 때만 보세요.

    이렇게 쓰세요

    1. 시험처럼 풀려면 세트 하나를 골라 1번부터 10번까지 정답 보기 없이 끝까지 제출하고 점수를 확인하세요.
    2. 틀린 문제는 채점 결과의 빨간 줄(기대 출력과 다른 줄)을 보고 고친 뒤 다시 제출하세요. 띄어쓰기·콜론·소수점 자릿수가 가장 흔한 실수예요.
    3. 막히면 입력 탭에 입력 예시를 넣고 실행으로 중간 값을 print()해 보세요. 끝나지 않는 반복문은 5초 뒤 자동으로 멈춰요.
    4. 편집기에서 Ctrl+Enter(Mac은 ⌘+Enter)는 실행, Ctrl+Shift+Enter는 제출이에요.
